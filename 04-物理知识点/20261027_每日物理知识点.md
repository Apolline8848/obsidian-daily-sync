# **第一部分：今日题目**

## **滚摆与蹦床中的能量转化（机械能）**

涉及章节：第二章 运动与能量

考查考点：动能与重力势能转化、能量守恒

## **题目**

小明在物理课上玩两个实验：（1）用滚摆（一个悬挂在细绳上的转轮）上下滚动；（2）观察蹦床运动员从高处下落到蹦床上又被弹起的过程。

请回答：

（1）滚摆下降过程中，其高度减小、速度增大，此过程中哪种能量转化为哪种能量？

（2）滚摆上升到最高点时速度为零，此时它具有的能量是什么？滚摆每次上升的高度会逐渐降低，这说明什么？

（3）蹦床运动员下落时，重力势能、动能、蹦床的弹性势能之间如何转化？

（4）运动员落到蹦床最低点时，蹦床形变最大，此时运动员的速度是多少？蹦床储存的能量是什么？

（5）若不计一切阻力，滚摆能否永远保持原来的高度上下滚动？这体现了什么规律？实际中为什么做不到？

# **第二部分：参考答案与解析**

（1）滚摆下降过程中，高度减小使重力势能减小，速度增大使动能增大，此过程是重力势能转化为动能。

（2）上升到最高点时速度为 0，动能为 0，此时只具有重力势能。每次上升高度逐渐降低，说明机械能逐渐减小，因为克服空气阻力和转轴摩擦做功，一部分机械能转化为内能。

（3）运动员下落：重力势能转化为动能；接触蹦床后，动能和重力势能转化为蹦床的弹性势能；被弹起时，弹性势能又转化为动能和重力势能。

（4）运动员落到最低点时，速度为零（动能为 0），蹦床形变最大，储存的弹性势能最大。

（5）若不计一切阻力，机械能守恒，滚摆能永远保持原来的高度上下滚动。这体现了能量守恒定律（机械能守恒）。实际中由于存在空气阻力和摩擦，一部分机械能转化为内能，机械能逐渐减小，所以做不到。
