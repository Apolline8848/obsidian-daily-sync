# **第一部分：今日题目**

## **冰的熔化实验与晶体特点（物态变化）**

涉及章节：第五章 物态变化

考查考点：晶体熔点、熔化图像、凝固放热

## **题目**

小明在实验室做「探究冰的熔化」实验：将碎冰放入试管，用水浴法加热，每隔 1 min 记录一次温度，数据如下表：

时间/min 0 1 2 3 4 5 6 7

温度/℃ -4 -2 0 0 0 0 2 4

请回答：

（1）冰是晶体还是非晶体？判断依据是什么？冰的熔点是多少？

（2）在第 2 min 到第 5 min，冰处于什么状态？温度为什么保持不变？

（3）该实验采用水浴法加热的好处是什么？

（4）冰在熔化过程中需要吸热还是放热？冬天北方菜窖里放几桶水，利用的是什么道理防止蔬菜冻坏？

（5）冰全部熔化后继续加热，水沸腾时温度会持续升高吗？水沸腾时有哪些特点？

# **第二部分：参考答案与解析**

（1）冰是晶体。判断依据：冰在熔化过程中温度保持不变（有固定的熔点）。冰的熔点是 0℃。

（2）第 2\~5 min 冰处于固液共存状态（正在熔化）。因为冰是晶体，熔化时虽然持续吸热，但温度保持熔点 0℃ 不变，吸收的热量用于熔化（改变状态）而不是升高温度。

（3）水浴法加热的好处：使试管内的冰受热均匀，便于观察和记录温度，避免局部温度过高。

（4）冰熔化过程中需要吸热。冬天菜窖里放水，水凝固成冰时放出热量，使菜窖内温度不至于降得太低，从而防止蔬菜冻坏（利用凝固放热）。

（5）水沸腾后继续加热，温度保持沸点不变，不再持续升高。水沸腾的特点：①温度达到沸点并保持不变；②需要持续吸热；③内部和表面同时发生剧烈的汽化现象，产生大量气泡。
