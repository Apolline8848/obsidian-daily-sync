**🚩 百年大党正青春------105年奋斗路上的信仰接力**

2026年7月·全国

**一、素材提炼**

2026年7月1日，中国共产党迎来成立105周年。从1921年嘉兴南湖的一艘小船，到如今领航14亿人民的巍巍巨轮，这105年是一部用信仰书写的史诗。全国各地举办了形式多样的纪念活动------青年党员在革命旧址重温入党誓词，中小学生走进红色教育基地聆听前辈故事，社交平台上"#105年正青春#"话题阅读量突破30亿。值得注意的是，参与纪念活动的年轻人比例创历史新高，Z世代正以他们特有的方式传承红色基因。这启示我们：信仰不是空洞的口号，而是在一代代人的接力中不断焕新的精神力量。

**二、关联名著**

1\. 《红岩》（罗广斌、杨益言）：江姐在狱中面对敌人的严刑拷打，始终坚守信仰，那句"竹签子是竹子做的，共产党员的意志是钢铁"震撼了无数读者的心灵。这部作品展现了信仰的力量如何在极端困境中支撑一个人。\
2. 《钢铁是怎样炼成的》（奥斯特洛夫斯基）：保尔·柯察金在双目失明、身体瘫痪的绝境中，依然坚持为理想而奋斗。"人最宝贵的是生命，生命对人来说只有一次"这段独白，激励了一代又一代青年。

**三、实例案例**

2026年6月，90后退伍军人杨明被评选为"最美基层党员"。他曾在西藏边防服役8年，退役后回到贵州老家，发现山里孩子们上学需要走两小时山路。他拿出全部积蓄20万元，又四处筹款，在山村建起了一所希望小学。有人问他为什么不留在城市享受安逸生活，他说："在边防站岗的时候，我守的是国门；现在教书，我守的是孩子们的未来。都是守护，没区别。"如今，他的学校已经有了6个年级、200多名学生。杨明的故事告诉我们：信仰不需要豪言壮语，它就藏在一个人的选择里。

**六、完整范文（记叙文）**

▎爷爷的勋章\
\
爷爷有一个旧木盒子，放在衣柜最里面的角落。小时候我总想打开看看，爷爷每次都把我的手轻轻推开："等你长大了再看。"\
\
今年七一前夕，爷爷终于把盒子拿了出来。\
\
盒子里铺着一块褪了色的红布，上面整整齐齐摆着三枚勋章。一枚是抗美援朝的纪念章，一枚是"光荣在党50年"纪念章，还有一枚很小很旧的，上面刻着一颗五角星。爷爷的手有些颤抖，他拿起那枚最小的勋章，摩挲了很久。\
\
"这是1969年修的成昆铁路纪念章。"爷爷说，"那时候我刚入党三年，被派去修铁路。那里全是山，根本没有路。我们两百多号人就住在山洞里，吃的是窝窝头，喝的是山沟水。"\
\
"累吗？"我问。\
\
"累。"爷爷笑了，"累得站着都能睡着。但是没有人喊苦。你知道为什么吗？"\
\
我摇摇头。\
\
"因为我们都相信，等铁路修通了，山里的孩子就能走出去，山外的世界就能走进来。人不怕苦，怕的是吃苦没有意义。"\
\
爷爷告诉我，成昆铁路修了十二年，有上千名建设者牺牲在工地上。有一个叫马文忠的班长，在一次塌方中为了救战友被埋在了隧道里，年仅二十三岁。"我们为他立了一块碑，刻了一行字------这里睡着的人，曾为别人的路醒着。"\
\
听到这里，我的眼眶有些湿了。二十三岁，比我大不了几岁。\
\
我拿起那枚"光荣在党50年"纪念章，问爷爷："入党五十年是什么感觉？"\
\
爷爷沉默了一会儿，慢慢地说："就像种一棵树。一开始你只看到种子，看不到树。但是只要你浇水、施肥、守护它，终有一天它会枝繁叶茂。我这一辈子没有做什么大事，但我做了该做的事------在修铁路的时候修铁路，在种田的时候种田，在带孙子的时候带孙子。"\
\
"就这么简单？"\
\
"就这么简单。伟大的事业不是一个人做成的，是无数人每天做着自己该做的事，一天一天，一年一年，慢慢做成的。"\
\
那天晚上，我把爷爷的勋章小心翼翼地放回了木盒子。盒子还是那个旧盒子，但在我心里，它变得沉甸甸的。\
\
我终于明白，爷爷不让我看盒子，不是因为它藏着什么秘密，而是因为他觉得我还不够大，不足以理解那三枚勋章的分量。那不是金属的重量，而是一个人把一生交给一个信念的重量。\
\
奥斯特洛夫斯基说："人的一生应当这样度过：当他回首往事时，不因虚度年华而悔恨，也不因碌碌无为而羞耻。"爷爷做到了。他也许没有轰轰烈烈的功绩，但他的一生，就像那枚小小的铁路纪念章------安静、朴素，却在群山之间留下了一条通往远方的路。\
\
而我呢？我的勋章会在哪里？\
\
答案不在盒子里，在我将要走的路里。

**🌕 嫦娥七号即将启程------中国探月，永不止步**

2026年6月-7月·北京/文昌

2026年6月底，国家航天局宣布嫦娥七号探测器已完成总装测试，计划于2026年下半年择机发射。与以往任务不同，嫦娥七号将首次对月球南极进行高精度探测，寻找水冰资源，并为后续的月球科研站建设选址。从2007年嫦娥一号绕月飞行，到2020年嫦娥五号采样返回，再到如今瞄准月球南极------中国探月工程用了不到二十年，走完了其他国家半个多世纪的路。这背后是几代航天人"板凳甘坐十年冷"的坚守，更是一个民族对浩瀚星空的永恒向往。月球之上，不仅有环形山和月海，还有人类对未知永不熄灭的好奇心。

**二、关联名著**

1\. 《西游记》（吴承恩）：孙悟空一个筋斗云十万八千里，直达天宫------这虽然是神话，却折射出中国人对"飞天"的古老渴望。从嫦娥奔月的传说到今天的嫦娥探月工程，神话正在变成现实。\
2. 《三体》（刘慈欣）：叶文洁向宇宙发出的第一声"你好"，开启了人类与外星文明的接触。虽然嫦娥七号不寻找外星人，但它同样回答着人类最本质的问题：我们从哪里来？宇宙中有没有我们的同伴？

**三、实例案例**

嫦娥七号副总设计师周莉是一位80后女性航天科学家。2007年嫦娥一号发射时，她还是北京航空航天大学的一名大四学生，在电视前看得热泪盈眶。毕业后她考入航天五院，从最基础的轨道计算做起，一干就是十九年。她说："我们团队里有很多人三十岁出头就有了白头发。一个数据要算几十遍，一个方案要推倒重来几十次。但当探测器成功着陆的那一刻，所有的辛苦都值了。"2026年，她负责嫦娥七号的着陆导航系统设计。从月球的仰望者到月球的探索者，她用了十九年。

**六、完整范文（议论文）**

▎从"仰望星空"到"走向星空"\
\
两千多年前，屈原仰望苍穹发出天问："日月安属？列星安陈？"月亮从哪里来？星星如何排列？这些问题在当时的世人看来，大概和问"天有多高"一样没有意义。但正是这些"没有意义"的问题，推动着人类一步一步走向星空。\
\
2026年，嫦娥七号即将飞向月球南极。从屈原的《天问》到嫦娥探月，时间跨越了两千年。两千年的仰望，终于变成了两千年的抵达。\
\
有人说，探月工程投入巨大，为什么不把钱花在解决现实问题上？这个质疑听起来很"务实"，但实际上是对"探索"价值的短视。哥伦布寻找新大陆的时候，有人说他是疯子------地球上还有那么多问题没解决，为什么出海去未知的地方？可是没有哥伦布，就没有地理大发现，也就没有今天的世界格局。同样，今天我们对月球的探索，是为了明天人类能够走得更远。月球上的水冰资源可能成为深空探索的"加油站"，月球科研站可能成为人类迈向火星的中转站。今天的"无用"，往往是明天的"必需"。\
\
更重要的是，探月工程的精神价值无法用金钱衡量。当2007年嫦娥一号传回第一张月面图像时，多少中国人在电视前热泪盈眶？那不是因为月球图像本身有多美，而是因为它承载着一个民族两千年的梦想。美国登月之后，有人说了一句著名的话："这是我个人的一小步，却是人类的一大步。"这句话之所以动人，是因为它说出了探索的本质------每一个个体的努力，都在为全人类拓展认知的边界。\
\
当然，探月之路并非一帆风顺。嫦娥七号的研发团队中，很多人三十多岁就熬白了头发。一个数据算几十遍，一个方案推翻几十次------这就是航天事业的日常。荀子说："不积跬步，无以至千里。"从嫦娥一号到嫦娥七号，每一次发射都是"跬步"的积累。没有捷径，只有日复一日的计算、测试和改进。\
\
作为中学生，我们也许一辈子都不会和火箭打交道。但探月工程教给我们的东西，和学习数学、语文是一样的------那就是对未知保持好奇心，对困难保持坚韧。你解答一道几何题的过程，本质上和科学家计算轨道没有区别------都是在黑暗中摸索，都是一种探索。\
\
从"仰望星空"到"走向星空"，人类走了几千年。而我相信，这仅仅是一个开始。因为我们的征途，正如那句名言所说------是星辰大海。

**🏛️ 暑假"博物馆热"------当Z世代爱上逛博物馆**

**一、素材提炼**

2026年暑期伊始，全国各地博物馆迎来客流高峰。故宫博物院、陕西历史博物馆、三星堆博物馆等热门场馆"一票难求"，预约名额常常在放票后几分钟内被抢空。更引人关注的是，参观者中18-30岁的年轻人占比超过60%，"逛博物馆"成为年轻人社交的新时尚。社交平台上，#博物馆打卡#话题累计播放量超过200亿次。年轻人不再满足于走马观花，而是带着功课"深度游"------有人为一件青铜器专门研究了商周历史，有人为看懂一幅山水画自学了中国美术史。这波"博物馆热"折射出一个深刻变化：传统文化正在以更有趣、更可感的方式走进年轻一代的生活。

**二、关联名著**

1\. 《国家宝藏》（于蕾主编）：这部同名图书记录了央视文物纪录片中的数十件国宝故事，将高冷的文物变成了有温度的历史叙事。它证明了一件事：不是年轻人不爱传统文化，而是我们需要用年轻人喜欢的方式来讲故事。\
2. 《文化苦旅》（余秋雨）：作者以行走的方式探寻中华文明遗迹------莫高窟、都江堰、天一阁......每一处都是历史留给今天的信物。读这本书，就像跟着作者一起"逛"了一次中国文化的博物馆。

**三、实例案例**

南京外国语学校初三学生李思源是今年暑假"博物馆热"的典型代表。暑假第一周，她已经打卡了南京博物院、上海博物馆和苏州博物馆。与一般游客不同，她每到一个馆都会带上笔记本，认真记录感兴趣的文物信息。"我最喜欢南京博物院的竹林七贤砖画，上面的人物表情太生动了，好像能听到他们在聊天。"李思源说。回家后，她花了三天时间查阅资料，写了一篇三千字的文章《砖画上的魏晋风度》，被学校推荐参加全国中学生历史写作大赛。她说："博物馆让我发现，历史不是死记硬背的年份和事件，而是一个个活生生的人的故事。"

**六、完整范文（散文）**

▎与一尊青铜器对视\
\
南京博物院的青铜器展厅里，灯光很暗。一尊西周的青铜鼎静静地立在展柜中，身上的饕餮纹在幽暗的光线下显得有些狰狞。\
\
我站在它面前，隔着玻璃，隔着三千年。\
\
鼎的四条腿敦实地扎着，腹部圆鼓鼓的，两边的耳像是要飞起来的样子。最吸引我的是鼎身上的纹饰------那些弯弯曲曲的线条，有的像云，有的像雷，有的像一个瞪大眼睛的怪兽。三千年前的工匠，已经把线条掌握到了出神入化的地步。\
\
我在想，这尊鼎的第一位主人是谁呢？也许是某位诸侯，用来祭祀祖先；也许是一位将军，打了胜仗后铸造此鼎以告慰天地。每逢重大仪式，鼎里煮着整只的牛或者羊，热气腾腾，人们围着鼎跪拜、祈祷、歌唱。那时候，它是一件活着的器物，不是展柜里冷冰冰的文物。\
\
可是后来呢？也许战乱来了，主人把它埋入地下，以为过几年就能取出来。没想到一埋就是三千年。它在地下沉睡的时候，地面上发生了多少事------秦始皇统一六国，李白在对月独酌，苏轼在赤壁泛舟，我在南京的教室里背着历史课本。\
\
直到某一天，一个农民的铁锹碰到了它，叮当一声，它重见天日。\
\
"你在看什么呢？"妈妈的声音把我拉回现实，"你已经站了十分钟了。"\
\
我这才发现，周围人来人往，只有我一直没有挪步。\
\
"我在跟它聊天。"我说。\
\
妈妈笑了："它能听懂吗？"\
\
我没有回答。其实我想说，不是它能不能听懂我，而是我能不能听懂它。这尊鼎身上的每一道纹路，都是三千年前一双手留下的痕迹。那个工匠叫什么名字？没有人知道。他也许穷其一生只做了十几件青铜器，但他的作品活了三千年。\
\
余秋雨在《文化苦旅》里写道："文化的旅程是苦的，也是甜的。"我想，苦的是创造者------那些无名工匠、那些战乱中埋鼎的人、那些在博物馆里修复文物的专家；甜的是后来者------像我一样的普通人，能够在某个下午，站在一尊三千年前的鼎面前，感受到一种超越时间的连接。\
\
走出博物馆的时候，太阳正好。城市的车水马龙和三千年似乎毫不相干。但我知道，那尊鼎还在那里，安静地等着下一个与它对视的人。\
\
也许三千年后，也有人这样看着今天的东西------一部手机、一本课本、一张试卷------揣测着我们的故事。那时候他们会说些什么呢？我想，那不重要。重要的是，我们今天如何对待那些从昨天走来的东西。\
\
每一件文物都是一封写给未来的信。而我们，是收信人。

▎最好的保护是"自律"而非"他律"\
\

\
先让我们看看现实。中国超过2亿未成年网民，几乎人手一部手机。对他们来说，网络不是"虚拟世界"，而是和吃饭喝水一样自然的生活方式。用一纸禁令把网络隔在外面，就像用竹篮打水------不是打不到水，而是水会从每一个缝隙里渗进来。今天限了短视频，明天还有别的App；今天断了WiFi，明天还有移动数据。技术管控永远追不上孩子的"破解"速度。\
\

\
那么，正确的方向在哪里？\
\
我认为，应该从"他律"走向"自律"。他律是别人管你，自律是自己管自己。前者是被动的、暂时的、容易反弹的；后者是主动的、持久的、内化于心的。杭州13岁男孩小宇的故事就是一个鲜活的例子------父母没收手机没有用，但当他找到了比刷视频更有趣的事情（做航模），他自然而然地减少了屏幕时间。这说明，孩子缺的不是管控，而是更有吸引力的替代品。\
\

\
当然，这不是说保护措施完全没用。在孩子们尚未具备足够自控力的年龄段，适度的外部保护是必要的。但保护只是手段，不是目的。最终的目的，是让孩子在这片数字海洋里学会游泳，而不是永远套着救生圈。\
\
古希腊人相信"自律给我自由"。这句话放在数字时代同样适用。当一个孩子能够自觉地管理自己的屏幕时间，他的自由反而更大了------因为他不再被算法和推荐所操控，而是真正成为了自己时间的主人。\
\
最好的保护，不是给孩子筑一面高墙，而是让他自己长出判断的根。
