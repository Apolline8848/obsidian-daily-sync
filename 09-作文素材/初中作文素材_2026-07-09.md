**🚀 嫦娥七号携月背样本归来：中国航天的星辰大海**

2026年7月 \| 中国文昌航天发射场

**一、素材提炼**

2026年6月底，嫦娥七号探测器成功从月球背面南极-艾特肯盆地采集约2千克月壤样本，并安全返回地球。这是人类历史上首次从月球背面获取样本，标志着中国探月工程"绕、落、回"三步走战略圆满收官后的新突破。更令人振奋的是，嫦娥七号在月背着陆、采样、起飞、交会对接等关键环节全部实现自主化，展现了我国在深空探测领域的核心技术实力。从嫦娥奔月的古老神话到月背采样的现实壮举，中国人用二十年时间将浪漫传说变成了科学奇迹。

**二、关联名著**

《西游记》中孙悟空一个筋斗云十万八千里，象征着人类对未知世界的无限向往与勇敢探索。嫦娥七号正如现代版"筋斗云"，带我们飞跃38万公里抵达月球背面。\
《海底两万里》中尼摩船长驾驶鹦鹉螺号探索深海，与嫦娥七号探索月球背面异曲同工------都体现了人类对未知领域的好奇心与征服欲。儒勒·凡尔纳用想象预言了潜艇，而中国航天人用行动把神话变成了现实。

**三、实例案例**

2024年，来自贵州山区的15岁初三学生李明（化名），因在"全国青少年航天创新大赛"中设计了一套"月球基地生态系统模拟方案"获得一等奖，被中国航天基金会授予"航天少年之星"称号。李明从小学三年级就开始自学天文知识，用废旧纸箱搭建空间站模型。他说："嫦娥探月让我相信，山里的孩子也能仰望星空。"如今，他已立志报考航天院校。

**四、名言名句**

***❝ 我们的目标是星辰大海。 ------ 毛泽东（化用）***

***❝ 地球是人类的摇篮，但人类不能永远生活在摇篮里。 ------ 康斯坦丁·齐奥尔科夫斯基***

***❝ 路漫漫其修远兮，吾将上下而求索。 ------ 屈原《离骚》***

**五、高分立意**

【立意一｜议论文】《从"嫦娥奔月"到"月背采样"------论梦想与实干的关系》\
角度：神话是梦想的起点，科技是梦想的翅膀，实干是梦想的路径。\
适用主题：梦想、传承、实干精神\
\
【立意二｜记叙文】《那个仰望星空的少年》\
角度：以李明的故事为原型，写一个普通少年因航天梦想而改变人生的成长故事。\
适用主题：励志、成长、梦想的力量\
\
【立意三｜议论文】《民族的，也是世界的------从探月工程看中国科技的自立自强》\
角度：嫦娥七号的自主技术突破，体现关键核心技术必须掌握在自己手中的道理。\
适用主题：科技创新、自立自强、家国情怀

**六、完整范文**

**【议论文范文】《一步一个脚印，走向星辰大海》**

当嫦娥七号从月球背面带回珍贵的月壤样本时，电视机前的我热泪盈眶。那一刻我忽然明白：所有的遥不可及，都是因为还没有迈出第一步。\
\
两千多年前，屈原仰望星空发出"日月安属？列星安陈？"的天问。那时的月亮，只是诗人心中的一轮白玉盘，美丽而遥远。没有人能回答屈原的问题，因为那是一个连"科学"二字都尚未诞生的时代。但正是这样朴素的好奇心，埋下了中华民族探索宇宙的种子。\
\
二十年前，当中国宣布启动探月工程时，许多西方媒体不以为然。那时候，我们连一克月球样本都没有。但中国航天人没有争辩，他们选择了最朴素的方式------埋头苦干。从嫦娥一号到嫦娥七号，二十年如一日，每一步都走得扎实而坚定。\
\
有人问，为什么要花这么多钱去探索月球？我想起一个故事：六百年前，郑和七下西洋，有人认为那是劳民伤财。但正是那些"无用"的远航，让明朝成为当时世界上最开放、最繁荣的国家。今天的探月工程，何尝不是新时代的"下西洋"？它拓展的不仅是物理疆域，更是人类认知的边界。\
\
我最感动的，是嫦娥七号返回舱落地时，一位白发苍苍的老科学家摘下眼镜擦拭的样子。他叫叶培建，从四十岁干到七十岁，把一生中最美好的年华献给了探月事业。他说过："一个人能把一辈子献给一件有意义的事，是最大的幸福。"\
\
作为初中生，我们也许现在还做不了惊天动地的大事。但我们可以学习航天人那种"板凳甘坐十年冷"的定力，把每一道数学题当作一次"发射任务"，把每一次考试当作一次"变轨"。我们脚下虽没有发射塔，但课桌就是我们的发射台。\
\
从嫦娥奔月的神话到月背采样的现实，中国人用两千年完成了这个跨越。而我们这一代人，将接过接力棒，去攀登更远的星辰。路还在延伸，故事才刚刚开始。\
\
一步一个脚印，终将抵达星辰大海。

**示例2 \| 国内素材**

**🤖 AI走进课堂：当人工智能成为你的"学习伙伴"**

2026年7月 \| 教育部印发《中小学人工智能教育指南》

**一、素材提炼**

2026年7月初，教育部印发《中小学人工智能教育指南》，明确提出将AI素养纳入基础教育体系。与此同时，国内多所中学已引入AI助教系统：AI可以根据每个学生的答题记录分析知识薄弱点，自动生成个性化练习题；作文批改系统能在30秒内给出结构、语言、立意等多维度反馈。但争议也随之而来：有人担心学生过度依赖AI会失去独立思考能力，有人则认为AI不是替代教师，而是解放教师，让教育回归"因材施教"的本质。这场"AI+教育"的变革，正在重新定义"学习"二字。

**二、关联名著**

《论语》中孔子提出"因材施教"的教育理念------根据每个学生的不同特点给予不同指导。AI助教系统正是"因材施教"理念的技术实现：两千年前需要孔子一对一问答才能做到的事，今天AI可以在几秒钟内为千万学生完成。\
《弗兰肯斯坦》中科学家创造了超越人类的力量，却无法控制它。玛丽·雪莱的这部科幻小说提醒我们：技术本身是中性的，关键在于人类如何使用它。AI同样如此------它可以是良师益友，也可能让人失去思考能力。

**三、实例案例**

四川凉山州一所乡村中学，2025年引入AI辅助教学系统后，学生数学平均分从62分提升到78分。校长说："我们学校只有3位数学老师，要教500多个学生，根本做不到因材施教。AI帮了大忙------它发现了大量被我们忽略的『隐形学困生』。"

**四、名言名句**

***❝ 授人以鱼，不如授人以渔。 ------ 《淮南子》***

***❝ 教育不是注满一桶水，而是点燃一把火。 ------ 叶芝***

***❝ 技术是答案，但问题是什么？ ------ 凯文·凯利***

**五、高分立意**

【立意一｜议论文】《AI时代的"渔"与"鱼"------论学习能力的不可替代性》\
角度：AI可以给答案（鱼），但学会提问、学会思考（渔）才是教育的本质。\
适用主题：科技伦理、学习本质、独立思考\
\
【立意二｜记叙文】《我的AI同桌》\
角度：通过一个学生与AI助教相处的故事，展现人与技术的关系变化。\
适用主题：人机关系、成长变化、时代变迁\
\
【立意三｜议论文】《当孔子遇见算法------"因材施教"的古今之变》\
角度：对比古代和现代的因材施教，论证技术如何让古老的教育理想成为可能。\
适用主题：传统与现代、教育公平、科技向善

**六、完整范文**

**【议论文范文】《AI时代，我们更需要"人"的智慧》**

最近，一款AI作文批改软件在我的学校上线了。同学们蜂拥而上，把作文拍照上传，几秒钟就能得到分数和修改建议。一时间，"找AI改作文"成了班级新风尚。我也试了几次，分数确实涨了。但有一天，我忽然发现------我已经不会自己改作文了。\
\
这让我想起一个故事。有个年轻人找到一位老渔夫，想学捕鱼。渔夫说："我可以给你鱼，但你要学会自己捕。"年轻人嫌麻烦，就花钱买了一台自动捕鱼机。起初收获满满，但有一天机器坏了，他站在河边，手足无措。\
\
AI就像那台自动捕鱼机------它能快速给出答案，但无法教会我们思考的过程。孔子说："不愤不启，不悱不发。"意思是，学生不到冥思苦想而不得的时候，不要去开导他；不到想说却说不出来的时候，不要去启发他。教育的精髓在于那个"挣扎"的过程，而AI恰恰跳过了这个过程------它直接把鱼递到你手上。\
\
但我要说的不是AI不好。恰恰相反，我认为AI是教育史上最伟大的工具之一。在四川凉山，AI帮助乡村学生突破了师资匮乏的困境；在上海，AI让特教老师有了更多时间关注每个特殊孩子。问题是工具太好了，好到我们忘了工具永远只是工具。\
\
真正让我警醒的，是我发现自己开始变得"懒惰"。以前遇到不会的题，我会翻书、画图、反复演算------那种豁然开朗的喜悦，是任何AI都给不了的。而现在，我习惯了拍照搜题，答案来了又走了，脑子里什么也没留下。\
\
所以我想说：AI时代，我们比任何时候都更需要"人"的智慧------那种面对未知敢于探索的勇气，那种在黑暗中摸索前行的耐心，那种"我思故我在"的独立精神。\
\
愿我们都能用好AI这个工具，但不被工具所定义。愿我们都能吃到"鱼"，但更会自己"捕鱼"。因为真正的学习，从来不是输入答案，而是点燃心中的那把火。

**示例3 \| 国内素材**

**🏛️ "敦煌女儿"樊锦诗：择一事，终一生**

2026年7月 \| 敦煌研究院建院82周年

**一、素材提炼**

2026年7月，敦煌研究院迎来建院82周年。被誉为"敦煌女儿"的樊锦诗先生，从1963年北大毕业后便扎根大漠，守护莫高窟六十余载。她推动建立了"数字敦煌"工程，用3D扫描和VR技术将千年壁画永久保存，让不可移动的文物"走"出洞窟、"走"向世界。如今已近九旬的她仍心系敦煌，常说："此生命定，我就是个莫高窟的守护人。"从青春少女到白发苍苍，她用一生诠释了什么是"择一事，终一生"的匠人精神。在快节奏的现代社会，这种"慢坚持"尤为珍贵。

**二、关联名著**

《红楼梦》中曹雪芹"批阅十载，增删五次"，用一生心血写就一部不朽之作。樊锦诗同样是用一生守护一处文化遗产------都是"用时间换深度"的极致体现。\
《老人与海》中圣地亚哥老人与大鱼搏斗三天三夜，看似徒劳，却赢得了精神的胜利。樊锦诗与风沙和时间"搏斗"六十年，守护的不仅是壁画，更是文明的尊严。

**三、实例案例**

2023年，浙江杭州一名初中生张子涵因在短视频平台持续两年发布"每日一幅敦煌壁画解说"系列，累计获得50万粉丝。她最初只是因为美术课上看到飞天壁画而着迷，后来利用课余时间查阅资料、学习剪辑，将敦煌之美传递给同龄人。她说："樊奶奶用一生守护敦煌，我能做的就是让更多年轻人知道它的美。"2025年，她被评为"全国青少年文化传播之星"。

**四、名言名句**

***❝ 择一事，终一生，不为繁华易匠心。 ------ 樊锦诗***

***❝ 古之立大事者，不惟有超世之才，亦必有坚忍不拔之志。 ------ 苏轼***

***❝ 简单的事情重复做，你就是专家；重复的事情用心做，你就是赢家。 ------ 佚名***

**五、高分立意**

【立意一｜议论文】《"快时代"需要"慢坚持"------从樊锦诗看坚守的意义》\
角度：在信息爆炸、注意力稀缺的时代，专注和坚持成为最稀缺的品质。\
适用主题：坚持、专注、匠人精神\
\
【立意二｜记叙文】《我和敦煌有个约定》\
角度：以张子涵的故事为蓝本，写一个少年与文化结缘、因热爱而行动的故事。\
适用主题：文化传承、热爱、行动力\
\
【立意三｜议论文】《文明的"守"与"传"------论文化传承的当代路径》\
角度：樊锦诗是"守"的典范，张子涵是"传"的代表，两者结合才是完整的传承。\
适用主题：传承与创新、文化自信、代际对话

**六、完整范文**

**【议论文范文】《六十年的答案》**

如果有一件事，需要你做六十年，你愿意吗？\
\
1963年，25岁的樊锦诗从北大考古系毕业，被分配到敦煌。从北京到大西北，火车转汽车，一路黄沙漫天。她后来回忆说："到了敦煌，第一晚我就哭了。"不是因为感动，而是因为太苦了------没有自来水，没有电，住的是土坯房。\
\
但她没有走。这一留，就是六十年。\
\
有人不理解：以她的学历和才华，留在北京会有更好的前程，为什么要"浪费"在荒漠里？我想，答案藏在一个细节里------樊锦诗曾说，每次走进洞窟，看到那些千年壁画在昏暗的光线中若隐若现，她都觉得那是古人在对她说话。那不是工作，那是使命。\
\
这让我想到苏轼的一句话："古之立大事者，不惟有超世之才，亦必有坚忍不拔之志。"苏轼自己就是最好的例子------一生被贬谪数次，却每到一处都造福一方，留下了数不尽的诗词文章。他与樊锦诗相隔千年，却共享同一种精神：在困境中守住内心，把"苦"酿成"光"。\
\
我们这个时代，太习惯"快"了。短视频15秒抓不住注意力就划走，学习讲究"速成"，连交朋友都追求"高效社交"。我们拥有了前所未有的效率，却似乎失去了某种更重要的东西------那种愿意为一件事花很长时间的耐心。\
\
但樊锦诗告诉我们：真正有价值的东西，都需要时间来酿造。千年壁画不是在一天之内画成的，伟大的文明不是在一代人手中建立的。每一个"伟大"的背后，都是无数个"平凡"的六十年。\
\
张子涵或许不用像樊锦诗一样在大漠中守六十年，但她用两年的坚持证明了同一件事：当你真正热爱一件事时，时间就不再是消耗，而是滋养。\
\
那么，你的"六十年"是什么？也许是一道难解的数学题，也许是一本读不进去的名著，也许是一个想要放弃的爱好。试着给它多一点时间，因为答案往往不在第一秒，而在你坚持到第六十年的那个瞬间。

**示例4 \| 国内素材**

**💡 初中生发明"盲文翻译笔"：科技向善的青春力量**
