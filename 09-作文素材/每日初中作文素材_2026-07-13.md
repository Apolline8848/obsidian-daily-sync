**示例1（国内时事热点）**

**长鑫两万员工共享股权盛宴**

📍中国·安徽合肥 \| 🕐2026年7月13日

**一、素材提炼**

长鑫存储科技公司实施大规模员工股权激励计划，近两万名员工每人可分得超百万元。一家成立不到十年的芯片企业，将发展红利与全体员工共享，彰显新时代科技企业的责任担当与以人为本的发展理念。

**二、代表性人物素材（2个）**

● 范蠡（历史纵深人物）：春秋末期越国大夫，辅佐勾践复国后辞官经商，三致千金而三散之，被后世尊为"商圣"。他践行"富好行其德"的理念，将财富回报社会，是中国古代共享精神的先驱。

● 任正非（当代精神标杆）：华为创始人，坚持"以奋斗者为本"的全员持股制度，将公司98.6%的股份分配给员工。他说过："华为没有成功，只有成长。"让每一位奋斗者都能共享企业发展成果。

**三、相关名著（2部）**

● 《史记·货殖列传》，司马迁（约前145---约前86），西汉史学家。记载范蠡等商人"富而好行其德"的故事，揭示财富共享的古老智慧。

● 《红星照耀中国》，埃德加·斯诺（1905---1972），美国记者。记录延安时期"官兵一致、同甘共苦"的分配制度，展现集体主义精神的源头。

**四、名言警句汇总（5条）**

● 不患寡而患不均，不患贫而患不安。------《论语·季氏》（白话：不担心财富少，而担心分配不均；不担心人口少，而担心社会不安定。）

● 富与贵，是人之所欲也；不以其道得之，不处也。------《论语·里仁》

● 财聚则民散，财散则民聚。------《大学》

● 一个人的价值，应该看他贡献什么，而不应当看他取得什么。------爱因斯坦

● 企业家的血管里要流淌着道德的血液。------温家宝

**五、高分立意（3个）**

立意1：共享发展成果是最大的凝聚力

可用写作角度：从长鑫科技的股权激励出发，论述共享如何激发创造力与归属感，可联系共同富裕的时代主题。

立意2：以人为本是企业长青之道

可用写作角度：对比榨取型与共享型两种企业治理模式，论证尊重劳动者价值才能赢得长远发展。

立意3：财富的终极价值在于利他

可用写作角度：从范蠡散财到当代企业家公益慈善，探讨财富伦理------拥有财富是为了更好地回馈社会。

**六、高分作文应用示例**

作文题目：《共享，让奋斗更有温度》

作文类型：议论文

近日，长鑫存储两万名员工每人分享超百万元股权激励的消息，在网络上引发热议。一家成立不到十年的芯片企业，在攻坚克难之际，没有将利润悉数装进少数人的口袋，而是让每一位奋斗者都成为企业成长的受益者。这让我深深思考：共享，究竟意味着什么？\
\
共享，首先是一种格局。古人云："财聚则民散，财散则民聚。"两千多年前，《大学》中的这句话便道破了财富分配与人心向背的关系。春秋时期的范蠡，辅佐越王勾践成就霸业后，三致千金而三散之。他不是不懂得财富的价值，而是懂得一个更深刻的道理：财富如活水，流动方能滋养万物；若只进不出，终成死水一潭。长鑫科技的选择，正是这种大格局的当代映照------当企业与员工共享发展红利，每一位员工便从"打工人"变成了"合伙人"，从谋生走向了共荣。\
\
共享，更深层次地看，是对劳动价值的真正尊重。华为创始人任正非曾说："华为没有成功，只有成长。"这家坚持全员持股的公司，将98.6%的股份分给了员工。在华为，扫地阿姨也可能持有公司股份。这不是施舍，而是承认------每一滴汗水都有价值，每一位奋斗者都值得被看见。埃德加·斯诺在《红星照耀中国》中描述了延安时期"官兵一致、同甘共苦"的场景，那种朴素而坚定的分配理念，正是中国革命赢得民心的关键所在。今天，当科技企业的股权激励从高管专属走向全员覆盖，我们看到的是一种更高级的文明形态：让创造价值的人分享价值。\
\
当然，共享不是平均主义。真正的共享，是在承认贡献差异基础上的公平分配。爱因斯坦说得好："一个人的价值，应该看他贡献什么，而不应当看他取得什么。"一个有活力的社会，既需要让奋斗者获得与其贡献匹配的回报，也需要守住基本公平的底线。共享的本质，是在效率与公平之间找到动态平衡。长鑫的股权激励，既是对技术骨干的肯定，也是对所有坚守岗位员工的认可------这种"有差别的共享"，恰恰是最可持续的模式。\
\
回望历史，放眼世界，那些基业长青的企业，往往都是共享理念的践行者。从范蠡的三致千金而三散之，到华为的全员持股，再到今天长鑫科技的股权盛宴，共享精神穿越千年而不衰。因为它触动了人性中最朴素也最深刻的渴望------被尊重、被看见、被公平对待。当每一个奋斗者都能在共享中感受到温度，这个社会的创造力便会如春泉般奔涌不息。

**示例2（国内时事热点）**

**海南率先迈入零燃油时代**

📍中国·海南 \| 🕐2026年7月13日

**一、素材提炼**

海南正式确认成为中国首个禁售燃油车的省份，明确2030年起全面禁售燃油汽车。作为国家生态文明试验区，海南以先行者的姿态，为中国交通领域的绿色革命迈出里程碑式的一步。

**二、代表性人物素材（2个）**

● 贾思勰（历史纵深人物）：北魏著名农学家，著《齐民要术》，主张"顺天时，量地利"，强调人与自然的和谐共生。他提出的顺应自然规律的思想，是中国人绿色生态观的早期源头。

● 王传福（当代精神标杆）：比亚迪创始人，2003年跨界造车，押注新能源汽车赛道。二十余年间，他将一家电池小厂做成全球新能源汽车销量冠军，用行动证明中国企业在绿色转型中不仅可以跟随，更可以引领。

**三、相关名著（2部）**

● 《昆虫记》，法布尔（1823---1915），法国昆虫学家。以细致入微的观察展现自然界的精妙平衡，提醒人类敬畏自然、顺应生态规律。

● 《寂静的春天》，蕾切尔·卡森（1907---1964），美国海洋生物学家。首次揭示化学农药对生态的毁灭性破坏，唤醒全球环保意识，是绿色运动的奠基之作。

**四、名言警句汇总（5条）**

● 天行有常，不为尧存，不为桀亡。应之以治则吉，应之以乱则凶。------《荀子·天论》（白话：自然运行有其规律，不会因为圣君而存在，也不会因为暴君而消亡。顺应规律行事就吉祥，违背规律就遭殃。）

● 竭泽而渔，岂不获得？而明年无鱼。------《吕氏春秋》

● 我们不是从祖先那里继承了地球，而是从子孙那里借来的。------印第安谚语

● 绿水青山就是金山银山。------习近平

● 人类是自然之子，而非自然之主。------蕾切尔·卡森

**五、高分立意（3个）**

立意1：取之有度、用之有节才是发展正道

可用写作角度：从禁售燃油车的减法思维切入，论述真正的进步不是无限索取，而是学会克制与平衡。

立意2：先行者的勇气与担当

可用写作角度：海南作为首个禁售燃油车省份，承担了探索成本与不确定性风险，这种"敢为天下先"的精神值得书写。

立意3：绿色转型是一场文明的自我革命

可用写作角度：从汽车百年史到电动化浪潮，论证每一次能源革命背后都是人类文明价值观的重塑。

**六、高分作文应用示例**

作文题目：《为未来留一片蓝天》

作文类型：文化散文

海南，这个被南海环抱的热带岛屿，又一次走在了时代的前列。2030年禁售燃油车------这一纸公文，看似只是一项产业政策，实则是一个省份、一个国家对自己未来的庄严承诺。当我读到这则新闻时，脑海中浮现的，是千年之前一位农学家在田间地头写下的朴素箴言。\
\
"顺天时，量地利。"北魏贾思勰在《齐民要术》中写下的这六个字，道尽了中国农耕文明最核心的生存智慧。种地要看天，用地要量力，这是祖先用几千年摸索出来的真理。然而进入工业时代后，我们似乎渐渐忘记了这条古训。汽车尾气遮蔽了蓝天，石油开采撕裂了大地，我们以"发展"的名义向自然无止境地索取，却忘记了《吕氏春秋》中的警告："竭泽而渔，岂不获得？而明年无鱼。"\
\
法国昆虫学家法布尔，用一生观察那些微小生命的生存智慧。在《昆虫记》中，螳螂捕食却不滥杀，蜜蜂采蜜却为花朵传粉------自然界中没有绝对的征服者，只有精妙的平衡。人类曾经以为自己是这种平衡的例外，直到蕾切尔·卡森用一本《寂静的春天》敲响了警钟。她写道："人类是自然之子，而非自然之主。"当春天不再有鸟鸣，再繁荣的城市也不过是一座寂静的坟墓。\
\
幸运的是，觉醒正在发生。王传福，这位从电池起家的中国企业家，在二十年前做出了一个被当时所有人视为"疯狂"的决定------跨界造电动车。如今，比亚迪已成为全球新能源汽车的销冠。这不是一个企业的胜利，而是一种理念的胜利：经济发展与环境保护从来不是非此即彼的零和博弈。"绿水青山就是金山银山"，这句简单而深刻的话语，正在从理念变为现实。\
\
海南的选择，让我想起一句印第安谚语："我们不是从祖先那里继承了地球，而是从子孙那里借来的。"禁售燃油车，不是剥夺我们的选择权，而是为子孙后代保留选择的权利------选择呼吸清洁空气的权利，选择仰望蔚蓝天空的权利，选择在绿色星球上安居乐业的权利。\
\
站在2026年的夏天，眺望2030年的海南，我仿佛看见：碧海蓝天之下，电动车悄无声息地穿行于椰林之间，空气中有海风的咸味，也有花朵的清香。那将是一幅怎样的图景？我想，那正是我们这一代人为未来留下的，最珍贵的礼物。

**示例3（国内时事热点）**

**海上风电点亮绿色未来**

📍中国·福建平潭 \| 🕐2026年7月13日

**一、素材提炼**

福建平潭海上风电场持续输送绿电，凭借台湾海峡丰富的风力资源，成为我国东南沿海清洁能源的重要基地。一排排巨型风机在海天之间转动，将海风化为源源不断的清洁电力。

**二、代表性人物素材（2个）**

● 张衡（历史纵深人物）：东汉科学家，发明地动仪与浑天仪，是最早利用自然力为人类服务的先驱之一。他对自然规律的敬畏与探索，奠定了中国古代科技文明的基石。

● 黄大年（当代精神标杆）：著名地球物理学家，放弃英国优厚待遇回国效力，带领团队在深地探测领域取得突破。他将毕生精力献给祖国的科技事业，直到生命最后一刻。

**三、相关名著（2部）**

● 《海底两万里》，儒勒·凡尔纳（1828---1905），法国科幻作家。以超凡想象力描绘人类利用海洋能源的图景，是对未来清洁能源的浪漫预言。

● 《钢铁是怎样炼成的》，奥斯特洛夫斯基（1904---1936），苏联作家。保尔修铁路时燃烧生命的热忱，与当代建设者为清洁能源事业劈波斩浪的精神一脉相承。

**四、名言警句汇总（5条）**

● 天行健，君子以自强不息。------《周易》（白话：天道运行刚健有力，君子应当效法天道，自强不息。）

● 大鹏一日同风起，扶摇直上九万里。------李白《上李邕》

● 能源是文明的血液。------丹尼尔·耶金

● 世界上最快乐的事，莫过于为理想而奋斗。------苏格拉底

● 一个人把自己献给某种事业时，是没有什么能阻止他的。------黄大年

**五、高分立意（3个）**

立意1：向自然借力，是人类最聪明的选择

可用写作角度：从古人利用风力行船到今日海上风电，论述人类与自然的关系不是征服而是合作。

立意2：艰苦环境中的奋斗最美

可用写作角度：海上风电建设者面对台风、巨浪、孤寂，仍坚守岗位，这种"风中逐梦"的精神值得礼赞。

立意3：绿色能源是可持续发展的"中国方案"

可用写作角度：从平潭风电看中国在全球能源转型中的角色------不仅是参与者，更是贡献者与引领者。

**六、高分作文应用示例**

作文题目：《风从海上来》

作文类型：文化散文

站在平潭的海岸边，我望着那一排排在海天交接处缓缓旋转的白色风机，忽然想起李白的诗句："大鹏一日同风起，扶摇直上九万里。"古人用诗意的想象描摹乘风而行的壮阔，而今天，我们真的让风扶摇而上，化作了点亮千家万户的电流。\
\
风是什么？《周易》说："天行健，君子以自强不息。"天道运行刚健有力，君子当效法自然，自强奋进。风，正是天道运行最生动的意象------看不见、摸不着，却蕴藏着无穷的力量。东汉的张衡，那个发明了地动仪的天才，一定也曾在某个起风的夜晚仰望星空，思考着如何将自然的伟力转化为人类的福祉。两千年的时光流转，我们终于在平潭的海面上，为这个古老的问题找到了现代的答案。\
\
儒勒·凡尔纳在《海底两万里》中，曾幻想过一个完全依靠海洋提供能源的未来世界。那时的读者大概觉得这只是科幻作家的天方夜谭。然而今天，当平潭的风机在海风中日夜旋转，凡尔纳的幻想正在变成现实。科幻与现实的边界，从来都是由那些敢于做梦又敢于实干的人打破的。黄大年，这位从英国归来的地球物理学家，把毕生精力献给了祖国的科技事业。他说："一个人把自己献给某种事业时，是没有什么能阻止他的。"平潭海上的那些建设者们，何尝不是如此？他们迎着台风出海检修，在摇晃的平台上度过一个个不眠之夜，用血肉之躯守护着那一台台海上大鹏。\
\
我忽然想起《钢铁是怎样炼成的》中那个在暴风雪中修铁路的保尔·柯察金。他燃烧着自己的生命，为苏维埃的建设事业奉献一切。今天，在远离大陆的风电平台上，同样有一群保尔，他们用自己的坚守，为中国能源转型这场伟大的建设事业添砖加瓦。苏格拉底说："世界上最快乐的事，莫过于为理想而奋斗。"他们或许不善言辞，但那一台台迎风转动的风机，就是他们对理想最好的告白。\
\
风从海上来，带着远古的吟唱，也带着未来的消息。当我们拧开电灯，空调送来凉风，电脑屏幕亮起------请记得，在遥远的海平面上，有一群人正与风共舞，为这个国家输送着最清洁的力量。

**示例4（国内时事热点）**

**台风中守望相助的普通人**

📍中国·沈阳 \| 🕐2026年7月12日---13日

**一、素材提炼**

超强台风巴威北上影响东北地区，沈阳遭遇百年一遇特大暴雨，全城停课停工停产停运。在这场极端天气中，无数普通人挺身而出------社区干部逐户排查、志愿者转移老人、居民互助送餐，诠释了守望相助的城市温度。

**二、代表性人物素材（2个）**

曼德拉曾说："和平不能靠宣言来维持，只能靠行动来争取。"外交不只是在谈判桌上的唇枪舌剑，更是千千万万普通人跨越语言和文化的真诚相待。阿努廷总理此次访华，或许会签署一系列合作协议，但真正让中泰"一家亲"的，是那些不写在纸上却刻在心中的东西：一个微笑，一次握手，一句"萨瓦迪卡"。\
\
远亲不如近邻。这句中国的老话，道出了国际关系中最朴素的真理。愿中国的每一个邻居，都是真正的朋友。

\
蒙巴萨港口，巨大的集装箱像积木一样堆叠在海岸线上。父亲指着一条崭新的铁轨说："这就是蒙内铁路，中国人修的。"语气中满是骄傲。一列火车正缓缓驶出港口，车厢里装的是从中国运来的日用品------塑料拖鞋、太阳能灯、手机配件。父亲告诉我，因为零关税政策，这些商品的价格在肯尼亚市场下降了近三分之一。"一个当地工人一个月的工资，以前只能买一双鞋，现在能买三双。"\

在蒙巴萨的市场里，我遇到了一个叫约瑟夫的咖啡种植户。他的咖啡豆通过零关税政策出口到中国，收入比三年前翻了一倍。他用不太流利的英语告诉我，他刚给女儿交了中学学费，下一个目标是给家里装太阳能板。"中国人是我们的朋友，"他笑着说，"你们修铁路，我们卖咖啡。"\
\
这句朴素的话，让我想起了两千年前的张骞。当他第一次出使西域，经历被匈奴俘虏、沙漠迷失、食粮断绝的艰险时，支撑他走下去的也许正是这个简单的信念：远方的人们需要沟通，需要交换，需要成为朋友。丝绸之路从来不是单向的输出，而是双向的奔赴------中国的丝绸去了罗马，罗马的玻璃来了长安。今天，蒙内铁路上奔流不息的，是同样的逻辑：零关税让每个人都有机会参与这场文明的对话。\
\
非洲有一句谚语："我们想要的不是施舍，而是公平贸易的机会。"十六世纪到二十世纪，这片大陆经历了长达四百年的殖民掠夺，数千万人被贩卖为奴，无数的黄金、钻石、象牙被运往欧洲。那种"我给你一顶帽子，你给我一座金矿"的所谓贸易，与今日中非之间的零关税合作有着天壤之别。袁隆平的杂交水稻在非洲推广种植，马达加斯加人将他的头像印在了纸币上------这是对"合作而非掠夺"的最高礼赞。\
\
孔子说："德不孤，必有邻。"中国在非洲获得的尊重和友谊，不是靠枪炮赢来的，而是靠一条条铁路、一座座港口、一颗颗水稻种子换来的。这种友谊不喧哗，却最坚实；不张扬，却最持久。\

站在蒙巴萨港的栈桥上，晚霞将印度洋染成了金色。远处又一列中国造的列车鸣笛启程。我想，这汽笛声回荡的，不仅是东非运输大动脉的繁忙，更是一个古老民族与一个年轻大陆相约未来的誓言。

国际乒联宣布恢复俄罗斯运动员参赛资格的那天，我正在刷着世界乒乓球锦标赛的集锦。屏幕上，中国选手马龙与德国选手奥恰洛夫激战正酣，两人的汗水在灯光下闪闪发光。那一刻我忽然想到：在这张球台前，国籍重要吗？\

\
