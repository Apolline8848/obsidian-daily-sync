**示例1 \| 国内素材**

**🎓 一纸录取通知书，万千青春路------2026高考录取季的思考**

2026年7月·全国

**一、素材提炼**

2026年7月初，全国高考录取工作全面展开，首批录取通知书正陆续送达考生手中。今年全国高考报名人数约1342万，录取率预计超过80%。值得关注的是，职业本科招生规模继续扩大，越来越多的高分考生主动选择职业教育路径，"技能成才"正在摆脱"退而求其次"的标签。与此同时，一些没有被理想院校录取的考生，也在复读、出国、创业等多条赛道上寻找自己的方向。高考录取通知书不是人生的判决书------它只是一张车票，而旅程才刚刚开始。真正的考场，从来不是那间教室，而是此后漫长的人生。

**二、关联名著**

1\. 《平凡的世界》（路遥）：孙少平高考落榜后，没有自暴自弃，而是走进煤矿、走进城市，在劳动中找到了生活的意义。路遥写道："生活包含着更广阔的意义，而不在于我们实际得到了什么。"这恰是对高考录取季最好的注脚。\
2. 《骆驼祥子》（老舍）：祥子三次失去自己的车，每一次打击都几乎摧毁他。但从另一个角度看，祥子的悲剧不在于命运的多舛，而在于他在打击面前放弃了向上的努力。这对落榜考生是一个反向警示：跌倒不可怕，可怕的是不再爬起来。

**三、实例案例**

2025年，湖南农村女孩刘雨欣以628分的成绩被北京大学录取。但鲜为人知的是，她初二时因为家庭变故差点辍学------父亲病重，母亲一人打三份工。班主任家访时说了一句话："雨欣，你不需要用北大的录取通知书来证明自己，你需要的是不管上什么学校，都能昂着头走下去的勇气。"这句话让她坚持了下来。她说："我考上北大不是因为聪明，是因为在最困难的时候，有人告诉我------你比一张录取通知书重要得多。"如今大一结束，她正在准备支教项目，暑假将回到家乡为留守儿童补课。

**四、名言名句**

***"生活包含着更广阔的意义，而不在于我们实际得到了什么。"------路遥《平凡的世界》***

***"胜败兵家事不期，包羞忍耻是男儿。"------杜牧《题乌江亭》***

***"人生的道路虽然漫长，但紧要处常常只有几步，特别是当人年轻的时候。"------柳青***

**五、高分立意**

【立意一·议论文】《录取通知书之外的人生》------论证高考成绩不能定义一个人的全部价值，批判"一考定终身"的社会偏见，提出多元成才观。关键词：多元评价、终身学习、自我价值。\
【立意二·记叙文】《七月的那封信》------以一封录取通知书（或落榜信）为线索，写一个少年面对人生转折时的心路历程。关键词：转折、成长、选择。\
【立意三·散文】《夏天的分岔口》------以高考后的夏天为背景，用诗意的语言描绘青春的迷茫与希望，思考什么才是真正重要的"录取"。关键词：青春、迷茫、希望。

**六、完整范文（记叙文）**

▎七月的那封信\
\
七月四日，晴。\
\
邮递员老李的电瓶车停在我家门口时，我正在院子里剥毛豆。他递过来一个牛皮纸信封，上面印着蓝色的校名。我的心跳到了嗓子眼。\
\
拆信的时候，手在发抖。\
\
妈妈站在三步远的地方，不敢靠近，也不敢离开。她是怕我看到结果后的任何一种表情，都会让她先于我承受痛苦。\
\
信纸抽出来了。第一行字是"经审核，你未被我校录取"。\
\
接下来的字我都没看清。世界忽然安静了，连院子里的蝉鸣都消失了。只有那句话，一遍一遍地在我脑子里回放：未被录取，未被录取，未被录取。\
\
那是我的第一志愿，一所211大学的中文系。差了三分。\
\
妈妈看到了我的表情，轻轻走过来，想抱我。我躲开了。"我没事。"我说。但声音是哑的。\
\
那天晚上我躺在床上一夜没睡。脑海里像放电影一样闪过这三年的画面：凌晨五点半的闹钟，堆满书桌的卷子，陪我熬夜的台灯，还有贴在墙上的那张便利贴------"你一定可以的！"现在看起来，那张便利贴像一个笑话。\
\
第二天早上，爸爸把我叫到阳台。他点了两根烟，递给我一根------这是第一次。我愣了一下，接过来，但没点。\
\
"你知道我当年高考考了多少分吗？"爸爸问。\
\
"不知道。"\
\
"312分。差专科线两分。"他弹了弹烟灰，"那时候高考比现在难多了，312分在我们村算中上等。但还是没学上。"\
\
"后来呢？"\
\
"后来我去学了木匠。在师傅家住了三年，从拉大锯开始，一点一点学。现在我有一个小家具厂，二十几个工人，日子不也过得挺好？"爸爸看着远方，语气很平静，"我想说的是，一张录取通知书决定不了你的人生。它只是一张纸，不是你的命。"\
\
我沉默了。\
\
"你有两条路，"爸爸继续说，"复读一年，再考一次；或者去第二志愿，好好读。无论选哪条，爸爸都支持你。但有一条路你不能走------那就是放弃。"\
\
那天下午，我翻出了第二志愿的录取通知书。那是一所普通的省属师范大学。我把两张通知书并排放在桌上，看了很久。\
\
然后我拿起手机，给班主任发了一条微信："老师，我决定去读师范。"\
\
老师秒回了："为什么？"\
\
我打了又删，删了又打，最后只发了四个字："我想教书。"\
\
是的，我想教书。想当一个像班主任那样的人------在每一个迷茫的少年面前，告诉他：你比任何一张录取通知书都重要得多。\
\
七月的阳光很烈，但我心里忽然凉快了下来。我把那张差三分的通知书折好，放回了信封里。不是丢掉，是收好。它是我人生中的第一封"落榜信"，但不会是最后一封"转折信"。\
\
路遥在《平凡的世界》里写过一句话："生活包含着更广阔的意义，而不在于我们实际得到了什么。"\
\
那封信让我没有得到理想中的大学，但它让我得到了一个更重要的东西：一份关于自己的确认。\
\
七月的那封信，不是终点，是起点。

**🌡️ 40°C下的坚守------极端高温中那些被汗水浸透的身影**

2026年6月-7月·全国多地

**一、素材提炼**

2026年入夏以来，我国多地遭遇罕见高温天气。华北、黄淮地区连续多日气温突破40°C，上海、杭州等城市打破历史同期最高气温纪录。当大多数人在空调房里避暑时，有一群人必须在烈日下坚守岗位：交警的制服湿了又干、干了又湿；外卖骑手在热浪中穿梭，平均每天骑行上百公里；环卫工人凌晨四点就开始清扫街道，只为了在太阳暴晒前完成工作。他们的汗水，换来了城市的正常运转。高温不仅是一道气象题，更是一道人性题------考验着一个社会如何对待那些被太阳"选中"的劳动者。

**二、关联名著**

1\. 《骆驼祥子》（老舍）：祥子在北平的烈日下拉车，汗如雨下，只为攒钱买一辆属于自己的车。老舍用细腻的笔触描绘了底层劳动者在酷暑中的挣扎------"太阳西斜了，河上的老柳歪歪着，梢头挂着点金光。没有风，一切是静止的。"这种对劳动者处境的深切关怀，才是文学的温度。\
2. 《卖炭翁》（白居易）："可怜身上衣正单，心忧炭贱愿天寒。"卖炭老人在寒冬中盼天更冷一些，好把炭卖出去。这种底层劳动者身处"两难"处境的描写，与今日高温下的户外工作者形成跨时空的呼应。

**三、实例案例**

在杭州，41岁的环卫工人赵大姐在高温中的故事被路人拍下后走红网络。视频里，她蹲在树荫下，用一瓶晒得温热的水浇在额头上降温。记者找到她时，她正在扫落叶。记者问："这么热的天，为什么不请个假？"赵大姐笑了笑："我请假了，这条街谁扫？几百米的路，一天不扫就全是垃圾。再说了，我习惯了，就当是免费蒸桑拿。"她的丈夫也是环卫工人，夫妻俩负责相邻的两条街，每天凌晨三点半出门，中午在路边的环卫驿站休息两个小时。她说，今年夏天，驿站里装了空调，还发了防暑药，"比以前好多了"。赵大姐的故事让很多人破防------"原来我们每天走过的干净街道，是有人在用汗水冲洗。"

**四、名言名句**

***"足蒸暑土气，背灼炎天光。力尽不知热，但惜夏日长。"------白居易《观刈麦》***

***"哪有什么岁月静好，不过是有人替你负重前行。"------网络流行语（苏心）***

***"劳动是产生一切力量、一切道德和一切幸福的威力无比的源泉。"------拉·乔乃尼奥里***

**五、高分立意**

【立意一·议论文】《被太阳"选中"的人》------从高温下的劳动者切入，论证劳动尊严和社会关怀的重要性，提出"尊重劳动者不能只在朋友圈转发"。关键词：劳动尊严、社会关怀、同理心。\
【立意二·记叙文】《汗水里的夏天》------以一名高温下的劳动者（环卫工、交警、外卖员等）为原型，写一个关于坚守与付出的故事。关键词：坚守、付出、平凡英雄。\
【立意三·散文】《阳光的重量》------以"阳光"为核心意象，从自然的酷热引申到人与人之间的温情，用对比手法展现城市的冷暖两面。关键词：温度、温情、城市。

**六、完整范文（记叙文）**

▎汗水里的夏天\
\
那个夏天，我记住了汗水的味道。\
\
中考结束的那个暑假，爸爸说："你大了，该去体验体验生活。"于是我被送到了城东的建筑工地，跟着李叔当小工。李叔是个四十多岁的中年人，皮肤黑得像涂了酱油，笑起来牙齿格外白。\
\
第一天，杭州的气温是42°C。\
\
工地上没有任何遮挡，阳光像刀子一样扎在身上。我搬了不到十块砖，衣服就湿透了。汗顺着额头流到眼睛里，火辣辣的疼。李叔递给我一条毛巾："擦擦。"他的毛巾已经能拧出水来。\
\
中午吃饭的时候，我瘫坐在地上，一口也吃不下。盒饭里的红烧肉看着就腻。李叔把自己的饭吃得干干净净，还喝了一大瓶水。"你得多吃，"他说，"下午还有四个小时。"\
\
"李叔，"我问，"你不觉得苦吗？"\
\
李叔愣了一下，笑了："苦？习惯了就不觉得了。你看这楼------从地基到封顶，每一块砖我都摸过。等它盖好了，就有人住进去，有的人结婚生子，有的人送孩子上学。这个城市就是这样一点一点长起来的。我们这些人，就是城市的砖。"\
\
我看着他被晒得发红的脸，心里忽然有点堵。\
\
下午两点，太阳最毒的时候，工头喊大家休息半小时。所有人都挤在那片唯一有阴影的墙根下。有人靠着墙打盹，有人用安全帽扇风，有人拿出手机看孩子的照片。李叔给我看了他家闺女的照片------一个扎马尾的小姑娘，笑得像一朵向日葵。\
\
"闺女今年上初中了，"李叔说，"成绩可好了，班里前三。我得给她攒学费。"他的声音里有一种说不出的温柔。\
\
那一天，我搬了不知多少块砖，流了不知多少汗。回家的时候，两条胳膊像灌了铅。妈妈心疼得直念叨："你爸也真是的，让一个孩子去工地......"\
\
但我没有抱怨。\
\
因为我知道了，这个城市的地铁每天准时运行，是因为有人凌晨在检修轨道；街道干净整洁，是因为有人在太阳出来前就扫完了垃圾；高楼拔地而起，是因为有人用肩膀扛起了每一块砖。\
\
白居易在《观刈麦》里写："足蒸暑土气，背灼炎天光。力尽不知热，但惜夏日长。"一千多年前的农夫在烈日下割麦，一千多年后的建筑工人在烈日下砌墙。时代变了，但汗水咸度没变。\
\
那个夏天过后，我每次看到马路上穿橙色工作服的环卫工人，都会认真地说一声"辛苦了"。每次接过外卖时，都会说一声"谢谢"。我知道，在那些汗水的背后，有一个女儿在等爸爸回家，有一个孩子在期待下学期的学费。\
\
汗水里的夏天教会我的，不是如何搬砖，而是如何看待那些搬砖的人。\
\
阳光总是公平地照在每个人身上，但有些人承受的重量，比阳光更重。

**🏛️ 排队一小时，看展五分钟------暑假"博物馆热"背后的文化觉醒**

2026年7月·全国

**一、素材提炼**

2026年暑假刚刚开始，全国各大博物馆迎来参观高峰。故宫博物院、国家博物馆、三星堆博物馆等热门场馆预约票"秒光"，一些网红展览甚至需要排队一小时才能看上五分钟。与此同时，"博物馆里过暑假"成为社交平台上的热门话题，"#带着课本逛博物馆#"话题阅读量突破20亿。值得注意的是，这波"博物馆热"的推动者以95后、00后为主力------他们不再是走马观花地"打卡"，而是真的在展柜前驻足、阅读解说牌、用手机查询文物背后的故事。从"逛博物馆"到"懂博物馆"，这种变化折射出年轻一代对中华文化从"知其然"到"知其所以然"的深层渴望。

**二、关联名著**

1\. 《文化苦旅》（余秋雨）：余秋雨以脚步丈量中国文化的遗迹，从敦煌莫高窟到都江堰，从岳麓书院到天一阁。他在书中写道："文化是一种时间的积累，但也有责任通过我们的脚步去丈量。"博物馆热正是这种"用脚步丈量文化"的现代表达。\
2. 《红楼梦》（曹雪芹）：大观园中的器物、书画、园林布局，处处渗透着中国传统文化的审美。曹雪芹不厌其烦地描写"软烟罗"的四种颜色、"慧纹"的绣工------这种对物之美的珍视，与博物馆中人们对文物的凝视如出一辙。

**三、实例案例**

南京的中学生陈思远是"博物馆少年"的代表。他从小学五年级开始，利用周末和假期走遍了全国40多家博物馆，手绘了200多幅文物速写。他把自己最喜欢的青铜器画成了一本小册子，取名《与三千年前对话》，在学校里传阅。2026年暑假，他的画作被南京博物院选中，做成了文创明信片。记者采访他时，他说："我画画不是为了好看，是为了记住。每画一笔，我都在想------三千年前做这个鼎的人，他的手是不是也像我这样用力？博物馆让两个不同时空的人，通过一件器物产生了联系。"

***"一个忘记来路的民族，是没有出路的民族。"------习近平***

**五、高分立意**

\

\
蕾切尔·卡森说："我们不是继承了地球，而是借用了子孙的地球。"对于海洋，这句话同样适用。我们借用了这片蔚蓝，将来要还给我们的孩子。还给他们的时候，我们希望看到的是游鱼成群、珊瑚绚烂，还是一片寂静的荒芜？\
\
答案，就在我们今天的每一次选择里。

**六、完整范文（议论文）**

▎当AI能写出满分作文，我们还要学写作吗？\
\
上个周末，我让AI帮我写一篇以"勇气"为主题的作文。\
\
三秒钟，一篇800字的文章就出现在屏幕上。有排比句，有名人名言，有起承转合，看起来简直是一篇完美的中考范文。我读了一遍，觉得很棒；读第二遍，觉得哪里不对；读到第三遍，我终于发现了问题------这篇文章什么都好，就是没有"我"。\
\
这件小事引发了我一个更大的思考：当AI能写出满分作文，我们还要学写作吗？\
\
我的答案是：要。而且比以往任何时候都更需要。\
\
首先，AI写的作文是"拼凑"出来的，而不是"感受"出来的。AI可以在几毫秒内搜索几亿篇文章，把最好的句子组合在一起。但它不知道什么是摔倒时膝盖上的刺痛，不知道什么是毕业时抱着好朋友哭得说不出话的感觉，不知道深夜一个人对着满天星星发呆的那种孤独。而这些------这些真实的感受------才是写作的灵魂。\
\
孔子说："学而不思则罔，思而不学则殆。"两千五百年前的话，放在今天依然精准。AI可以替代"学"的部分------它可以记住人类所有的知识，比任何一个人都博学。但它替代不了"思"------那种基于自身经历和生活体验的独立思考。而写作的本质，不是把句子写漂亮，是把思想写清楚。\
\
其次，学习写作的过程，其实就是学习思考的过程。当你坐下来认真写一篇文章的时候，你需要理清自己的思路、组织素材、选择表达方式------这个"烧脑"的过程比任何AI生成的"完美"文章都更有价值。就像跑步机再先进，也替代不了真正在路上跑步的感觉------你的肌肉在用力，你的心脏在跳动，你的汗水在流淌。写作也是一样，真正有价值的是你在写的过程中经历的挣扎和突破。\
\
当然，我不是说我们应该拒绝AI。AI是一个很棒的工具，可以帮我们查资料、改语法、找灵感。但工具终究是工具。就像计算器帮我们算数学题，但我们仍然要学算术一样------因为算术教会我们的不是答案，而是逻辑。写作教给我们的也不是排比句，而是如何成为一个有独立思想的人。\
\
北京的小学生陈曦在试过AI写作文之后说了一句话："AI可以写一篇完美的作文，但它写不出我第一次骑自行车摔倒时膝盖上的那道疤。"\
\
那道疤，就是人之所以为人的证明。\
\
所以，当AI能写出满分作文的时候，我们更需要学会写作------不是为了写出比AI更好的文章，而是为了成为一个比AI更完整的人。\
\
苏格拉底说："教育的本质不是灌输，而是点燃火焰。"AI可以灌输知识，但只有人，才能点燃另一个人心中的火焰。\
\
而写作，正是点燃这种火焰的方式之一。
