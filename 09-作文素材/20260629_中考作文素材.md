案例一：王定国（1913-2020），长征中的女红军，谢觉哉夫人。她在长征中三过草地，新中国成立后仍积极投身社会公益事业，享年107岁。她晚年常说：「长征教会我的，是一辈子都不怕困难。」\

**题目：让记忆发光**

\
八十多年前，她还是一个十几岁的川妹子，穿着草鞋，踏上了那条被后人称为「奇迹」的道路。雪山上的寒风如刀割，草地里的沼泽深不见底。三百六十八个日日夜夜，两万五千里行程------这不是一串冰冷的数字，而是无数如她一样的年轻人用热血写下的史诗。\
\
历史有时很远，远到教科书上的铅字都带着时间的灰尘；但有时又很近，近到一个老人眼角的泪光就能折射整个时代的重量。老人的记忆已经模糊了，但当她看到那段修复后的影像时，她认出了自己------那个无所畏惧、信念如铁的少女。\
\
我想起一位哲人说过的话：「一个没有记忆的民族，是永远长不大的孩子。」数字技术让模糊的历史变得清晰，让褪色的记忆重新发光。这不是对过去的简单怀旧，而是让那些在历史中沉淀下来的精神品质------勇敢、坚韧、奉献------在今天的语境中获得新的生命。\
\
可是，生活在和平年代的我们，还需要长征精神吗？\
\
需要。只不过今天的长征不再是雪山草地，而是攻克芯片技术的封锁，是守护绿水青山的承诺，是面对人生困境时的不放弃。每一个时代都有属于自己的「雪山」和「草地」，而穿越它们的方式，从来就没有捷径------唯有一步一个脚印。\
\
老人的手指终于触到了屏幕。她笑了，那笑容穿过八十多年的光阴，依然明亮如初。我忽然觉得，那就是一个民族最动人的表情------不是沉浸在过去的荣耀里，而是在回望中汲取继续前行的力量。\
\
让记忆发光吧。不是为了照亮过去，而是为了让我们看得见未来。

**二、关联名著与作者**

**三、实例案例**

案例一：张桂梅与华坪女高。她扎根贫困山区数十年，用知识改变了近两千名大山女孩的命运。她说：「我生来就是高山而非溪流。」她的教育不在于华丽的设施，而在于日复一日的陪伴与坚持。\
案例二：「陪读妈妈」李红。她在女儿患有阅读障碍的情况下，每天陪读两小时，坚持十二年，女儿最终考取上海交通大学。她说：「不是她笨，是她需要多一点时间。」

**题目：最笨的方法**

文体：记叙文/议论文 \| 建议字数：700字

在这个「速成」盛行的时代，一位父亲用了十七年，完成了对女儿最笨的教育------陪伴。\
\
两张照片，跨越了十七年的时光。第一张里，小女孩的眼中还有怯生生的不安；第二张里，清华大学的学士帽下是自信从容的微笑。十七年间发生了什么？没有天价学区房，没有密密麻麻的补习班，只有一个父亲每天下班后坐在女儿身边，陪她写作业，听她讲学校里发生的趣事，在她考砸时不说「你怎么这么笨」而是说「没关系，我们看看错在哪里」。\
\
这听起来太「笨」了------笨到不需要什么教育理论，笨到任何一个普通父母都能做到。可是，越是简单的事情，坚持十七年就越不简单。\
\
我想起《管子》里的话：「十年树木，百年树人。」现代社会把「百年」压缩成了「三年高考」，把「树人」简化成了「分数」。我们看到无数家庭为了教育焦头烂额：择校、培优、奥数、编程，恨不得把孩子每一分钟都安排得满满当当。可是，当「鸡娃」成为一种社会现象，当亲子关系异化成「项目经理与执行者」，我们是否忘记了教育最初的模样？\
\
这位父亲的十七年告诉我们：教育从来不是技术问题，而是态度问题。不是你有没有能力送孩子去最好的学校，而是你有没有耐心在孩子最需要的时候，陪在他的身边。\
\
当然，我不是说知识学习不重要。我想说的是，在知识之外，还有一种更根本的教育------那就是让孩子感受到被爱、被尊重、被信任。当一个孩子知道，无论他考多少分，家里总有一盏灯为他亮着，总有一个声音对他说「没关系，慢慢来」------这种安全感，比任何补习班都更能激发一个孩子内在的成长动力。\
\
十七年，一棵幼苗长成了大树。那位父亲说「爸爸没什么本事」，可在我看来，他用最笨的方法，完成了一件最聪明的事------把一个生命的根，扎得足够深。

余华《活着》：福贵经历丧子、丧妻等磨难却依然坚韧地「活着」，这种面对苦难的态度，与张伟不向命运低头的精神内核相通。\
欧·亨利《麦琪的礼物》：妻子卖掉长发为丈夫买表链，丈夫卖掉金表为妻子买发梳------最珍贵的礼物不是物品本身，而是甘愿为对方付出的心意。

**三、实例案例**

案例一：霍金。21岁被诊断肌萎缩侧索硬化症，全身几乎瘫痪，但他凭借一台特制轮椅和语音合成器，完成了《时间简史》等科学巨著，成为当代最伟大的物理学家之一。\

**六、高分作文示例**

**题目：站起来的理由**

文体：议论文 \| 建议字数：700字

截瘫十年，张伟没有站起来。但他用一个自制的轮椅，让自己「站」了起来------不只是身体的高度，更是灵魂的高度。\
\
记者问他：是什么支撑你做这件事？他回答：「我不想让我老婆一直弯着腰跟我说话。」这个答案出乎所有人的预料。我们本以为他会说「梦想」「毅力」「不服输」之类的豪言壮语，没想到理由如此朴素------不过是心疼一个人的腰。\
\
然而细想之下，最打动人的力量，往往就藏在这种朴素里。\
\
我们见过太多宏大的叙事：为了人类进步，为了民族复兴，为了改变世界。这些当然很好，但普通人的人生，更多是被一些微小而具体的情感所驱动的。一个丈夫想让妻子少弯几次腰，一个母亲想让孩子每天吃上热乎的早饭，一个学生想让爸妈在家长会上抬得起头------正是这些「小」的理由，撑起了无数人「大」的人生。\
\
张伟的轮椅让我想到一个问题：什么叫「站起来」？是双腿直立吗？那么霍金从来没有站起过，但他在物理学的殿堂里比任何人都站得高。是得到社会的认可吗？那么那些默默无闻地在平凡岗位上坚守一生的人就不算「站着」吗？\
\
我想，真正的「站起来」，是找到那个让你愿意为之努力的理由------不管这个理由多么微小------然后一步一个脚印地朝它走去。张伟的理由是爱，你的理由可能是梦想，他的理由可能是责任。理由不同，但方向一致：都不愿意向生活的重力屈服。\
\
当我在新闻里看到张伟操作轮椅缓缓「站立」起来的那一刻，他妻子在他对面笑得像个孩子。那一刻我突然明白：这世界上让人站起来的，从来不是科技，不是金钱，甚至不是毅力------而是有一个值得你为之站立的人。
