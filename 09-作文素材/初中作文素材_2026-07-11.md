**⚽ 2026世界杯进行时：当中国少年遇见世界足球**

2026年7月 · 2026美加墨世界杯小组赛激战正酣

**一、素材提炼**

2026年美加墨世界杯正在北美大陆火热进行。虽然中国队未能出现在赛场上，但中国元素在世界杯中随处可见------从比赛用球到场馆空调，从球迷手中的国旗到社交媒体上的热议。更值得关注的是，中国青少年的足球热情正在持续升温：各地暑期足球夏令营爆满，乡村学校的足球场越来越多，越来越多的孩子把踢球当作暑假最开心的事。世界杯不只是32支球队的竞技场，更是一面镜子------映照出中国人对体育的热爱和对世界的开放心态。体育的真正魅力，不在输赢，而在参与和热爱。

**二、关联名著**

1.《老人与海》（海明威）：老渔夫圣地亚哥在大海上与大鱼搏斗了三天三夜，最终只带回一副鱼骨架。但他没有输------因为「人可以被毁灭，但不可以被打败」。足球场上同样如此：真正的强者不是从不失败的人，而是失败后依然热爱的人。\
2.《水浒传》（施耐庵）：梁山好汉各怀绝技、团结协作的故事，正如一支足球队------前锋如林冲般锐不可当，后卫如武松般坚不可摧，门将如鲁智深般一夫当关。

**三、实例案例**

贵州黔东南苗族侗族自治州的一所山村小学，2024年在爱心企业的资助下建成了全县第一块人工草坪足球场。初二学生杨小军从那时开始接触足球。没有专业教练，他就对着手机视频一个动作一个动作地学；没有队友，他就一个人对着围墙练传球。2026年暑假，他代表县里参加了全省青少年足球邀请赛。虽然最终没有拿到名次，但他被评为「最佳拼搏奖」。记者问他为什么喜欢足球，他说：「踢球的时候，我觉得整个世界都是我的。」他的故事被拍成短视频后感动了无数网友。

**四、名言名句**

***1.「人可以被毁灭，但不可以被打败。」------海明威《老人与海》***

***2.「胜败乃兵家常事。」------中国古语***

***3.「体育拥有改变世界的力量。」------纳尔逊·曼德拉***

**五、高分立意**

立意一（记叙文）：《我和足球的夏天》------以暑假踢球经历为线索，写热爱如何改变一个普通少年的生活。\

**六、完整范文（记叙文）**

**《我和足球的夏天》**

今年暑假，我多了一个身份------「野球场」的前锋。\
\
说是「野球场」，其实就是小区后面那片坑坑洼洼的水泥地。球门的立柱是两根生锈的铁管，球网早已不知去向。但就是这片不起眼的场地，成了我这个夏天最向往的地方。\
\
每天下午五点，当太阳不那么毒辣的时候，我就抱着那个磨掉了皮的足球跑下楼。球是我用攒了三个月的零花钱买的，花了六十八块钱。妈妈说我「浪费」，但她不知道------这个球对我来说，就像哈利·波特的魔杖。\
\
起初我只能对着墙踢。一脚出去，球弹回来，再踢，再弹。枯燥吗？一点也不。因为每当我踢出漂亮的一脚，脑海中就会自动配上解说员的呐喊：「球进了！中国队！中国队！」虽然现实中只有我一个人在傻笑，但那一刻------我觉得自己就是世界杯赛场上最耀眼的明星。\
\
后来有更多人加入了。隔壁楼的小胖是守门员，他的体型天然适合这个位置。对面小区的阿杰脚法最好，是我们默认的队长。还有刚搬来的小周，虽然才小学五年级，但跑起来像一阵风。一支「杂牌军」就这样凑齐了。\
\
最难忘的是上周的那场「恶战」。对面是另一拨经常在这踢球的人，个个都比我们高半头。比赛开始不到十分钟，我们就丢了两个球。小胖从地上爬起来时膝盖蹭破了皮，但他拍拍灰说：「没事，继续！」下半场，我们像发了疯一样逼抢。阿杰一脚长传，球划出一道弧线落在我的脚下------我甚至没来得及想，抬脚就射。球擦着对方守门员的指尖飞进了「球门」。\
\
那一刻，整个水泥地都安静了一秒，然后爆发出震耳欲聋的欢呼。虽然最终我们还是输了------但那个进球带来的快乐，比赢球本身更让我满足。\
\
暑假还剩二十天。每天晚上看世界杯直播，白天在「野球场」挥汗如雨------这大概就是十四五岁最好的夏天。也许我这辈子都不会站在真正的世界杯赛场上，但我知道：热爱本身就是一种奖杯。\
\
海明威说：「人可以被毁灭，但不可以被打败。」在球场上摔倒了那么多次，我依然热爱踢球------这大概就是「不败」的真正含义吧。

**🎒 暑期「研学游」热：行走的课堂与少年的文化觉醒**

2026年7月 · 全国各地暑期研学旅行进入高峰

**一、素材提炼**

2026年暑假，「研学游」持续火爆。从敦煌莫高窟到贵州天眼，从景德镇陶艺工坊到三星堆考古现场------全国各地的博物馆、文化遗产地和科研基地迎来了络绎不绝的中小学生研学团队。与普通旅游不同，研学游强调「在行走中学习」：在敦煌临摹壁画体会千年匠心，在天眼基地感受宇宙浩瀚，在红旗渠理解「人工天河」的精神。教育部数据显示，2026年暑期研学游参与人数预计突破500万人次。这一现象的背后，是素质教育理念的深化------最好的课堂不仅在教室里，更在广阔天地间。

**二、关联名著**

1.《文化苦旅》（余秋雨）：余秋雨行走在中国大地上的文化遗址之间，在断壁残垣中寻找文明的温度。「路就是书」------研学旅行的核心理念正在于此：让脚下的路，化为心中的书。\
2.《徐霞客游记》：四百年前，徐霞客「达人所之未达，探人所之未知」，用双脚丈量山川，用文字记录地理。他可能是中国最早的「研学旅行者」------不是为了功名，纯粹因为好奇和热爱。

**三、实例案例**

江苏南京初二学生顾思远，2026年暑假随学校研学团前往河南安阳殷墟。在甲骨文展厅，当讲解员讲到「一片甲骨惊天下」时，他被那些刻画在龟甲兽骨上的古老文字深深震撼了。回来后他主动报名参加了学校的甲骨文兴趣小组，开始学习认读和摹写甲骨文。他在研学报告中写道：「以前我觉得甲骨文是考古学家的事，离我很远。但当我亲手触摸到那些三千年前的刻痕时，我突然意识到------这些文字是我的祖先留下的，它们和我的DNA一样，是我身体里的一部分。」他的报告获得全市一等奖，被老师评价为「一个少年在文化根脉前的觉醒」。

**四、名言名句**

***1.「读万卷书，行万里路。」------董其昌***

***2.「纸上得来终觉浅，绝知此事要躬行。」------陆游***

***3.「一个忘记自己历史的民族是没有未来的。」------丘吉尔***

**五、高分立意**

立意一（记叙文）：《行走的课堂》------写一次研学旅行中的见闻与感悟，展现「行」与「知」的结合。\
立意二（议论文）：《旅游与研学有何不同？》------辨析观光式旅游与学习式研学的本质区别及教育价值。\
立意三（游记）：《在敦煌，我和千年前的画工对话》------以游记形式，在实地体验中展开与历史的对话。

**六、完整范文（记叙文）**

**《行走的课堂》**

出发前，我把这次敦煌研学之旅想象成了一次「高级旅游」------沙漠、骆驼、拍照发朋友圈。我想错了。\
\
大巴车在戈壁滩上行驶了整整六个小时。窗外是一望无际的黄色，偶尔有几簇干枯的骆驼刺。当莫高窟那面布满洞窟的崖壁终于出现在视野中时，全车人都安静了。不是因为它多么雄伟------恰恰相反，从外面看，它只是一面土黄色的山崖。但那种沉默的力量，压得人不敢大声说话。\
\
走进第45窟时，讲解员用手电筒照亮了墙上的壁画。一尊唐代彩塑菩萨出现在光线中，面容安详，衣纹流转。讲解员说：「这尊菩萨已经在这里坐了一千三百年了。」\
\
一千三百年。我默默在脑子里换算------那是李白还没出生的年代。\
\
最触动我的不是壁画本身，而是讲解员讲的一个细节：在一幅壁画下面的角落，有人发现了一行唐代画工留下的小字------「张二郎到此一游，累死了。」同学们都笑了，但我笑不出来。一千三百年前，一个叫张二郎的画工，在完成一天的绘制后，偷偷在这面墙上写下了这句牢骚。他没有想到，这句话会被一千三百年后的一个中学生读到。\
\
那一刻我忽然觉得，张二郎不再是一个面目模糊的「古代画工」，而是一个有血有肉的人------会累、会抱怨，但依然日复一日地在昏暗的洞窟里描摹着心中的佛国世界。\
\
研学最后一天，老师让我们每人写一句话作为总结。我写道：「以前我以为历史是一本书，现在我明白------历史是一面墙，墙上写满了和你我一样的人。」\
\
回程的火车上，翻开余秋雨的《文化苦旅》，第一句就击中了我：「路就是书。」是的，这趟敦煌之行让我读到了一本在教室里永远读不到的书。而那本书的名字，叫「中国」。

**🤖 2026世界人工智能大会：当AI学会「思考」，人类何为？**

2026年7月 · 上海世界人工智能大会（WAIC）开幕

**一、素材提炼**

2026年7月，世界人工智能大会（WAIC）在上海如期举行。本届大会最引人关注的话题是AI的「类人推理」能力------新一代大模型不仅能回答问题，还能进行多步骤的逻辑推理、创意写作甚至科学假设生成。面对AI的飞速进化，教育界展开了激烈讨论：当AI能在三秒内写出一篇高分作文时，学生还需要练习写作吗？大会达成的共识是：AI可以替代技能，但无法替代体验；可以提供信息，但无法代替思考；可以模仿情感，但无法拥有真情。在AI时代，人类最需要守护的恰恰是那些AI永远无法复制的能力------好奇心、同理心、创造力和对生命意义的追问。

**二、关联名著**

1.《弗兰肯斯坦》（玛丽·雪莱）：这部科幻小说鼻祖提出了一个永恒之问------人类是否有能力控制自己创造的东西？今天的AI正如弗兰肯斯坦的「怪物」：本身并非邪恶，但若无伦理约束，其力量可能失控。\
2.《论语》（孔子）：「学而不思则罔，思而不学则殆。」AI可以帮助我们「学」得更多更快，但「思」------那种带有体温的、个性化的、充满困惑与灵光一闪的思考------永远是人类不可让渡的领地。

**三、实例案例**

杭州初三学生林子涵是个「AI重度用户」------数学题用AI扫、作文让AI代写、连给妈妈发微信都要让AI润色。2026年5月的月考中，他语文作文拿了全班最高分------但那篇作文是AI写的。正当他窃喜时，语文老师在班上说了一句话让他彻夜难眠：「这篇文章结构完美、用词精准，但我读不到\'人\'。」第二天他主动找老师坦白，并重新手写了一篇------虽然分数低了十分，但老师在文末批注：「这一篇，有力气了。」林子涵从此给自己立了规矩：「AI是工具，不是替身。」他说：「技术可以帮我跑得更快，但往哪个方向跑------必须由我自己决定。」

**四、名言名句**

***1.「我思故我在。」------笛卡尔***

***2.「技术只是工具，关键在于人心。」------史蒂夫·乔布斯***

***3.「真正的教育不是注满一桶水，而是点燃一把火。」------叶芝***

**五、高分立意**

立意一（记叙文）：《AI写不出我的故事》------以个人经历切入，写AI时代中「人」的独特性与不可替代性。\
立意二（议论文）：《当AI比我会写作文》------从AI写作出发，论述人类学习写作的深层意义不止于「写出一篇文章」。\
立意三（想象文）：《2046年，我收到了一封AI写的信》------通过未来场景的想象，反思人与AI的关系。

**六、完整范文（议论文）**

**《当AI比我会写作文》**

上周，我做了个实验：把「我的妈妈」这个作文题目分别交给AI和我自己写。AI用了13秒，生成了一篇文字优美的文章------「我的妈妈有一双温柔的眼睛，她的爱如春风化雨......」而我自己趴在书桌前写了两个小时，开头改了四遍，最后交上去的版本是这样的：「我妈是个急性子，催我起床的声音整栋楼都听得到。但每天早上出门前，书包侧袋里总有一盒温好的牛奶。」\
\
语文老师的评语让我想了很久。在AI那篇上，她只写了四个字：「没有体温。」在我那篇上，她写了一大段，最后一句是：「读到你妈妈的热牛奶那一段，我想起了自己的母亲。」\
\
AI的文章很「完美」------但它写的不是一个具体的人，而是从海量数据中提炼出的「妈妈」的平均值。它不知道我妈催我起床时喜欢用家乡话，不知道牛奶一定要是红枣味的，不知道她偷偷把我破洞的校服补了又补。这些细节，AI永远编不出来------因为它们不是「信息」，而是「记忆」；不是「数据」，而是「生命」。\
\
笛卡尔说：「我思故我在。」这句话在AI时代有了新的含义：当机器也会「思考」时，「我思」不再是人类的专利------但「我感受」、「我经历」、「我爱」、「我痛」，这些带着体温的生命体验，是永远无法被算法复制的。\
\
所以，当AI比我会写作文时------我不该恐慌，而该庆幸。因为它逼我去想一个更重要的问题：如果连写作文都可以被替代，那么「我」到底是谁？\
\
答案或许是这样的：我不是那个能写出完美作文的人，而是那个愿意花两个小时把「妈妈的热牛奶」写成永恒记忆的人。技术可以让我跑得更快，但往哪个方向跑------必须由我自己决定。\
\
乔布斯说：「技术只是工具，关键在于人心。」在AI时代，守住自己的「心」------那才是我们作为人最珍贵的东西。

**☀️ 40°C的夏天：致敬高温下的城市守护者**

2026年7月 · 全国多地持续高温预警

**一、素材提炼**

2026年7月，中国多地持续发布高温红色预警，部分地区气温突破40°C。当大多数人在空调房里躲避酷暑时，有一些人却必须在烈日下坚守岗位------环卫工人凌晨四点开始清扫街道，交警在滚烫的柏油路面上指挥交通，外卖骑手穿越热浪送来每一份餐食，电力工人爬上烫手的电线杆抢修故障。他们的汗水，撑起了这座城市的正常运转。这个夏天，「高温关怀」成为社会热词：各地增设「清凉驿站」、爱心企业捐赠防暑物资、社区志愿者为户外工作者送绿豆汤。一座城市的温度，不在夏天的气温有多高，而在于它对普通劳动者的关怀有多暖。
