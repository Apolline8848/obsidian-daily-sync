**⚽ 2026世界杯激战正酣：绿茵场上的青春梦与中国力量**

2026年7月 · 美国/加拿大/墨西哥

**一、素材提炼**

2026年FIFA世界杯正火热进行中。本届世界杯首次由美国、加拿大、墨西哥三国联合举办，48支球队参赛规模空前。虽然中国队憾未入围，但中国元素无处不在：从义乌制造的球迷用品到球场周边的中国企业广告，从中国裁判到志愿者，中国以另一种方式"参赛"。更值得关注的是，无数中国青少年熬夜看球、在社区球场模仿偶像动作------足球带来的热爱、坚持与团队精神，正在新一代心中生根发芽。世界杯不仅是竞技场，更是一面镜子，映照出人类对梦想的共同追求。

**二、关联名著**

1.《老人与海》（海明威）：老渔夫圣地亚哥连续84天捕不到鱼仍不放弃，最终捕获大马林鱼。这与足球运动员在落后时不言弃、拼到最后一秒的精神高度契合------"人可以被毁灭，但不能被打败。"\
2.《西游记》（吴承恩）：唐僧师徒历经九九八十一难取得真经。世界杯夺冠之路何尝不是一场"西行"？每支球队都要跨越重重强敌，需要信念、团结和不屈的意志。

**三、实例案例**

浙江杭州初三学生张子豪是校足球队队长。初一时他因体型偏胖被同学嘲笑"不适合踢球"。他没有放弃，每天早上5:30起床跑步减重，课余时间苦练球技。两年后他不仅减重15公斤，还带领校队打进全市中学生足球联赛四强。他说："梅西小时候也被认为太矮，但他用行动证明了一切。我不需要成为梅西，我只需要成为更好的自己。"张子豪的故事被当地媒体报道后，激励了许多同龄人。

***2."天行健，君子以自强不息。"------《周易》***

**六、完整范文（议论文）**

**《过程比奖杯更闪亮》**

2026年世界杯如火如荼，当球迷们为进球欢呼、为胜负揪心时，我想起了八年前那个让我终生难忘的画面。\
\
2018年俄罗斯世界杯，日本队对阵比利时队。日本队一度2比0领先，全世界都以为奇迹即将发生。然而比利时队在最后时刻连扳三球，3比2逆转取胜。赛后，日本球迷没有愤怒离场，而是默默拿出蓝色垃圾袋，弯腰捡起看台上的每一片纸屑。那一刻，全世界的镜头对准了他们------这支球队虽然输了比赛，却赢得了全世界的尊重。\
\
这让我想起语文课上学过的《老人与海》。老渔夫圣地亚哥拖回一副巨大的鱼骨架，所有鱼肉都被鲨鱼吃光了。从结果看，他"一无所获"。但海明威告诉我们，真正的胜利不在于带回多少鱼肉，而在于那个搏斗的过程------在于一个人如何面对极限、如何坚持到底。\
\
在我们的学习生活中，何尝不是如此？考试分数是"结果"，但真正塑造我们的，是挑灯夜读的那个深夜、解出一道难题时的豁然开朗、与同学讨论时碰撞出的思维火花。如果一个人的目光只盯着终点线，就会错过沿途所有的风景。\
\
当然，重视过程并不意味着放弃对结果的追求。恰恰相反------只有把每一个过程做到极致，好的结果才会水到渠成。就像工匠打磨一件器物，每一刀、每一凿都倾注心血，最终的成品自然会发光。\
\
世界杯终会落幕，冠军只有一个。但那些在绿茵场上奔跑的身影、那些不服输的目光、那些赛后相拥的泪水------它们比任何奖杯都更加闪亮。因为它们告诉我们：人生最重要的不是站在哪里，而是你曾经怎样走过。

**🏊 暑期安全第一课：防溺水，守护生命之花**

2026年7月 · 全国中小学暑假期间

**一、素材提炼**

每年暑假，中小学生溺水事故进入高发期。据教育部通报，溺水是导致中小学生非正常死亡的头号杀手，尤其在农村地区和城乡结合部。2026年暑期伊始，全国各地学校密集开展防溺水安全教育，许多地方组织"巡河志愿队"、安装智能监控设备、开设公益游泳培训。这场全社会的"生命守护行动"背后，折射出一个深刻命题：安全教育不只是知识的传递，更是一种对生命的敬畏------每一个少年都值得被这个世界温柔保护。

**二、关联名著**

1.《活着》（余华）：主人公福贵经历了亲人的一次次离去，让我们深刻体会到生命的脆弱与珍贵。每一次"意外"背后都有可以被避免的可能------敬畏生命，从预防开始。\
2.《小王子》（圣埃克苏佩里）：小王子对他的玫瑰说："你对你的玫瑰所花费的时间，才让你的玫瑰变得如此重要。"每一条生命都独一无二，值得被用心守护。

**三、实例案例**

2025年暑假，湖南岳阳14岁的初中生李浩在河边玩耍时不慎落水。危急时刻，路过的退伍军人王师傅毫不犹豫跳入水中将他救起。被救后，李浩主动加入学校的安全宣传队，用自己的亲身经历向同学们讲述防溺水知识。他说："那次经历让我明白，生命真的太脆弱了。现在我最大的心愿是让每一个同学都平平安安。"他的转变感动了整个校园，也带动了更多学生成为安全宣传志愿者。

**四、名言名句**

***1."身体发肤，受之父母，不敢毁伤，孝之始也。"------《孝经》***

***2."生命，那是自然付给人类去雕琢的宝石。"------诺贝尔***

***3."君子不立于危墙之下。"------《孟子》***

**五、高分立意**

立意一（记叙文）：《那个夏天的"生死一课"》------以亲身经历或所见所闻写安全教育带来的触动。\
立意二（议论文）：《敬畏生命，从我做起》------从防溺水切入探讨青少年如何树立安全意识和责任意识。\
立意三（书信体）：《给学弟学妹的一封信》------以过来人身份向低年级同学传递安全警示与关爱。

**六、完整范文（记叙文）**

**《那个夏天的"生死一课"》**

每年暑假开始前，学校都会反复强调"防溺水"。说实话，过去我对这些叮嘱是不以为然的------"我又不是不会游泳""哪有那么巧就轮到我"。直到去年夏天，我才真正理解了那些话的分量。\
\
那是七月中旬最热的一天，我和表哥去村后的小河游泳。河水看着不深，但中间有一段因采砂形成了一个深坑。我仗着自己会游泳，没带救生圈就下了水。游到河中央时，一股暗流突然把我往下拽------水比我想象的深得多！我拼命划水，但腿像被什么东西缠住了，身体不断下沉。恐惧像冰水一样灌进我的胸口：我会不会......死在这里？\
\
千钧一发之际，表哥发现不对劲，迅速游过来把我托住。他后来告诉我，如果不是他刚好在附近，后果不堪设想。\
\
那晚回家，我躺在床上久久无法入睡。我想起了妈妈每天出门前的叮嘱，想起了老师在班会课上一遍遍的强调，想起了新闻里那些再也回不了家的孩子。我第一次如此真切地感受到：生命，真的只有一次。\
\
今年暑假，我主动报名成为了学校的安全宣传志愿者。在社区的安全讲座上，我给低年级的孩子们讲述了我的故事。一个小朋友举手问："哥哥，你当时害怕吗？"我说："怕，所以我才站在这里告诉你，永远不要觉得自己是例外。"\
\
那个夏天的"生死一课"，让我明白了一个最朴素的道理：活着，才有无限可能。敬畏生命，不是胆小，而是对父母、对天地、对自己最大的负责。

**🚀 嫦娥探月新征程：从"嫦娥奔月"到"中国足迹"**

2026年7月 · 中国文昌航天发射场

**一、素材提炼**

2026年，中国探月工程四期持续推进，嫦娥七号任务进入关键准备阶段，计划对月球南极进行高精度探测。从2007年嫦娥一号发射至今，中国探月工程已走过近二十年。从绕月到落月，从采样返回到建设月球科研站，每一步都凝聚着几代航天人的心血。更令人振奋的是，越来越多的"90后""00后"航天科技工作者站上历史舞台------他们用青春诠释了"仰望星空，脚踏实地"。探月工程不仅是国家科技实力的象征，更是一盏灯，点燃了无数中国少年心中的科学梦想。

**二、关联名著**

1.《海底两万里》（儒勒·凡尔纳）：19世纪的凡尔纳用想象力描绘了潜水艇和海底世界。一百多年后，他的"幻想"大多成为现实。探月工程也是如此------人类对未知的渴望，驱动着科技不断向前。\
2.《三体》（刘慈欣）：这部中国科幻巨著提出了"给岁月以文明"的命题。航天探索的本质，正是人类文明不断拓展边界的过程。

**三、实例案例**

四川成都的初一学生林晓宇从小痴迷天文。他的卧室天花板上贴满了荧光星星，书架上全是航天科普书籍。2025年，他参加了全国青少年航天创新大赛，设计了一款"月球基地植物种植系统"模型，获得一等奖。评委问他为什么做这个设计时，他说："我想让未来登上月球的中国人能吃上自己种的蔬菜。"这个朴素的梦想打动了在场所有人。林晓宇现在每天坚持学编程和物理，他说："总有一天，我要成为真正的航天工程师。"

**四、名言名句**

***1."我们的征途是星辰大海。"------田中芳树《银河英雄传说》***

***2."路漫漫其修远兮，吾将上下而求索。"------屈原《离骚》***

***3."一个人可以走得很快，但一群人可以走得很远。"------非洲谚语***

**五、高分立意**

立意一（记叙文）：《我的"月球梦"》------写一个少年追逐航天梦想的故事，展现热爱与坚持。\
立意二（议论文）：《从嫦娥奔月到嫦娥探月------论神话与科学的距离》------探讨想象力和科技创新的关系。\
立意三（演讲稿）：《仰望星空，脚踏实地》------面向同龄人的演讲，鼓励将远大理想与日常努力相结合。

**六、完整范文（演讲稿）**

**《仰望星空，脚踏实地》**

亲爱的同学们：\
\
大家好！今天我演讲的题目是"仰望星空，脚踏实地"。\
\
小时候，我躺在院子里数星星，奶奶说："每一颗星星都是一个梦想。"我信了。后来我读到嫦娥奔月的故事，觉得那是世界上最浪漫的事情。再后来我才知道，2020年嫦娥五号真的去了月球，还带回来一千七百多克月壤------神话和现实，原来离得这么近。\
\
但当我真正去了解中国探月工程的历史，才发现"浪漫"的背后是无数航天人几十年的坚守。嫦娥一号的总设计师叶培建院士曾说："我们就像一群蜗牛，一步一步往上爬。"从零开始，没有经验可以借鉴，每一个零部件的误差都必须控制在头发丝的千分之一以内。一个螺丝钉拧错半圈，整个任务就可能失败。\
\
同学们，这让我想到我们的学习。我们每个人都有属于自己的"月球"------可能是考上理想的高中，可能是学好一门乐器，可能是写出第一篇让老师赞叹的作文。这些梦想看起来很远，就像月亮挂在天上。但如果把它们拆解成每天的小目标------今天背20个单词，这周读完一本书，这个月学会一种解题方法------那么再远的"月球"，也会有到达的一天。\
\
蜗牛虽然慢，但它每一步都朝着目标前进。我们也一样------重要的不是飞得多快，而是每天都在向上。\
\
所以，从今天开始，让我们一起：仰望星空，心怀梦想；脚踏实地，走好每一步。\
\
谢谢大家！

**🏮 00后非遗传承人：当古老技艺遇见青春创意**

**一、素材提炼**

2026年暑假，全国各地的非遗研学活动迎来热潮。越来越多的00后、10后青少年走进非遗工坊，学习剪纸、皮影、苏绣、京剧脸谱绘制等传统技艺。更令人欣喜的是，一批年轻"非遗传承人"脱颖而出------他们用短视频记录学艺过程、用现代设计改造传统产品、在校园里组建非遗社团。古老的非遗不再沉睡在博物馆里，而在新一代手中焕发出活力和创意。文化传承不是一个被动的"保存"，而是一个主动的"再创造"------这正是当代青少年给出的答案。

**二、关联名著**

1.《红楼梦》（曹雪芹）：书中描绘了丰富的传统手工艺------从风筝制作到诗词吟诵，从刺绣到园林艺术。这些"技艺"承载的不仅是手艺，更是中国人的审美情趣和生活智慧。\
2.《百年孤独》（马尔克斯）：布恩迪亚家族七代人的故事中，传统与现代反复碰撞。马尔克斯提醒我们：遗忘历史意味着失去根基，但拒绝变化同样会走向衰亡。

**三、实例案例**

江苏苏州的初三学生陈雨桐，在初一时的综合实践课上第一次接触苏绣。她发现身边的同学都觉得刺绣"土气"，于是决定做点什么。她利用课余时间跟奶奶学刺绣，同时自学设计软件，将动漫角色、校园风景用苏绣表现。她创作的"二次元苏绣"系列在学校艺术节展览后引起轰动，连美术老师都惊叹不已。央视《非遗里的中国》节目组还专程采访了她。陈雨桐说："非遗不是老古董，它可以是任何时代的样子，包括我们这一代。"

***1."不忘本来才能开辟未来，善于继承才能更好创新。"------习近平***

***2."传统不是守住灰烬，而是传递火焰。"------古斯塔夫·马勒***

***3."周虽旧邦，其命维新。"------《诗经》***

**六、完整范文（议论文）**

**《传承，是点燃新的火焰》**

一说起"非遗传承"，很多人的第一反应是保护、抢救、别让它断了。这些当然重要。但我认为，传承的目的不是让传统"活着"，而是让它"活得更好"。\
\
奥地利作曲家马勒说过一句很深刻的话："传统不是守住灰烬，而是传递火焰。"守住灰烬，是把一件东西原封不动地保存下来，不让它变样。而传递火焰，是让火继续烧，甚至烧得更旺------这需要新的木柴，新的风，新的燃烧方式。\
\
记得去年在央视看到一档节目，讲的是90后皮影戏传承人的故事。他没有墨守几百年前的剧目，而是创作了《西游记之大圣归来》皮影版，还加入了LED灯光和电子音乐。老一辈艺人起初摇头："这不是皮影戏！"但当演出座无虚席、年轻观众看得目不转睛时，老先生们也沉默了。\
\
这让我明白了一个道理：文化传承不是搬运，而是翻译------用当代人能听懂的语言，重新讲述古老的故事。如果一味固守形式，非遗就会变成博物馆里的标本，虽然有形却无神；只有让每一代人都能在其中找到自己的影子，文化才能真正"活"在当下。\

当然，创新不等于乱改。真正的创新必须建立在对传统深刻理解的基础上。就像书法------你得先临摹《兰亭序》一万遍，才有资格谈"自成一家"。\
