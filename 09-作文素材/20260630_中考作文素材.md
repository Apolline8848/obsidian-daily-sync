**✈️ 运-20列装十周年：大国鲲鹏，十年磨一剑**

时间：2026年6月30日 \| 地点：中国 \| 类型：国内·科技创新

**一、素材提炼**

2026年6月，中国自主研制的大型运输机运-20迎来列装十周年。十年间，运-20从首飞、列装到走出国门，先后执行抗疫物资运输、国际人道救援、海外撤侨等重大任务，航迹遍布亚洲、非洲、欧洲和大洋洲。运-20家族已衍生出加油机、预警机等多种型号，标志着中国航空工业实现了从"跟跑"到"并跑"再到部分领域"领跑"的跨越。这款被亲切称为"胖妞"的国产大飞机，承载着几代航空人的梦想，是自主创新、艰苦奋斗精神的集中体现。

**二、关联名著**

《钢铁是怎样炼成的》（奥斯特洛夫斯基）------保尔·柯察金在极端艰苦的条件下，以钢铁般的意志投身革命事业。运-20的研制同样经历了无数次失败与重来，航空人像保尔一样，在"不可能"中创造了"可能"。书中那句"人最宝贵的是生命，生命属于人只有一次"与运-20团队"十年磨一剑"的精神高度契合------把有限的生命投入无限的事业，便是青春最美的姿态。

**三、实例案例**

案例一：2020年新冠疫情暴发，运-20首次执行非战争军事行动，向武汉紧急运送医护人员和物资。飞行员在请战书中写道："国有召，召必应，应必战，战必胜。"那一刻，鲲鹏不仅是飞机，更是生命的方舟。\
案例二：运-20总设计师唐长红院士，从运-7到运-20，将一生献给中国大飞机事业。他曾说："我们这代人，就是要让中国人自己的大飞机翱翔蓝天。"他用行动诠释了什么是"择一事，终一生"。

***「天行健，君子以自强不息。」------《周易》***

**五、高分立意方向**

立意一：《十年磨一剑，今朝试锋芒》------以"坚持"为主线，将运-20的十年征程与个人成长中的"长期主义"相映照。任何伟大的成就，都是一点一滴的积累。\
立意二：《从"跟跑"到"领跑"》------以"创新"为核心，探讨中国制造如何从模仿到自主创新的跃迁之路，引申到个人学习的"超越"。\
立意三：《鲲鹏展翅，志在千里》------以"梦想"为主题，运-20的飞天之路告诉我们：梦想不怕遥远，只怕放弃。

**六、完整范文**

**《十年磨一剑》（记叙文）**

2026年6月，运-20列装十周年。当我在新闻中看到"胖妞"翱翔蓝天的画面时，忽然想起了自己学琴的十年。\
\
那年我六岁，妈妈把一架电子琴搬回家，说："学琴吧，将来能多一个朋友。"我似懂非懂地点了点头。最初的新鲜感很快被枯燥的指法练习取代，哈农、车尔尼、巴赫......这些名字成了一座座翻不完的山。\
\
三年级那年，我参加了市里的钢琴比赛。台上灯光刺眼，我紧张得手指发僵，弹错了好几个音。下台后，我哭着对妈妈说："我不学了。"妈妈没有责备，只是带我去了科技馆。在航空航天展厅，我第一次看到了运-20的模型。妈妈指着它说："这架飞机，从图纸到飞上天，用了十年。研制团队失败过无数次，但他们从来没有说'不干了'。"\
\
我望着那架银白色的模型，想象着它冲破云层的样子。回家的路上，我对妈妈说："我再试试。"\
\
从此，练琴不再是被动任务。我开始享受每一个音符从指尖流淌出来的感觉。五年级时，我在全校文艺汇演上弹奏了《彩云追月》，台下掌声雷动。那一刻我终于明白：不是比赛名次定义了你，而是那段不放弃的时光塑造了你。\
\
如今，中考在即。回望从"弹不好"到"能弹好"的十年，我发现运-20的故事早已成为我心中的灯塔。十年磨一剑，有人磨出了鲲鹏，有人磨出了琴声------这都不重要。重要的是，我们都选择了"再来一次"。\
\
愿每一个正在路上的少年，都能像运-20一样：冲破迷雾，直上云霄。

**🚄 西安至十堰高铁开通：穿越秦岭的钢铁纽带**

时间：2026年6月 \| 地点：中国·陕西/湖北 \| 类型：国内·基建发展

**一、素材提炼**

2026年6月，西安至十堰高铁正式开通运营。这条全长约256公里的高铁线路，穿越秦岭山脉，将西安与十堰的车程从原来的4个多小时压缩至1小时左右。线路桥隧比高达94%，建设者们在崇山峻岭间架桥凿隧，克服了地质复杂、生态保护等多重挑战。西十高铁不仅是"八纵八横"高铁网的重要组成部分，更是连接西北与华中的经济大动脉，为沿线地区的旅游、商贸和人员往来注入了新的活力。

**二、关联名著**

《平凡的世界》（路遥）------孙少平、孙少安兄弟在黄土高原上艰难创业，他们修路、办砖厂，用双手改变命运。西十高铁的贯通，恰似"平凡的世界"中那条连接希望的路------对秦巴山区的百姓而言，高铁不仅是交通工具，更是通向外部世界的桥梁。路遥写道："生活不能等待别人来安排，要自己去争取和奋斗。"这条高铁，正是成千上万建设者"争取"来的。

**三、实例案例**

案例一：西十高铁秦岭隧道施工队队长李师傅，在隧道里连续工作了三年，妻子生产时他只能在洞口接了一个电话。他说："隧道打通那天，我站在两省交界处哭了一场。这辈子能参与这样的大工程，值了。"\
案例二：十堰山区一位茶农老周，以前茶叶要翻山越岭半天才能运到县城。高铁开通后，他的茶叶可以通过"高铁快运"48小时内到达西安、郑州等大城市，销量翻了三倍。

**四、名言名句**

***「千里之行，始于足下。」------老子***

***「世上本没有路，走的人多了，也便成了路。」------鲁迅***

***「逢山开路，遇水架桥。」------中国谚语***

**五、高分立意方向**

立意一：《跨越》------以"克服障碍"为主题，从秦岭天堑到高铁通途，诠释人类克服自然阻隔的智慧与勇气，引申到个人成长中的"跨越"。\
立意二：《连接》------高铁连接的不只是两座城市，更是人与人的心。可从"连接"的角度写亲情、友情、时代变迁。

**六、完整范文**

**《跨越那座山》（议论文）**

秦岭，中国南北分界线。千百年来，它既是地理屏障，也是文化分水岭。韩愈被贬潮州时悲叹"云横秦岭家何在"，李白过蜀道时惊呼"难于上青天"。然而，2026年的夏天，一列高铁以350公里的时速穿越了这座千古名山。\
\
我不禁思考：是什么让人类能够不断"跨越"？\
\
是工具，但绝不仅仅是工具。从秦直道到丝绸之路，从蒸汽火车到高铁动车，每一次交通革命背后，都是人类对"远方"的渴望与对"局限"的不甘。秦岭隧道的建设者们，在地下数百米处与岩爆、涌水搏斗了上千个日夜。让他们坚持下来的，不是冰冷的机器，而是"让山里人走出去"的朴素信念。\
\
跨越，更是一种精神姿态。孔子周游列国，是在跨越思想的边界；张骞出使西域，是在跨越文明的隔阂；中国航天人让嫦娥奔月，是在跨越地球的引力。每一次跨越，都始于一个简单的问题："山的那边是什么？"\
\
对我们中学生而言，中考也是一座"秦岭"。它横亘在眼前，让人望而生畏。但请记住：所有的高山都是用来跨越的，所有的远方都是用来抵达的。西十高铁的建设者们用四年打通了94%的桥隧，而我们用了九年时间，已经走完了初中三年------中考，不过是最后一段隧道。\
\
当你走出考场的那一刻，你会发现：那座曾经让你焦虑不安的"大山"，已经在你身后了。你跨越了它，也跨越了自己。

**🏗️ 制造业PMI重返扩张区间：中国经济展现韧性**

时间：2026年6月30日 \| 地点：中国 \| 类型：国内·经济奋斗

**一、素材提炼**

国家统计局6月30日发布数据，6月份中国制造业采购经理指数（PMI）为50.3%，重返50%的荣枯线以上，显示制造业景气水平有所回升。其中，高技术制造业和装备制造业PMI分别为52.1%和51.8%，高于制造业总体水平。专家分析认为，在外部环境复杂多变的背景下，中国经济展现出较强韧性，新质生产力正在加速培育。这一数据背后，是无数企业、工人和科研人员共同努力的结果。

**二、关联名著**

《老人与海》（海明威）------老渔夫圣地亚哥在连续84天没有捕到鱼后，依然出海，最终钓到大马林鱼。制造业的回升恰如圣地亚哥的"第85天"------在经历低谷后，凭着不屈的精神重新出发。海明威写道："人可以被毁灭，但不可以被打败。"经济的起伏是常态，但奋斗者的韧性永不褪色。

**三、实例案例**

案例一：深圳一家机器人创业公司的90后CEO刘洋，在2025年行业低谷时，公司账上只剩三个月资金。他没有裁员，而是带着团队住在办公室，吃泡面，终于研发出新一代巡检机器人，获得重要订单，公司起死回生。\
案例二：浙江义乌一位经营小商品的外贸老板娘张姐，面对订单下滑，自学跨境电商直播，用"散装英语"在TikTok上卖货，如今海外订单占比已超过60%。

**四、名言名句**

***「沉舟侧畔千帆过，病树前头万木春。」------刘禹锡***

***「宝剑锋从磨砺出，梅花香自苦寒来。」------《警世贤文》***

***「冬天来了，春天还会远吗？」------雪莱***

**五、高分立意方向**

立意一：《反弹》------从PMI"反弹"切入，探讨人生中的低谷与回升，低谷不是终点，而是积蓄力量的起点。\
立意二：《韧性的力量》------以经济韧性比拟人的精神韧性，论述在逆境中保持弹性比一味强硬更可贵。

**六、完整范文**

**《在低谷中仰望星空》（散文）**

50.3%。一个看似枯燥的数字，却让无数人的心为之一振。中国制造业PMI重返荣枯线以上，意味着工厂的机器重新轰鸣，流水线上的灯光再度亮起。\
\
我想起去年冬天去舅舅的模具厂。偌大的车间里，一半机器停着，舅舅坐在办公室，对着订单表抽烟。他说："二十年来第一次这么难。"我问他打算怎么办，他掐灭烟头说："等。等天亮。"\
\
他没有只是等。接下来的半年，他开始学CAD画图------一个五十岁只有初中文化的人，每天对着电脑教程学到深夜。他把工厂从单纯代工转向自主设计，接下了新能源汽车零部件的小批量订单。端午我去看他时，车间里的机器已经全部开动。舅舅笑着说："最难的时候，我每天看着天上的星星想，明天太阳一定会出来。"\
\
经济有周期，人生有起伏。PMI会跌破50%，我们也会遇到考砸的模拟考、落选的竞赛、失利的比赛。但重要的不是那一刻有多黑暗，而是你是否相信天亮，是否在天亮之前为自己准备好了行囊。\
\
圣地亚哥在第85天等到了他的大马林鱼，中国制造业在低谷后迎来了50.3%的回升。而你我，只需在自己的"第85天"到来之前，做好所有准备------然后，扬帆出海。

**🤝 中美青少年鼓岭相聚：青春架起友谊之桥**

时间：2026年6月 \| 地点：中国·福州鼓岭 \| 类型：国内·文化交流

**一、素材提炼**

2026年6月，中美青少年文化交流活动在福州鼓岭举行。来自美国十几个州的100多名青少年与中国同龄人一起，在鼓岭百年避暑胜地共同体验了书法、茶道、武术等中国传统文化，并围绕"气候变化""人工智能""青年责任"等议题展开对话。鼓岭是中美民间友谊的象征------上世纪早期，许多美国传教士和商人在此居住，与当地居民结下深厚情谊。习近平主席曾专门讲述鼓岭故事，强调"国之交在于民相亲"。

**二、关联名著**

《小王子》（圣埃克苏佩里）------小王子与狐狸的"驯服"建立了一种独一无二的联系。鼓岭上的中美青少年，正是在共同体验中建立了超越国界的友谊。书中写道："真正重要的东西，眼睛是看不见的，唯有用心才能感受。"文化的交融，语言的障碍，最终都被一颗真诚的心消融。

**三、实例案例**

案例一：来自加州的16岁女孩艾米莉在鼓岭学习书法时，写了"和平"两个汉字。她的中国搭档小雯帮她纠正了笔顺，两人因此结为好友。艾米莉回国后在社交媒体上分享中国之行的见闻，她说："我想让更多人知道，中国不是新闻里的样子，而是有温度、有笑容的。"\
案例二：1992年，曾在鼓岭度过童年的美国老人加德纳夫人，应习近平邀请访问鼓岭，完成了丈夫的遗愿。这段感人故事成为中美民间交往的经典案例。

**四、名言名句**

***「海内存知己，天涯若比邻。」------王勃***

***「有朋自远方来，不亦乐乎？」------《论语》***

***「真正的友谊，是一株成长缓慢的植物。」------华盛顿***

**五、高分立意方向**

立意一：《桥》------以"桥"为意象，从鼓岭的友谊之桥延伸到人与人、国与国之间的理解之桥。\
立意二：《看见》------艾米莉说"中国不是新闻里的样子"，以此探讨如何跨越偏见、真正"看见"他人。

**六、完整范文**

**《我是一座桥》（散文）**

如果让我选一个词来形容青春，我不会选"朝阳"，不会选"花朵"，我会选------"桥"。\
\
鼓岭的夏天，来自太平洋两岸的少年们坐在一起。语言不通的时候，他们用比划、用笑容、用手机翻译软件。一个美国男孩想学太极拳，中国教练用最慢的动作演示，他跟着比划，歪歪扭扭的样子引来一片笑声。笑声不需要翻译。\
\
我想起自己的一段经历。初二那年，班上转来一个新疆同学阿迪力，普通话说得磕磕绊绊，同学们不知道如何与他交流。有一天体育课，他带了一个足球，在操场上娴熟地颠球。那一刻，足球成了"桥"。不需要语言，一个眼神、一个传球，我们就成了朋友。\
\
青春之所以能成为"桥"，是因为年轻人还没有学会筑墙。成年人总喜欢先问"你是哪国人""你信仰什么"，而少年只问："你愿意和我一起玩吗？"\
\
鼓岭的故事始于一百年前，至今绵延不绝。一百年后，也许今天参加活动的某个中国少年和美国少年，会成为各自国家的桥梁建设者------不是钢筋水泥的桥，而是人心与人心的桥。\
\
我们都是桥。连接昨天和明天，连接此岸和彼岸，连接"我"和"我们"。

**🌊 防汛救灾进行时：风雨中的守护者**

\
后来我渐渐明白：人生不是淘汰赛，而是联赛。淘汰赛输一场就出局，但联赛输一场还有下一轮。中考只是人生"联赛"中的一场。赢了固然好，输了------只要你还愿意继续踢，就远远没有"出局"。\
\
德国队在世界杯上输给了巴拉圭，但德国足球依然伟大。你在某次考试中输给了同桌，但你的学习生涯依然漫长。\
\
愿我们都能学会"输得漂亮"------像德国队长那样，输掉比分，不失风度；认输，但不认命。
