**示例1：长征十号乙火箭首次成功回收**

示例1（国内/国际时事热点新闻）

📍中国海南文昌 \| 🕐2026年7月10日12时15分

**一、素材提炼**

2026年7月10日，长征十号乙运载火箭在海南商业航天发射场成功首飞，火箭一子级在海上通过网系捕获方式成功回收。这是中国首次实现运载火箭可控回收，也是全球首次采用\"网捕\"式火箭回收方案，标志着中国商业航天进入重复使用时代。

**二、代表性人物素材（2个）**

人物1：钱学森------中国航天之父。1955年冲破重重阻力回国，在极其艰苦的条件下带领团队从零起步，开创了中国航天事业。他提出的系统工程思想至今指引着中国航天的发展方向。长征十号乙的\"网捕回收\"方案正是系统工程思想与创新精神结合的产物。

人物2：张智------长征十号乙运载火箭总设计师。他带领团队在不到一年时间内完成从立项到首飞回收成功的全过程，攻克了网系捕获回收等数十项关键技术难题，创造了中国航天发展的新速度。他常说：\"创新不是灵光一现，而是一万次失败后的第一万零一次尝试。\"

**三、相关名著（2部）**

《海底两万里》------儒勒·凡尔纳（法国科幻小说家）。书中\"鹦鹉螺号\"潜艇的想象在百年后变为现实，恰如火箭回收从科幻到工程实践的跨越，体现人类探索未知的永恒勇气。《西游记》------吴承恩。孙悟空一个筋斗云十万八千里，象征着中华民族对飞天梦想的千年追求，长征火箭正是这梦想的当代续写。

**四、名言警句汇总（5条）**

1\. \"路漫漫其修远兮，吾将上下而求索。\"------屈原《离骚》（白话：前路漫长而遥远，我将上天入地追寻探索。）

2\. \"可上九天揽月，可下五洋捉鳖。\"------毛泽东《水调歌头·重上井冈山》

3\. \"世上无难事，只要肯登攀。\"------毛泽东

4\. \"想象力比知识更重要。\"------爱因斯坦

5\. \"创新是一个民族进步的灵魂。\"------江泽民

**五、高分立意（3个）**

立意一：从\"追赶\"到\"引领\"的自主创新之路。核心观点：中国航天从跟跑到并跑再到领跑的历程，证明自主创新才是大国崛起的根本途径。可用写作角度：攻克\"卡脖子\"技术的故事、从零到一的创造历程。

立意二：梦想的力量穿越时空。核心观点：从万户飞天的悲壮尝试到长征火箭的精准回收，中华民族的飞天梦跨越千年从未熄灭。可用写作角度：梦想的代际传承、古人想象与今人实践的对照。

立意三：失败是成功的阶梯。核心观点：火箭回收技术背后是无数次坠毁与改进，真正的强者不是从不失败，而是从失败中汲取力量重新出发。可用写作角度：面对挫折的态度、成长中的\"坠落\"与\"起飞\"。

**六、高分作文应用示例**

**作文题目：《再次起飞》**

作文类型：记叙文

那个夏天的午后，我站在学校航模社团的工作室里，看着地上一堆散落的零件，眼泪不争气地掉了下来。\
\
三个月前，当老师在黑板上写下\"全国青少年航天创新大赛\"的通知时，我第一个举起了手。我想造一枚能飞上天的模型火箭------不是那种买来的套件，而是从零开始、自己设计的火箭。同学们笑我异想天开，但老师说：\"试试看，万一飞起来了呢？\"\
\
从那天起，我每天放学后都泡在工作室里。画图纸、切木片、调配燃料，每一项都像在攀登一座看不见山顶的高峰。第一次试飞，火箭刚离开发射架就歪歪扭扭地栽进草丛。第二次，它在半空中炸成了一团烟花。第三次、第四次......到第七次的时候，我已经习惯了失败，甚至能在火箭坠毁后笑着对队友说：\"又收集到一个不飞的姿势。\"\
\
可是这一次不同。这是比赛前最后一次试飞，我们花了整整三个星期改进的\"星火七号\"，在升空三十米后突然失去控制，一头扎进了校园后面的池塘。捞上来的时候，电路板已经被水泡得面目全非。\
\
\"算了，\"队友小陈把湿漉漉的残骸扔进垃圾桶，\"明天就是截止日期，来不及了。\"\
\
那天晚上，我一个人回到工作室。夜色从窗户漫进来，把满墙的设计图和零件架淹没在暗影里。我坐在昏黄的灯光下，一张一张地翻看那些画满了修改标记的图纸------每一处涂改，都是一次失败留下的印记。忽然，我的目光落在墙角那本翻旧了的《钱学森传》上。我想起书中写的一句话：\"科学试验如果次次成功，那就不叫试验了。\"\
\
第二天是星期六，距离作品提交只剩不到三十个小时。我重新打开了电脑。这一次，我没有盯着那些失败的图纸，而是把所有试飞的数据------七次坠毁的轨迹、每一次的传感器读数------全部调出来重新分析。一个小时后，我发现了一个被所有人忽略的问题：火箭的重心在燃料燃烧过程中会逐渐后移，而我们从未考虑过这个动态变化。\
\
我们在火箭尾部加装了一个可动小翼，通过简单的机械连杆连接到重心感应器。当重心后移时，小翼自动微调角度来补偿。这个设计简单得令人惊讶------不需要复杂的飞控系统，只有三根弹簧和一片铝片。\
\
\"星火八号\"在周日上午装好了。我们甚至来不及试飞，就抱着它冲向了比赛现场。\
\
发射倒计时归零的那一刻，我的手心全是汗。火箭笔直地冲向天空，在蓝天的映衬下拉出一道白色的尾迹。一百米，两百米，三百米------它稳稳地攀升，像一个终于学会飞翔的雏鹰。当降落伞准时打开，火箭缓缓飘回地面时，整个赛场爆发出雷鸣般的掌声。\
\
评委老师说：\"你们的方案简单而巧妙，特别是那个动态重心补偿装置------这比很多成年人的设计都要高明。\"\
\
我站在领奖台上，手里捧着金灿灿的奖杯。阳光从体育馆的穹顶洒下来，把奖杯照得闪闪发光。我忽然明白了一个道理：真正的起飞，不是在第一次就成功的时候，而是在第七次坠毁之后，你依然选择重新站到发射架前的那一刻。\
\
就像长征火箭经历了无数次失败才学会回收一样，所有令人仰望的高度，都曾经贴地飞行。

📍中国北京 \| 🕐2026年7月15日

**一、素材提炼**

国家统计局7月15日发布数据，上半年中国GDP达695704亿元，同比增长4.7%。在复杂国际环境和多重压力下，中国经济延续\"向新向优\"态势，人工智能、新能源等新动能持续壮大，展现强大韧性与活力。进出口规模首超25万亿元。

**二、代表性人物素材（2个）**

人物1：邓小平------改革开放总设计师。1978年，他以\"摸着石头过河\"的务实精神开启中国市场经济转型，让一个贫穷大国成长为世界第二大经济体。GDP增长4.7%的数字背后，是四十年改革开放打下的坚实基础。

人物2：任正非------华为创始人。面对国际封锁和技术\"卡脖子\"，他带领华为坚持自主创新，从交换机代理商成长为全球通信巨头。上半年中国AI相关产品出口动力强劲，正是无数像华为这样的企业用创新撑起了经济韧性。

《史记》------司马迁。记载了中华文明三千年兴衰，揭示了一个深刻规律：真正的繁荣来自开放与变革。当今中国经济转型正是这一历史规律的当代延续。《钢铁是怎样炼成的》------奥斯特洛夫斯基。保尔在极端困境中炼就钢铁意志，中国经济在压力中向新向优，同样是一曲\"百炼成钢\"的壮歌。

1\. \"穷则变，变则通，通则久。\"------《周易·系辞下》（白话：事物发展到极限就要变革，变革才能通达，通达才能长久。）

3\. \"天行健，君子以自强不息。\"------《周易》

4\. \"在危机中育新机，于变局中开新局。\"------习近平

5\. \"经济是一切的基础，但人是一切的目的。\"------阿马蒂亚·森（诺贝尔经济学奖得主）

立意二：数字背后是人民的力量。核心观点：GDP的每一个百分点，都凝结着普通劳动者的汗水与智慧。可用写作角度：身边人的奋斗故事、平凡岗位上的\"经济贡献\"。

立意三：开放包容方能行稳致远。核心观点：上半年进出口超25万亿元，说明合作共赢才是人间正道。可用写作角度：文化交流的故事、合作与共赢的经历。

**六、高分作文应用示例**

**作文题目：《父亲账本里的中国》**

作文类型：文化散文

父亲有一个牛皮纸封面的旧账本，封皮已经磨得发亮，边角卷起细小的毛边。从我记事起，这个账本就被锁在他书桌最下面的抽屉里，一年只拿出来三四次。\
\
直到去年暑假，父亲才把这个秘密\"正式\"交给我。\"你都上初三了，\"他一边开锁一边说，\"该知道咱家这些年是怎么过来的。\"\
\
翻开账本，第一页记录的是二〇一〇年。那时父亲刚辞职创业，在县城租了一间二十平米的门面卖电脑配件。\"1月收入：3200元。支出：房租800，进货1800，生活费600。\"字迹潦草而用力，我仿佛能看到那个冬天，父亲哈着白气坐在没有暖气的店里，一笔一画盘算着每一块钱的去向。\
\
翻过几页，到二〇一四年，数字开始变了。\"3月收入：8500元。\"\"6月收入：12000元。\"旁边还有一行小字：\"今日签下第一笔企业订单，给镇上的工厂装二十台电脑。\"父亲的字条理了许多，不再像从前那样急促潦草。那一年，他买了一辆二手面包车------账本里夹着一张泛黄的购车发票。\
\
最有意思的是二〇一八年那一页。除了日常进出账，父亲还记了一行：\"双十一当天线上订单62单，首次超过线下。\"然后是一个感叹号，三个。那时候我上小学四年级，只记得爸爸那阵子天天往快递点跑，周末也不休息。\
\
而到了二〇二二年，账本上出现了一个新词：\"直播\"。父亲的字迹变得圆润从容：\"3月18日，第一次直播带货，销售23单，利润480元。\"后面每隔几天就有一条直播记录，数字从两位数跳到三位数，再到四位数。账页之间还夹着一张打印出来的直播间截图：父亲举着新到的键盘，身后是刚装修好的背景墙，脸上带着不太自然的微笑。\
\
最让我动容的，是二〇二四年底的一页。在全年汇总的下面，父亲用红笔写了两行字：\"全年净利186427元。儿子初三了，攒够了他以后上大学的钱。\"红色的墨水像一团安静的火焰，在泛黄的纸面上安静地燃烧。\
\
我合上账本，抬头看父亲。他正站在窗边，夕阳把他的侧脸勾出柔和的轮廓。不知何时，他的鬓角已经生出了许多白发。\
\
\"爸，您这本账本，比政治课本上讲的\'中国经济\'生动多了。\"\
\
父亲笑了笑，眼睛眯成两道温柔的弧线。他说：\"咱们老百姓的账本，就是国家经济的底账。国家统计局发布的数据是多少万亿GDP，但构成这些数字的，就是千家万户日复一日的努力。\"\
\
那个傍晚，我把账本放回书桌抽屉的时候，忽然觉得它比任何一本书都重。因为它记录的不仅是一个家庭的成长，更是一个时代的体温------从线下到线上，从坐商到直播，从解决温饱到规划未来。\
\
每一笔潦草的记录，都是中国经济这棵大树的年轮里最细微、也最真实的一圈。

**示例3：世界人工智能大会：从空间站发出的AI之约**

📍中国上海 \| 🕐2026年7月17日---20日

**一、素材提炼**

7月17日，2026世界人工智能大会（WAIC）在上海开幕。大会期间，神舟二十三号航天员、载荷专家黎家盈从中国空间站向大会AI女性论坛发来\"太空问候\"，成为科技与人文交融的经典瞬间。

**二、代表性人物素材（2个）**

人物1：王亚平------中国首位出舱活动的女航天员。她以\"太空教师\"的身份在天宫空间站为全国青少年授课，用亲身经历证明了女性在航天和科技领域同样可以抵达星辰大海，激励了无数女孩勇敢追梦。

人物2：李飞飞------斯坦福大学计算机科学教授、AI领域领军人物。作为ImageNet的创建者，她推动了深度学习革命。同时她倡导\"以人为本的人工智能\"，强调技术必须服务于人类的共同福祉，科技与温度从来不是对立面。

**三、相关名著（2部）**

《海底两万里》------凡尔纳以超凡想象力预言了潜水艇的诞生，正如今天的AI从科幻走进现实，人类对智能的探索永无止境。《朝花夕拾》------鲁迅在回忆中寻找成长的印记，AI时代同样需要我们回望人文传统，技术向前看的同时也要向内心看。

3\. \"妇女能顶半边天。\"------毛泽东

**五、高分立意（3个）**

立意一：科技的温度在于为人服务。核心观点：从空间站传来的问候提醒我们，无论技术如何发展，最终目标都是让人的生活更美好。可用写作角度：科技产品改变生活的故事、技术与人情的平衡。

立意二：打破偏见的力量。核心观点：黎家盈从太空传来的声音和李飞飞在AI领域的成就，共同打破了\"女性不适合科技\"的刻板印象。可用写作角度：挑战偏见的故事、突破天花板的力量。

立意三：工具与人的关系之思。核心观点：AI可以处理海量数据，但只有人类才能赋予数据以意义和温度。可用写作角度：科技便利与人文关怀、学习中如何善用工具。

**六、高分作文应用示例**

**作文题目：《从地面到太空的问候》**

作文类型：议论文

前几天看新闻，一个画面深深打动了我：在世界人工智能大会的AI女性论坛上，来自中国空间站的航天员黎家盈通过太空连线发来问候。那一刻，一个在距离地面四百公里的太空中运行的飞船，和一个在地面讨论人工智能未来的会场，被一道无形的信号连接在一起。\
\
这个画面之所以令人动容，是因为它浓缩了这个时代最动人的两个命题：科技能走多远，以及科技最终是为了谁。\
\
先说科技能走多远。人类对智能的追求由来已久------从古希腊神话中赫淮斯托斯铸造的青铜巨人，到诸葛亮发明的木牛流马；从图灵在二战中破译密码的机器，到今天大会上展示的能写诗画画的大模型。我们用了两千年把神话变成科学，又用了不到一百年让机器学会了\"学习\"。WAIC现场六十台机器人同时服务的壮观场面，让我想起《荀子》中的一句话：\"君子生非异也，善假于物也。\"人之所以为人，正是因为我们善于制造和使用工具。AI不是异类，它是我们制造过的规模最大、能力最强的工具。\
\
然而，\"善假于物\"的前提是\"知物之性\"。工具本身没有善恶，有善恶的是使用工具的方式。大会上有一个细节让我印象深刻：一位演讲者说，AI可以在一秒钟内生成一篇八百字的作文，但它永远无法替代你真正经历过的那场雨------淋在身上的凉意、空气中泥土的味道、你当时心里的孤独或欢喜。技术可以模拟数据，但模拟不了体验。\

这就说到了第二个命题：科技最终是为了谁。\
\
黎家盈从太空发来的问候，恰好回答了这个问题。她在空间站从事的是载荷实验------那些实验有些关于生物生长，有些关于材料科学，最终都指向人类在地球上的生活能变得更好。AI也是一样。大会上展示的AI Home概念、地震预警AI系统、教育辅助AI------它们共同指向一个目标：让科技从\"炫技\"走向\"暖人\"。\

是的，技术能走很远。从地面的芯片到太空的问候，从算力的堆叠到算法的突破，我们正在跑一场没有终点的马拉松。但在这场马拉松的每一个补给站，都应该站着人------那些有温度、有判断、能说\"勇敢一点\"的人。\
\
科技应该让我们跑得更远，而不是让我们忘记了为什么出发。

这个细节让我想了很久。生活在一座随时可能喷发的火山脚下，是一种怎样的感受？\
\
我去查了资料。樱岛是日本最活跃的火山，平均每年喷发数百次。但在这座火山的山脚下，生活着约六十万人。他们种田、开店、上学、恋爱，生活如常。他们不是不害怕，而是学会了与恐惧共处。\
\
这让我想起《鲁滨逊漂流记》里的一句话：\"对危险的恐惧比危险本身更可怕一万倍。\"鲁滨逊在荒岛上面对野兽、地震、疾病，他当然害怕，但他选择去了解这座岛屿的规律------什么时候可以在户外活动，什么地方比较安全，什么植物可以吃。他做的不是消除危险，而是学会与危险共存。\
\
樱岛脚下的居民做的正是同样的事情。他们把火山灰收集起来做成建筑材料，用火山地热发电，甚至把火山景观发展成旅游资源。他们在敬畏与利用之间找到了平衡。这不是\"征服自然\"，而是与自然共生。\
\
这让我对中国古代张衡发明地动仪的故事有了新的理解。将近两千年前，张衡就认识到了一个道理：地震不是天怒，而是一种可以观测的自然现象。他的地动仪虽然不能预测地震，但它标志着人类开始用科学的目光看待自然灾难------这是从\"恐惧\"到\"理解\"的第一步。今天的火山监测仪、地震预警系统，都是张衡精神的延续。\
\
当然，我们这一代人极少有机会站在真正的火山脚下。但我们每个人都有自己的\"火山\"要去面对。它可能是一次重要的考试，可能是一段艰难的家庭处境，可能是一个让你夜不能寐的梦想。面对这些\"火山\"时，我们有两种选择：一是转身逃跑，永远活在恐惧中；二是像樱岛脚下的孩子们一样------在书包里放好护目镜和口罩，然后照常去上学。\
\
\"照常去上学\"这五个字，看似稀松平常，实则需要极大的勇气和智慧。因为它意味着你没有被恐惧击倒，你接受了\"火山就在那里\"的现实，你不打算浪费生命去害怕不可控的事，而是专注于自己能做的事------把今天的功课学好，把眼前的路走好。\
\
樱岛火山今天又喷发了，鹿儿岛的孩子们明天还会去上学。这就是人类面对自然最朴素也最坚韧的回答：我们不放弃家园，我们不放弃生活，我们不放弃希望。
