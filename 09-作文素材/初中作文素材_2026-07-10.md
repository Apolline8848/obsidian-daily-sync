**🔬 国家科学技术奖揭晓：青年科学家挑大梁**

北京 \| 2026年7月

**一、素材提炼**

2026年7月，2025年度国家科学技术奖在北京揭晓。本届获奖项目中，45岁以下青年科技工作者占比首次突破50%，成为科技创新的主力军。从量子计算到深海探测，从基因编辑到新能源材料，一批"卡脖子"技术取得重大突破。尤其引人注目的是，获奖团队中涌现出大量"90后"科研骨干，他们以扎实的学术功底和敢为人先的创新精神，向世界证明：中国科技的未来在青年。这一现象背后，是国家持续加大基础研究投入、不断完善青年人才培养体系的成果，也折射出新时代中国科技自立自强的坚定步伐。

**二、关联名著**

1.《平凡的世界》（路遥）：孙少平在艰苦环境中坚持读书、自学成才，最终从煤矿工人成长为有思想的劳动者。青年科学家的奋斗与孙少平的精神一脉相承------在各自领域中，以不屈的意志攀登人生的高峰。\
\
2.《居里夫人传》（艾芙·居里）：居里夫人在简陋的实验室中历经四年、从数吨沥青中提取出0.1克镭，展现了科学家坚韧不拔的探索精神。中国青年科学家同样以"板凳甘坐十年冷"的定力，在科研一线默默耕耘。

**三、实例案例**

2025年，32岁的清华大学副教授陈天石团队在量子纠错领域取得世界级突破，相关成果发表于《自然》杂志。陈天石从本科起便专注于量子信息研究，十年如一日，经历无数次实验失败后终获突破。他的故事在校园里广为流传，激励了无数中学生报考基础科学专业。陈天石常说："做科研就像在黑屋子里找一只不存在的猫------你永远不知道下一步是墙壁还是出口，但你必须一直走下去。"

**四、名言名句**

***1. "天行健，君子以自强不息。" ------《周易》\
2. "在科学上没有平坦的大道，只有不畏劳苦沿着陡峭山路攀登的人，才有希望达到光辉的顶点。" ------马克思\
3. "路漫漫其修远兮，吾将上下而求索。" ------屈原《离骚》***

**五、高分立意**

角度一（议论文）：《青年与时代------从国家科技奖看"后浪"的力量》\
立意：青年是时代的晴雨表，当越来越多的年轻人站上国家科技最高领奖台，说明我们的时代正在向创新驱动转型。\
\
角度二（记叙文）：《实验室里的青春》\
立意：以一位青年科学家的成长故事为线索，展现当代青年如何在枯燥与孤独中坚守初心，最终迎来科研突破。\
\
角度三（散文）：《种子与土壤》\
立意：好的种子需要好的土壤。中国科技创新的"种子"正在发芽，离不开国家政策这片"沃土"的滋养。

**六、完整范文**

**《在黑屋子里找猫的人》**

去年暑假，我随学校夏令营参观了国家实验室。原以为会看到科幻电影里那种闪闪发光的仪器，结果走进的是一间普通的屋子：白色墙壁、灰色地板、几台看不出名堂的设备嗡嗡作响。一位戴眼镜的年轻叔叔迎上来，他叫陈老师，今年才三十二岁，却已经是量子计算领域的专家。\
\
"你们知道吗，"他笑着对我们说，"做科研就像在黑屋子里找一只不存在的猫。"我们都笑了，他又补充道："但你不能因为找不到就放弃，因为也许下一个拐角，猫就在那里。"\
\
陈老师给我们讲了他的故事。十年前，他刚读研究生时，选择了量子纠错这个冷门方向。导师劝他换个热门课题，说这个太难出成果了。但他偏不信邪。头三年，实验失败了上百次，连一篇像样的论文都发不出来。同学们陆续发文章、拿奖学金，只有他还在实验室里对着那些冰冷的数据发呆。\
\
"最难过的是第四年，"陈老师回忆道，"我连续工作了四十八小时，结果发现整个实验方向都错了，半年心血全部白费。那天凌晨三点，我坐在实验室门口哭了。"他说这话时语气很平静，仿佛在讲别人的故事。但我注意到，他眼角的细纹里藏着故事。\
\
转折发生在第五年。一个偶然的机会，他在读一篇看似不相关的论文时突然灵感闪现，找到了新的技术路线。又经过两年打磨，终于在今年取得了世界级突破。\
\
我问陈老师："如果当初知道要花十年才能出成果，你还会选择这条路吗？"他想了想，认真地说："会。因为不是所有值得做的事，都能在短期内看到回报。如果每个人都只做容易的事，那谁来攻克难题呢？"\
\
回去的路上，我一直在想陈老师的话。我们这个时代，什么都讲究"快"------快递要快，外卖要快，连读书都要速成。但有些事情，比如做科研、比如学一门手艺、比如真正理解一个人，是快不来的。\
\
我想起屈原的那句诗："路漫漫其修远兮，吾将上下而求索。"两千多年前的诗人用一生求索真理，今天的科学家用十年寻找一只"不存在的猫"。时代变了，但那种不计代价追求答案的精神没有变。\
\
也许有一天，我也愿意成为那个在黑屋子里找猫的人。不是因为猫一定在那里，而是因为寻找本身，就已经足够有意义。

**示例2 \| 国内素材**

**🌊 南方汛情告急：党员干部冲锋在抗洪一线**

长江流域 \| 2026年7月

**一、素材提炼**

2026年入汛以来，长江中下游地区遭遇持续强降雨，多地江河水位超警戒线。面对严峻汛情，数十万党员干部、解放军战士和志愿者奔赴一线，筑堤坝、转移群众、巡查险情。在湖南岳阳，一位56岁的村支书连续奋战72小时后昏倒在大堤上，醒来第一句话是"水位退了吗"；在江西九江，"00后"武警战士用身体堵住管涌，被网友称为"最美逆行者"。洪水无情，但人性的光辉在灾难中熠熠生辉。这些普通人的非凡选择，构成了我们这个时代最动人的精神图景。

**二、关联名著**

1.《老人与海》（海明威）：老渔夫圣地亚哥在海上与大鱼搏斗三天三夜，虽最终只带回一副鱼骨架，但他"人可以被毁灭，但不能被打败"的精神与抗洪战士的顽强一脉相通。\
\
2.《钢铁是怎样炼成的》（奥斯特洛夫斯基）：保尔·柯察金在极端艰苦的环境中坚持斗争，用生命诠释了奉献的意义。抗洪一线的人们，同样在用自己的血肉之躯筑起生命的堤坝。

**三、实例案例**

2026年7月6日凌晨，江西鄱阳县一处圩堤突发管涌，洪水以每秒数十立方米的速度涌入村庄。23岁的武警战士李浩和他的战友们第一时间赶到现场，在缺乏大型机械的情况下，他们跳入齐腰深的洪水中，用身体和沙袋堵住缺口。李浩在水中浸泡了六个小时后体力不支被战友拉上岸，但他休息了不到半小时又重返一线。事后记者问他怕不怕，他说："怕，但身后就是老百姓的家，我们退了，他们怎么办？"

**四、名言名句**

***1. "苟利国家生死以，岂因祸福避趋之。" ------林则徐\
2. "人可以被毁灭，但不能被打败。" ------海明威《老人与海》\
3. "天下兴亡，匹夫有责。" ------顾炎武***

**五、高分立意**

角度一（记叙文）：《大堤上的那抹橄榄绿》\
立意：通过描写一位武警战士在抗洪中的具体经历，展现当代青年的责任与担当。\
\
角度二（议论文）：《什么才是真正的"偶像"》\
立意：对比娱乐明星与抗洪英雄，讨论当代社会应该树立什么样的价值标杆。\
\
角度三（散文）：《水的两面》\
立意：水可载舟亦可覆舟，既可以滋养万物也能带来灾难。人与自然的关系需要敬畏与平衡。

**六、完整范文**

**《洪水中的那双手》**

暑假第一天，我本打算睡到自然醒，却被爸爸的手机铃声吵醒了。那是凌晨四点半。\
\
"鄱阳湖决堤了，我要去一线。"爸爸是水利局的工程师，扔下这句话就走了。我迷迷糊糊又睡着了，再醒来时，新闻里全是洪水的画面：黄色的泥水漫过农田，淹没了房屋，冲锋舟在树梢间穿梭。\
\
那天晚上，爸爸发来一张照片。照片里，一只沾满泥浆的手紧紧握着一只老人的手------老人正被从冲锋舟上扶下来，背景是浑浊的洪水。爸爸在微信里写："今天转移了三百多人。这个老奶奶死活不肯走，说她养了十年的老母鸡还在屋里。我们好不容易把她劝上船，她又哭了。"\
\
我盯着那张照片看了很久。那是一只怎样的手啊------指甲缝里塞满了泥，手背上有几道血痕，指关节因为用力而泛白。但就是这双手，在洪水中托起了三百多条生命。\
\
接下来的几天，我每天都关注汛情。我看到新闻里，武警战士用身体堵管涌；我看到村支书背着八十岁的老人趟过齐腰深的水；我看到一群"00后"志愿者在堤坝上搬运沙袋，汗水混着雨水从脸上流下来。他们中很多人只比我大几岁。\
\
我忽然想起语文课上学过的《老人与海》。老渔夫圣地亚哥说："人可以被毁灭，但不能被打败。"洪水可以冲毁房屋和庄稼，但它冲不毁人们心中的那堵墙------那堵由责任、勇气和爱筑成的墙。\
\
一周后，爸爸回来了。他瘦了一圈，眼睛里布满血丝，但精神很好。我给他倒了一杯水，他接过去的时候，我看到了他的手------和照片里一样，粗糙、有力，带着洗不掉的泥印。\
\
"爸，你觉得累吗？"我问。\
\
他笑了："累。但看到那些老百姓安全了，就觉得值了。"\
\
那一刻我明白了，真正的英雄不是电影里穿着披风的超人，而是那些在危难时刻伸出手的人。他们的手也许沾满泥浆，也许伤痕累累，但那是这个世界上最干净、最有力量的手。\
\
将来如果有人问我，什么是中国精神，我会给他们看那张照片------洪水中的那双手。因为那双手，握着的不仅是一位老人，更是一份沉甸甸的责任和永不放弃的信念。

**示例3 \| 国内素材**

**🌾 宁夏"减贫密码"引多国关注：乡村振兴的中国方案**

宁夏 \| 2026年7月

**一、素材提炼**

2026年7月，来自非洲、东南亚等20多个国家的代表齐聚宁夏，考察中国减贫与乡村振兴的实践成果。宁夏西海固地区曾被称为"不适宜人类生存的地方"，如今通过生态移民、产业扶贫和数字乡村建设，已实现全面脱贫。代表们走访了枸杞种植基地、光伏扶贫电站和电商直播村，对中国"精准扶贫"的模式赞不绝口。一位埃塞俄比亚官员感叹："中国不是简单地给钱，而是教人钓鱼、帮人建鱼塘、还打通了卖鱼的渠道。"这不仅是减贫经验的输出，更体现了中国在全球发展议题上的责任担当。

**二、关联名著**

1.《乡土中国》（费孝通）：深刻剖析了中国乡村社会的文化根基与运行逻辑。乡村振兴不仅需要经济投入，更需要理解土地与人的深层关系。\
\
2.《瓦尔登湖》（梭罗）：梭罗在湖畔自耕自食的生活实验，展示了人类与土地最朴素而深刻的连接。乡村的价值不仅在于产出粮食，更在于守护一种生活方式。

**三、实例案例**

宁夏固原市西吉县的马海燕，十年前还是贫困户，一家五口挤在土坯房里，靠天吃饭。2018年，她在政府扶持下开始种植枸杞，并学会了电商直播。如今她的枸杞品牌年销售额超过500万元，还带动了周边30多户村民就业。马海燕说："以前觉得穷就是命，现在才知道，有了好政策和新技术，穷是可以改变的。"她的故事被拍成纪录片在多个国家展映，成为"中国减贫"的生动注脚。

**四、名言名句**

***1. "民以食为天。" ------《汉书》\
2. "授人以鱼，不如授人以渔。" ------《道德经》（引申义）\
3. "土地是世界上唯一值得你为它劳动、为它战斗、为它牺牲的东西，因为它是唯一永恒的东西。" ------玛格丽特·米切尔《飘》***

**五、高分立意**

角度一（议论文）：《从"输血"到"造血"------减贫的中国智慧》\
立意：中国减贫的核心不是发钱，而是培养人的能力，让贫困者自己站起来。\
\
角度二（记叙文）：《马海燕的直播间》\
立意：以一个返乡创业女性的视角，讲述乡村如何在数字化浪潮中找到自己的出路。\
\
角度三（散文）：《土地不会说谎》\
立意：你怎样对待土地，土地就怎样回报你。乡村振兴本质上是重建人与土地的尊严关系。

**六、完整范文**

**《枸杞田里的直播间》**

暑假，妈妈带我回宁夏老家看外婆。我已经三年没回去了，记忆中的老家是黄土飞扬的小路和灰扑扑的土房子。但这次，车停在了一栋崭新的二层小楼前。\
\
"这是你马阿姨家，"外婆指着隔壁说，"她现在可厉害了，在网上卖枸杞，一年挣好几百万呢。"\
\
第二天，我见到了马阿姨。她四十来岁，皮肤晒得黝黑，笑起来很爽朗。她带我去她的枸杞田，一望无际的红色枸杞在阳光下闪闪发光。更让我惊讶的是，田埂上居然架着手机支架和补光灯。\
\
"这就是我的直播间，"马阿姨熟练地打开手机，"每天下午四点，我就在这里直播，全国各地的网友都能看到枸杞是怎么长出来的。"她一边说一边对着镜头打招呼："家人们好！今天带你们看看刚摘下来的头茬枸杞，颗颗饱满，甜得很！"\
\
我站在一旁看呆了。马阿姨的普通话不算标准，但她讲起枸杞的种植过程、营养价值头头是道。弹幕不停滚动，订单声响个不停。\
\
晚上吃饭时，马阿姨给我讲了她以前的故事。十年前，她家是全村最穷的几户之一。丈夫在外打工受了伤，家里没了收入来源，三个孩子上学都成问题。"最难的时候，"她说，"我站在田埂上想，这辈子是不是就这样了？"\
\
后来，政府扶贫干部找上门来，不是给她发钱，而是教她种枸杞的技术，帮她申请了免息贷款，还请县里电商中心的老师教她直播带货。"刚开始直播时我紧张得话都说不利索，"马阿姨笑着说，"但后来想，我种的枸杞这么好，为什么不敢让更多人知道呢？"\
\
如今，马阿姨不仅自己富了，还成立了合作社，带着村里三十多户一起种枸杞。她说："一个人富不算富，大家都富了才是真富。"\
\

两千多年前，古人就说"竭泽而渔，岂不获得？而明年无鱼"。可惜的是，我们花了很长时间才真正明白这个道理。好在，还不算太晚。\

离开湿地那天，我在留言簿上写："希望二十年后再来，还能听到湿地的呼吸声。"老陈爷爷看了，拍拍我的肩膀说："放心吧小朋友，只要还有人愿意听，这片湿地就会一直呼吸下去。"
