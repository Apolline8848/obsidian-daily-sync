**示例1 \| 国内素材**

**🎓 2026年暑假开启：全国1.5亿中小学生迎来成长季**

时间：2026年7月初 \| 地点：全国 \| 类型：国内·时事热点

**一、素材提炼**

2026年7月，全国1.5亿中小学生迎来暑假。教育部联合文旅部推出"暑假成长计划"，倡导学生利用假期参与社会实践、阅读经典、锻炼身体。各地图书馆、博物馆、科技馆纷纷推出青少年专场活动，研学旅行报名人数同比增长35%。专家指出，暑假不应该是"第三学期"，而应是孩子探索兴趣、发展个性的黄金窗口。在"双减"政策持续深化的背景下，越来越多的家长开始关注孩子的全面发展而非单纯的分数竞争。

**二、关联名著**

《童年》（高尔基）------主人公阿廖沙在困苦的童年中依然保持着对世界的好奇与热爱。暑假正是孩子们像阿廖沙一样，走出课本、拥抱真实生活的好时机。高尔基写道："我把自己埋进书本里，就像饥饿的人扑在面包上。"假期的自由阅读，恰是精神成长的盛宴。\
《窗边的小豆豆》（黑柳彻子）------巴学园的校长让孩子在暑假自由探索，去田野里奔跑、去河边捉鱼。这种"不教而教"的理念，与今天"把暑假还给孩子"的呼声一脉相承。

**三、实例案例**

案例：北京初二学生李明去年暑假没有上补习班，而是参加了社区组织的"胡同文化守护者"志愿活动。他用两个月时间走访了20条胡同，拍摄了500多张照片，整理出一本《消失中的胡同记忆》小册子，被区图书馆收藏。李明说："那个暑假我学到了教科书上永远学不到的东西------关于历史、关于人情、关于一座城市的呼吸。"他的经历被《中国教育报》报道，成为"双减"后暑假生活的典范。

**四、名言名句**

***「教育不是注满一桶水，而是点燃一把火。」------叶芝***

***「读万卷书，行万里路。」------董其昌***

***「大自然希望儿童在成人以前就要像儿童的样子。」------卢梭***

**五、高分立意**

立意一：《暑假，是一本无字的书》------以记叙文写自己在暑假中的一段特别经历，展现"生活即教育"的主题。\
立意二：《"补"与"不补"之间》------以议论文讨论补习班盛行的利弊，提出教育不应只有一种尺度的观点。\
立意三：《慢下来的时光》------以散文形式描写暑假中那些没有被计划填满的时刻，体现"留白"的价值。

**六、完整范文**

**《那个没有补习班的夏天》（记叙文）**

初一结束的那个暑假，我做了一个让妈妈皱眉的决定：不报任何补习班。\
\
"你不补，别人都在补，开学你就跟不上了。"妈妈把一叠补习班传单拍在桌上。我看了看那些花花绿绿的广告------"20天搞定初二数学""暑假英语提分特训营"------心里泛起一阵说不出的烦躁。\
\
"妈，我想用这个暑假做点不一样的事。"\
\
妈妈最终妥协了，但她给我布置了一个任务：每天必须写一篇日记，记录自己做了什么。\
\
于是，那个夏天变得格外漫长而丰盈。\
\
第一个星期，我跟着爷爷学书法。爷爷八十岁了，手有点抖，但写出来的字依然苍劲有力。他教我握笔时说了一句："字如其人，字站稳了，人也就站稳了。"我每天练两小时，从歪歪扭扭到渐渐像样。爷爷看着我的进步，笑眯眯地说："比你爸当年强。"\
\
第二个星期，我加入了社区志愿者队，和几个高中生哥哥姐姐一起去河边捡垃圾。七月的太阳火辣辣的，塑料袋、饮料瓶、废弃的渔网------我们弯着腰捡了整整一下午。汗水湿透了衣服，但看到清理后的河岸变得干净清爽，那种成就感是考满分都无法替代的。\
\
第三个星期最特别------我去了乡下外婆家。外婆家没有WiFi，手机信号只有两格。起初我焦躁不安，但渐渐地，我开始享受这种慢下来的生活。清晨跟外婆去菜园浇水，看露珠在叶子上滚动；午后躺在竹椅上读书，蝉鸣是唯一的背景音；傍晚爬到后山看日落，云彩被染成橘红色，像一幅流动的油画。\
\
外婆说："娃啊，你看这太阳，每天按时升起、按时落下，不急不躁。人也一样，该快的时候快，该慢的时候慢。"\
\
开学前一天，我翻开暑假日记本------整整55篇，没有一天中断。最后一篇我写道："这个暑假，我没有多学一个字、多做一道题，但我学会了写毛笔字、学会了辨认三种鸟叫、知道了河水从哪里来到哪里去------这些，都是书本上学不到的功课。"\
\
初二第一次月考，我的成绩并没有下滑。妈妈惊讶地问："不补课也能考这么好？"我笑了笑："妈，我补了，只不过补的不是课。"\
\
那个没有补习班的夏天，成了我记忆中最珍贵的一页。它让我明白：成长从来不只是分数的增长，更是心灵的开阔。

**示例2 \| 国内素材**

**🤖 中国AI大模型助力教育公平：乡村课堂迎来智能助教**

时间：2026年6月底 \| 地点：全国 \| 类型：国内·科技创新

**一、素材提炼**

2026年6月，教育部宣布启动"AI助教进乡村"计划，首批覆盖全国5000所乡村学校。由中国自主研发的AI大模型为每个学生生成个性化学习方案，可实时批改作文、纠正英语发音、解答数理难题。在贵州毕节的一所山区小学，AI助教帮助语文老师在一个月内将全班作文平均分提升了8分。与此同时，社会上关于"AI会不会取代教师"的讨论也在持续升温。教育专家指出：AI解决的是"教"的效率问题，而"育"的温度永远需要真人来传递。

**二、关联名著**

《海底两万里》（儒勒·凡尔纳）------尼摩船长的"鹦鹉螺号"是人类科技想象的巅峰，但它终究需要人来驾驶。AI正如潜艇，是强大的工具；但决定航向的，永远是人的心灵。\
《师说》（韩愈）------"师者，所以传道授业解惑也。"AI可以"授业解惑"，但"传道"------传递价值观、塑造人格、给予关怀------这些永远需要教师来完成。

**三、实例案例**

案例：云南昭通市鲁甸县的一名留守儿童小雨，父母都在外打工，她跟着奶奶生活。学校引入AI助教后，小雨每天课后用平板和AI对话练英语口语。三个月后，她的英语成绩从不及格提升到78分，还在全县英语演讲比赛中获得二等奖。小雨说："AI老师不会嫌我笨，我问一百遍它都会回答。但我最想要的，还是妈妈能回来给我开一次家长会。"这番话让许多人动容------AI可以拉平知识的差距，却无法填补情感的缺失。

**四、名言名句**

***「教育的艺术不在于传授本领，而在于激励、唤醒和鼓舞。」------第斯多惠***

***「技术是人类的延伸，而非替代。」------麦克卢汉***

***「善用器者，不伤于器。」------中国古语***

**五、高分立意**

立意一：《AI来了，老师还在》------以记叙文写AI助教进入课堂后的变化与不变，落脚到师生情谊的不可替代。\
立意二：《科技这把双刃剑》------以议论文探讨AI对教育的影响，既要拥抱技术红利，也要警惕技术依赖。\
立意三：《我与AI同学》------以科幻视角写自己与AI共同学习的故事，展现人机协作的未来图景。

**六、完整范文**

**《看不见的黑板》（议论文）**

朋友，你有没有想过这样一个问题：如果有一天，站在讲台上的不再是老师，而是一台机器，你会感到庆幸还是失落？\
\
2026年，AI助教走进了全国五千所乡村学校。它能一秒批改作文，能听懂各种口音的英语，能在深夜两点回答学生的问题。新闻里，乡村孩子的成绩在上升，这是事实。有人欢呼：教育公平终于来了。但我却在想另一个问题：教育仅仅等于知识的传递吗？\
\
韩愈在《师说》中开篇说："师者，所以传道授业解惑也。"请注意这个顺序：传道在先，授业解惑在后。AI可以完美地完成后面的"授业解惑"，但"传道"是什么？传道是老师看到你垂头丧气时，走过来拍拍你的肩膀问一句"怎么了"；是老师发现你的作文里藏着心事，下课后把你叫到办公室聊天；是老师在毕业典礼上抱着你说"老师相信你一定行"时，那种让人鼻子一酸的温暖。\
\
AI的黑板可以无限大、无限清晰，但它是一块看不见的黑板------因为它永远照不出人的灵魂。\
\
有人会说：你这是保守，是拒绝进步。不，我不是反对AI。恰恰相反，我认为AI是教育史上最伟大的发明之一------它让贵州山区的孩子和北京的孩子拥有了同等的知识资源，它让每一位学生都能拥有专属的"辅导老师"。这些，都是了不起的进步。\
\
但我坚持的只有一点：AI应该做它擅长的事，而人应该做人擅长的事。\
\
就像《海底两万里》中的"鹦鹉螺号"------它是当时世界上最先进的潜艇，但尼摩船长才是决定它航向的人。AI是船，教师是舵手。船越先进，舵手越重要，因为走得越远，方向越不能出错。\
\
我理想中的课堂是这样的：AI负责教知识，老师负责教做人。AI告诉你什么是三角函数，老师告诉你为什么要学三角函数。AI纠正你的语法错误，老师理解你为什么要写那篇关于妈妈的作文。AI为你的每一道错题打上标记，老师看到这些标记后，走到你身边说："没关系，我们再来一次。"\
\
所以，答案是：AI来了，老师不会消失。\
\
因为教育的本质，从来不是注满一桶水，而是点燃一把火。而能点燃火的，只能是另一团火。

**示例3 \| 国内素材**

**🏮 非遗进校园：00后、10后成了传统文化"守艺人"**

时间：2026年6月 \| 地点：全国 \| 类型：国内·文化传承

**一、素材提炼**

2026年"文化和自然遗产日"前后，全国各地中小学掀起非遗进校园热潮。从苏州的苏绣到陕西的皮影戏，从福建的南音到四川的蜀锦，越来越多的非遗项目走进课堂，成为校本课程。据统计，全国已有超过12万所中小学开设了非遗相关课程，参与学生超过3000万人次。更令人欣喜的是，不少00后、10后不仅在学习传统技艺，还在用短视频、直播等新方式传播非遗文化------传统与潮流的碰撞中，古老技艺焕发出青春活力。

**二、关联名著**

《红楼梦》（曹雪芹）------大观园中处处可见传统工艺的身影：晴雯补裘的巧手、黛玉调香的雅致、宝玉赏玩的各色器物。这些精致的文化细节，正是非遗的文学呈现。\
《朝花夕拾》（鲁迅）------鲁迅在书中深情回忆了故乡的社戏、年俗、民间故事。那些带着泥土气息的文化记忆，是一个人精神世界的底色。非遗就是我们民族的"朝花"，值得每一代人"夕拾"。

**三、实例案例**

案例：杭州初二学生张一涵，从小学五年级开始学习西湖绸伞制作技艺。她的老师是国家级非遗传承人宋师傅，已经78岁了。张一涵在抖音上开设账号"小涵学绸伞"，用短视频记录学习过程------从劈竹、制骨到蒙面、绘画，每个步骤都拍得细致入微。两年多来，她的账号积累了30万粉丝，其中一半是同龄人。宋师傅欣慰地说："我以为这门手艺会断在我手里，没想到被这群娃娃接过去了，还传得比我更远。"张一涵则说："我做的不是一把伞，是一把打开传统文化大门的钥匙。"这对祖孙的故事被央视《非遗里的中国》专题报道，感动了无数观众。

**四、名言名句**

***「周虽旧邦，其命维新。」------《诗经》***

***「不忘本来才能开辟未来，善于继承才能更好创新。」------习近平***

***「传统不是守住炉灰，而是传递火焰。」------托马斯·莫尔***

**五、高分立意**

立意一：《一把伞的重量》------以记叙文写自己或同学学习非遗技艺的经历，展现"传承"二字的千钧分量。\
立意二：《老手艺·新表达》------以议论文探讨传统技艺如何在当代社会找到新的生命力，强调创新的必要性。\
立意三：《我与传统的一次对话》------以散文形式写与传统文化的邂逅，表达文化自信和身份认同。

**六、完整范文**

**《守艺人》（记叙文）**

宋爷爷的手抖得很厉害。\
\
那是去年秋天的一个下午，我第一次走进他在西湖边的绸伞作坊。满墙的绸伞像一片片盛开的睡莲，在午后的阳光里静静绽放。但宋爷爷的右手一直在发抖------那是做了六十年绸伞落下的职业病。\
\
"孩子，你来学这个？"他有些惊讶地看着我，"现在谁还学这个啊。"\
\
我是学校非遗社团的成员，老师让我们每人选择一门传统技艺深入学习。当我在非遗名录上看到"西湖绸伞"四个字时，眼前浮现出外婆撑着绸伞在雨巷里行走的画面------那是属于江南的诗意。\
\
宋爷爷说，一把绸伞有18道工序，每道工序都有讲究。选竹要在冬至后，劈篾要顺着纹理，制骨要三十六根一样粗细，蒙面要绷得紧而不皱。最难的是给伞面绘画------毛笔蘸着矿物颜料，在薄如蝉翼的丝绸上画出一朵荷花、一只蝴蝶，不能有一丝偏差。\
\
第一周，我只学了劈竹。竹子在刀下裂开的声音很清脆，像冬天冰面碎裂的声响。我的手被竹刺划破了好几次，宋爷爷一边给我贴创可贴，一边说："我当年学的时候，十个手指头没一个好的。"\
\
第二周，我开始学制骨。三十六根伞骨要排成一个圆，每根间距必须一模一样。我做了拆、拆了做，三天下来的成果被宋爷爷一句话否定了："歪了，重来。"我眼泪在眼眶里打转，但想到了《红楼梦》里晴雯补裘时的专注------那份把一件事做到极致的精神，正是我要学的。\
\
一个月后，我终于做成了一把完整的绸伞------伞面上画着一枝斜斜的红梅。宋爷爷把伞举起来对着光看了看，轻轻点头："还行。"这是几个月来我听到的最高评价。\
\
半年后，我的抖音号"小涵学绸伞"有了30万粉丝。每天都有同龄人给我留言："姐姐好厉害！""原来绸伞这么美！""暑假我也想去学！"我把这些留言读给宋爷爷听时，他沉默了很久，然后擦了擦眼角。\
\
"我这辈子最大的遗憾，就是怕这门手艺断在我手里。现在好了，有你们这群娃娃了。"他顿了顿，又加了一句："你们比我强------我只会在作坊里做，你们能让全世界都看到。"\
\
