## **素材1：长征十号乙火箭首获海上可控回收**

国家：中国\
时间：2026年7月10日

**├─ 素材提炼**

2026年7月10日12时15分，长征十号乙运载火箭在海南商业航天发射场成功发射。发射约八分钟后，海上回收平台通过「网系捕获」方式，精准回收了火箭一子级。这是中国运载火箭首次实现海上可控回收，标志着中国航天在火箭重复使用技术上取得历史性突破。\
\
在火箭回收海域，新华社记者邢广利乘坐「牧海号」保障船，经历了一天一夜的颠簸航行。由于台风影响，海况恶劣，记者严重晕船，但依然坚持完成拍摄任务。回收船「领航者号」上，技术人员通力协作，在海上风浪中安装遥控相机和卫星通信设备。\
\
火箭回收那一刻，一道白线贯穿天空，火箭喷着火焰从画面右上方进入取景框，稳稳落入网系回收系统，底部冒出巨大烟雾。现场欢呼声与哽咽声交织，无数航天人数十年的付出凝结于此。这一技术的突破，意味着中国成为继美国之后第二个掌握火箭海上回收技术的国家。\
\

那个在海上颠簸的身影\
\
深夜的三亚码头，海风带着咸味扑面而来。邢广利背着沉重的摄影器材和卫星通信设备，踏上「牧海号」保障船的甲板。船身在夜色中轻轻摇晃，他深吸一口气------这是一趟注定不平凡的航程。\
\
凌晨四点，牧海号起锚。邢广利在睡梦中被发动机的轰鸣唤醒，醒来时已是上午十点。眩晕如潮水般涌来，天花板在旋转，胃里翻江倒海。同屋的伙伴打来热水，从食堂带了玉米，他却一口也咽不下。领队鲁佳明送来晕船药，他勉强服下，却还是在厕所吐得天昏地暗。最惊险的一次，他眼前一黑，差点晕倒在狭窄的过道里------幸好及时扶住了墙壁。\
\
「你不是说不怕晕船吗？」同伴半开玩笑地问。邢广利苦笑。他曾在南海上工作一个半月，以为自己早已免疫。可这一次，台风搅动了整片海域，浪高三四米，船舱里的每一件物品都在疯狂摇晃。一天一夜，三顿饭滴水未进，他终于明白：在大海面前，人类的自信多么微不足道。\
\
然而，更难的任务还在后面。到达预定海域后，邢广利发现，所有记者都不被允许登上回收船「领航者号」------海浪太大，过驳用的软梯子被风浪打得疯狂摆荡，工人从小艇爬上回收船，不到二十个人竟用了整整三个小时。看着小艇在大浪中时隐时现，他理解了这条禁令的分量：不是不信任，而是保护。\
\
卫星天线重达几十公斤，需要焊接到甲板上。没有人手，邢广利和船长、电工一起搬运设备。烈日炙烤着甲板，汗水顺着额头滴落，他干脆坐到甲板上喘气。技术同事吴聪杰调试卫星设备，却发现海上没有手机信号，4G遥控完全失灵。\
\
「那只能用无人机飞过去了。」邢广利咬牙做出决定。可是，回收船距离十公里，无人机理论航程虽然够，但海风大、信号杂，任何意外都会让价值不菲的无人机葬身大海。他反复测试、细化方案：火箭发射同时起飞，以60公里时速飞行八分钟，拍摄回收画面后立即逆风返航，电池剩70%就绝不多停留。\
\
7月10日中午12点15分，发射时刻终于到来。邢广利站在烈日下的甲板上，双手紧抱栏杆对抗摇晃，眼睛盯着手表------每一秒都像一年那样漫长。网络延迟看不到直播，对讲机一片静默。他果断将无人机升空，80米高度，定速巡航。\
\
七分钟后，有人大喊：「火箭来了！」邢广利猛然抬头------一道绵长的白线从左至右贯穿整片天空。他让无人机悬停，屏住呼吸。下一秒，火箭喷着烈焰从画面右上方闯入取景框，带着两声巨响，稳稳落入网系回收系统！巨大的烟雾从火箭底部翻涌而出，甲板上爆发出山呼海啸般的欢呼，其间夹杂着压抑已久的哽咽。\
\
邢广利的手在颤抖。他让无人机飞得更近一些，拍下那历史性的画面，然后迅速逆风返航。返程途中，他看了一眼取景器里的画面：简洁、流畅，美得如同CG动画。后来有网友质疑这是AI生成的------他们不知道，这不到30秒的画面背后，是多少人在海上颠簸了多少天。\
\
回到三亚港，邢广利终于拿到了回收船上相机拍摄的素材。当火箭稳稳落入网系的画面在屏幕上展开时，他的眼眶湿润了。所有的晕船、呕吐、恐惧、疲惫，在这一刻都化作了值得。他想起钱学森先生的那句话：「外国人能搞的，难道中国人不能搞？」是的，中国人不仅能搞，还能在台风肆虐的南海之上，完成全世界最优雅的火箭回收。\
\
那个在海上颠簸的身影，不只是一个记者的身影，更是千千万万中国航天人的缩影。他们在大风大浪中坚守，在无人看见的地方付出，只为让五星红旗在星辰大海中飘扬。

## **素材2：台风「巴威」来袭，全民防汛防灾**

**├─ 新闻基本信息**

发生地：中国福建/浙江沿海\
国家：中国\
时间：2026年7月11日

**├─ 素材提炼**

2026年第4号台风「巴威」（强台风级）于7月11日凌晨在福建沿海登陆，中心最大风力达14级（45米/秒），带来狂风暴雨和大范围风暴潮。福建省紧急关闭沿海景区，加固电力设施，转移危险区域群众数十万人。交通运输部启动强降雨一级防御响应，浙江、江西、安徽等省同步做好防汛准备。\
\
在福建宁德，基层党员干部组成抢险突击队，冒雨巡查海堤、转移低洼地带居民。一位老党员在劝说独居老人撤离时说：「我背您走，一个都不能少。」在泉州，电力工人在风雨中抢修受损线路，确保医院和避难所供电。舟山群岛的渔民将数千艘渔船全部回港避风，互帮互助固定缆绳。\
\
台风来临前夕，国家气象中心提前72小时发布预警，手机短信、电视、广播、社交媒体全渠道推送，为各地争取了宝贵的准备时间。截至7月11日晚，台风路径上的受灾地区无一人因灾死亡，创造了近年来台风防灾的最好纪录。\
\
核心精神：人民至上、生命至上、众志成城、守望相助。体现的价值观包括责任担当、集体主义、科学精神和人文关怀。

开头：以台风「巴威」中实现「零死亡」的新闻引入，提出核心论点：生命的价值在于被守护，而守护的力量来自每一个人的担当。

坚守在风雨中\
\
2026年7月11日，台风「巴威」携14级狂风登陆福建。风雨过后，一个数字令人振奋：零死亡。在这个每年夺走无数生命的自然灾害面前，「零死亡」是一个了不起的奇迹。它告诉我们：灾难虽然不可完全避免，但生命可以被守护------而守护的力量，来自每一个在风雨中坚守的普通人。\
\

整合分析：可可西里是一个成功的案例------通过人类的努力，一个物种得到了拯救；欧洲热浪则是一个正在恶化的趋势------如果人类不改变行为方式，更多物种包括人类自己都将面临危机。人与自然不是对立的，而是命运相连的------伤害自然就是伤害自己，守护自然就是守护未来。

# **第三部分：中考实战模拟**

以下为3道基于今日素材命制的中考作文模拟题，建议每周选1题进行限时训练（60分钟）。

## **模拟题1**

阅读下面的材料，根据要求写作。（60分）\
\
2026年7月10日，长征十号乙运载火箭在海上成功回收。参与报道的记者在台风中晕船到几乎晕倒，却依然坚持完成拍摄。他说：「所有的颠簸和付出，都值得。」\
可可西里的巡护队员在海拔4600米的生命禁区中坚守数十年，他们说：「看到藏羚羊在草原上奔跑的样子，一切辛苦都值得。」\
\
在你的生活中，是否也有过「值得」的时刻？请以「值得」为题，写一篇文章。\
\
要求：①文体不限（诗歌除外）；②不少于600字；③不得抄袭、套作。

**审题指导**

【审题指导】\
关键词：「值得」------这是一个价值判断词，意味着付出与回报之间的衡量。\
材料提供了两个角度：记者的「值得」是职业使命感的实现，巡护队员的「值得」是对生命价值的守护。\
你可以写自己的经历------比如坚持练琴多年后的一次成功演出、帮助他人的一次经历、克服困难后的一次突破。\
核心技巧：不要只写「结果」，要重点写「过程」------正是过程的艰辛，才让结果的「值得」显得珍贵。\
推荐文体：记叙文。用一个具体的故事来承载「值得」这个抽象的主题。

## **模拟题2**

阅读下面的材料，根据要求写作。（60分）\
\
委内瑞拉发生大地震后，中国国际救援队跨越万里赶赴灾区。一位灾民说：「感谢中国，我们有了临时安身之处。」\
欧洲极端热浪中，志愿者走上街头为无家可归者送水。\
\
有人说：「我们帮助别人，是因为我们都是地球村的居民。」\
也有人说：「自己的生活都顾不过来，哪有精力管别人的事。」\
\
对此，你有怎样的思考和感悟？请写一篇文章。\
\
要求：①自选角度、自拟题目；②文体不限（诗歌除外）；③不少于600字。

**审题指导**

【审题指导】\
核心矛盾：「帮助远方的人」vs「管好自己的事」------这其实是「利己」与「利他」的经典辩论。\
材料立场明显------通过灾民的感谢和志愿者的善举，肯定了「帮助他人」的价值。\
但写作时不要简单地「站队」，而要辩证思考：帮助他人和自我发展并不矛盾，人类命运共同体意味着「帮助他人」最终也是在「帮助自己」。\
推荐文体：议论文。论点清晰（应该帮助他人）、论据充分（引用材料中的事例）、论证有力（逻辑递进）。\
参考立意：①无穷的远方与我有关；②善意无国界；③一个人可以走得很快，但一群人才能走得更远。

## **模拟题3**

阅读下面的材料，根据要求写作。（60分）\
\
比利时足球「黄金一代」在2026年世界杯谢幕，他们四届世界杯的最佳成绩是季军，从未夺冠。但球迷打出的横幅却是：「感谢你们，陪伴了我们整个青春。」\
秘鲁的藤森庆子四次参加总统选举，前三次均以失败告终，第四次终于成功。\
\
这两个故事引发了你怎样的联想和思考？请结合你的生活体验，写一篇文章。\
\
要求：①自选角度、自拟题目；②文体不限（诗歌除外）；③不少于600字。

**审题指导**

【审题指导】\
两个材料的共同内核：坚持的价值。区别在于------比利时队「坚持但未到达终点」，藤森庆子「坚持并最终成功」。\
这提供了两个写作角度：①坚持不一定成功，但坚持本身就是意义（过程论）；②坚持终有回报（结果论）。\
最佳策略：不是简单地选一边，而是将两个角度融合------无论结果如何，坚持都让人生更加丰盈。\
推荐文体：议论文或记叙文均可。议论文可以用材料的对比来论证；记叙文可以写自己一次坚持的经历。\
参考立意：①输赢之外；②等待花开；③无冕之王亦英雄。
