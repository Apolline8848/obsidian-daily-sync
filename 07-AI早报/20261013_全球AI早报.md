🏢 哈佛大学 / Jellyfish \| 📅 2026年10月9日 \| 📂 🔬 前沿研究

📰 Harvard study: AI coding agents write 30% more code but ship no more software

**【摘要】**

哈佛大学与数据分析公司 Jellyfish 发布首份企业级大规模实证研究，覆盖 700 多家软件公司、70 万名员工的逾 3 亿条工作事件。结果显示：引入 AI 编程代理后，代码行数增加 30%、提交次数增加 20%、拉取请求增加 23%，但「交付的软件产出」并未提升------已解决的 Jira 工单数量持平，产出增幅超过 12% 的假设被统计排除。根源是「代码审查瓶颈」：审查耗时增加 49%、修改请求近乎翻倍，人工审查无法被 AI 审查工具替代。

**【技术要点】**样本：718 家公司、70 万员工、3 亿+工作事件；核心发现：代码量 +30%、提交 +20%、PR +23%，但已解决工单无增长；审查时间 +49%、修改请求近翻倍。
