**每日数学题（八年级上册·北师大版）· 2026年10月25日**

------ 周末社区体育馆·羽毛球与健身 ------

**一、题目**

【生活情境】周末，小华和爸爸一起去社区体育馆锻炼。体育馆里有羽毛球场、乒乓球室和健身区。他们先在场馆导览图上找位置，接着预约场地，再测量球场地板、观察场地边线，最后还统计了本周来馆健身的人数。请你帮他们解决下面四个问题（每题覆盖一个不同的章节）。

**第1题（第三章·位置与坐标）**

体育馆以大厅入口为原点 O 建立平面直角坐标系（单位：米），正东为 x 轴正方向，正北为 y 轴正方向。

\(1\) 羽毛球场的中心 A 坐标为（−3，2）。写出点 A 关于 y 轴对称的点 A′ 的坐标，并指出点 A′ 位于第几象限；

\(2\) 乒乓球室入口 B 的坐标为（1，−2）。把点 B 向右平移 4 个单位、再向上平移 3 个单位，到达健身区入口 C。求点 C 的坐标，并指出点 C 位于第几象限。

**第2题（第五章·二元一次方程组）**

体育馆售票处出售两种场地球票：羽毛球场地票和乒乓球场地票。小华家买 2 张羽毛球票和 3 张乒乓球票共花 66 元；又买 3 张羽毛球票和 2 张乒乓球票共花 64 元。求羽毛球场地票和乒乓球场地票的单价各是多少元。（请列出二元一次方程组并求解）

**第3题（第六章·数据的分析）**

小华记录了本周社区体育馆连续 6 天来健身的人数（单位：人）：44，44，45，45，45，47。

\(1\) 求这组数据的平均数、中位数和众数；

\(2\) 求这组数据的方差，并指出哪一天来健身的人数偏离平均数最远。

**第4题（第七章·证明（平行线））**

羽毛球场地面上有两条平行的边线 a 和 b，一条横跨两条边线的中线（截线）c 与它们都相交。

\(1\) 小华测得直线 c 与 a、b 相交形成的一对内错角 ∠1 = ∠2 = 72°。请判断 a 与 b 是否平行，并说明依据；

\(2\) 已知 a ∥ b，∠2 = 72°，∠3 与 ∠2 是一对同旁内角。求 ∠3 的度数；

\(3\) 场馆内有一块三角形指示牌 △ABC，量得 ∠A = 72°、∠B = 46°。求 ∠C 的度数，并说明依据的定理。

**二、答案与解析**

**第1题（第三章·位置与坐标）**

【解析】(1) 关于 y 轴对称的点：横坐标变为相反数、纵坐标不变。所以 A(−3，2) 关于 y 轴对称的点 A′ = (3，2)。因为 A′ 的横坐标 3 \> 0、纵坐标 2 \> 0，符号为（+，+），所以 A′ 位于第一象限。

\(2\) 点的平移规律「右加左减、上加下减」：向右平移 4 个单位，横坐标 1 + 4 = 5；向上平移 3 个单位，纵坐标 −2 + 3 = 1。所以 C(5，1)。因为横坐标 5 \> 0、纵坐标 1 \> 0，所以 C 位于第一象限。

答：① A′(3，2)，位于第一象限；② C(5，1)，位于第一象限。

**第2题（第五章·二元一次方程组）**

【解析】设羽毛球场地票每张 x 元，乒乓球场地票每张 y 元。由题意列方程组：

2x + 3y = 66　......①

3x + 2y = 64　......②

用加减消元法：①×3 得 6x + 9y = 198；②×2 得 6x + 4y = 128。两式相减：

(6x + 9y) − (6x + 4y) = 198 − 128，即 5y = 70，解得 y = 14。

把 y = 14 代入①：2x + 3×14 = 66，即 2x + 42 = 66，2x = 24，解得 x = 12。

检验：3×12 + 2×14 = 36 + 28 = 64，符合②。

答：羽毛球场地票每张 12 元，乒乓球场地票每张 14 元。

**第3题（第六章·数据的分析）**

【解析】(1) 平均数 = (44 + 44 + 45 + 45 + 45 + 47) ÷ 6 = 270 ÷ 6 = 45（人）。

把这 6 个数据从小到大排列：44，44，45，45，45，47。中间两个数都是 45，所以中位数 = (45 + 45) ÷ 2 = 45（人）。

45 出现了 3 次，次数最多，所以众数是 45 人。

\(2\) 各数据与平均数 45 的差分别为：−1，−1，0，0，0，+2；差的平方分别为 1，1，0，0，0，4。

方差 = (1 + 1 + 0 + 0 + 0 + 4) ÷ 6 = 6 ÷ 6 = 1。

其中 47 与平均数相差 2 人，偏离最远（其余数据偏离都不超过 1 人），所以第 6 天（47 人）偏离平均数最远。

答：平均数、中位数、众数均为 45 人；方差为 1；第 6 天（47 人）偏离平均数最远。

**第4题（第七章·证明（平行线））**

【解析】(1) 因为 ∠1 与 ∠2 是一对内错角，且 ∠1 = ∠2 = 72°，根据平行线的判定「内错角相等，两直线平行」，所以 a ∥ b。

\(2\) 因为 a ∥ b，∠2 = 72°，∠3 与 ∠2 是一对同旁内角，根据平行线的性质「两直线平行，同旁内角互补」，所以 ∠2 + ∠3 = 180°，∠3 = 180° − 72° = 108°。

\(3\) 在 △ABC 中，∠A = 72°、∠B = 46°，根据「三角形内角和等于 180°」这一定理，∠C = 180° − 72° − 46° = 62°。

答：① a ∥ b（内错角相等，两直线平行）；② ∠3 = 108°；③ ∠C = 62°（三角形内角和为 180°）。
