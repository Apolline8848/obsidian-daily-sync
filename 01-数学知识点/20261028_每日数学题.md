**每日数学题（八年级上册·北师大版）· 2026年10月28日**

周末去市图书馆·自习与借书

**第一部分　题目**

【生活情境】周末，小明和同学一起去市图书馆自习、借书。图书馆里有整齐的书架、自助复印机、装书的纸箱和铺在地面的正方形地毯，处处藏着数学问题。请你运用所学的数学知识，帮小明解决下面的四个问题（每个问题覆盖一个不同的章节）。

**第1题（第一章　勾股定理）**

（1）图书馆大厅地面是一个长方形，长 12 米、宽 5 米。小明从大厅的一个顶点沿对角线走到相对的顶点，求他走的距离是多少米。

（2）大厅里有一块三角形地毯，量得三边长分别为 8 米、15 米、17 米。请判断这块地毯是否为直角三角形，并说明理由。

**第2题（第二章　实数）**

（1）图书馆把一个正方体纸箱用来装捐赠的图书，纸箱的体积是 216 立方分米，求纸箱的棱长。

（2）大厅门口铺了一块正方形地毯，面积是 45 平方米，求这块地毯的边长，结果用最简二次根式表示。

**第3题（第四章　一次函数）**

图书馆的自助复印机按「开机费 + 每页费用」收费。设复印 x 张收费 y 元，y 是 x 的一次函数。小明复印 5 张付了 13 元，复印 15 张付了 33 元。

（1）求 y 关于 x 的函数表达式；

（2）指出一次项系数 k 的值，并说明复印费随复印张数如何变化；

（3）小明复印 40 张，应付多少元？

**第4题（第七章　证明（平行线））**

图书馆书架上相邻的两层隔板 AB、CD 由一根竖向立柱 EF 支撑，直线 EF 同时与 AB、CD 相交。小明量得 EF 截 AB、CD 所形成的一对同位角 ∠1 = ∠2 = 58°。

（1）判断隔板 AB 与 CD 是否平行，并说明依据；

（2）已知 AB ∥ CD，∠2 = 58°，∠3 与 ∠2 是一对内错角，求 ∠3 的度数；

（3）已知 AB ∥ CD，∠2 = 58°，∠4 与 ∠2 是一对同旁内角，求 ∠4 的度数；

（4）一个三角形书挡的两个内角分别为 58° 和 62°，求第三个内角的度数。

**第二部分　答案与解析**

**第1题（第一章　勾股定理）**

（1）长方形的对角线与长、宽构成直角三角形，其中长、宽是两条直角边，对角线是斜边。

由勾股定理 a² + b² = c²，得：

对角线² = 12² + 5² = 144 + 25 = 169

对角线 = √169 = 13（米）

答：小明沿对角线走 13 米。

（2）三边中，最长边为 17 米，两条较短边为 8 米、15 米。

8² + 15² = 64 + 225 = 289，而 17² = 289。

因为两条较短边的平方和等于最长边的平方，所以由勾股定理的逆定理可知，这个三角形是直角三角形，且边长为 17 米的边所对的角是直角。

答：这块地毯是直角三角形。

**第2题（第二章　实数）**

（1）正方体的体积 = 棱长的立方，所以棱长 = 体积的立方根。

棱长 = ∛216 = 6（分米）　（因为 6³ = 216）

答：纸箱的棱长为 6 分米。

（2）正方形的面积 = 边长的平方，所以边长 = 面积的算术平方根。

边长 = √45 = √(9 × 5) = √9 × √5 = 3√5（米）

答：地毯的边长为 3√5 米。

**第3题（第四章　一次函数）**

（1）设 y = kx + b。把 x = 5、y = 13 和 x = 15、y = 33 分别代入，得：

5k + b = 13　......①

15k + b = 33　......②

② − ①，得：10k = 20，解得 k = 2。

把 k = 2 代入①：5 × 2 + b = 13，即 10 + b = 13，解得 b = 3。

所以函数表达式为 y = 2x + 3。

答：y = 2x + 3。

（2）一次项系数 k = 2。因为 k = 2 ＞ 0，所以复印费 y 随复印张数 x 的增大而增大。

（3）当 x = 40 时，y = 2 × 40 + 3 = 80 + 3 = 83（元）。

答：复印 40 张应付 83 元。

**第4题（第七章　证明（平行线））**

（1）因为 ∠1 = ∠2 = 58°，且 ∠1 与 ∠2 是直线 EF 截 AB、CD 所形成的同位角，根据「同位角相等，两直线平行」，所以 AB ∥ CD。

答：AB ∥ CD（同位角相等，两直线平行）。

（2）因为 AB ∥ CD，∠2 与 ∠3 是内错角，根据「两直线平行，内错角相等」，所以 ∠3 = ∠2 = 58°。

答：∠3 = 58°。

（3）因为 AB ∥ CD，∠2 与 ∠4 是同旁内角，根据「两直线平行，同旁内角互补」，所以 ∠2 + ∠4 = 180°，∠4 = 180° − 58° = 122°。

答：∠4 = 122°。

（4）根据「三角形内角和等于 180°」，第三个内角 = 180° − 58° − 62° = 60°。

答：第三个内角为 60°。
