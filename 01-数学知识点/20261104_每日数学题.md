**每日数学题（八年级上册·北师大版）· 2026年11月04日**

------ 周末逛社区庙会·欢乐游园 ------

**第一部分　题目**

**【生活情境】**

周末，社区举办了一年一度的欢乐庙会游园会。小华和爸爸妈妈一起去逛庙会，庙会入口搭起了高高的彩棚，场地上挂满了一排排彩旗，还有套圈、猜灯谜、投壶等游园活动和各种小吃摊位。请你运用所学的数学知识，帮小华解决下面的四个问题（每个问题覆盖一个不同的章节）。

**【第1题】（第1章　勾股定理）**

庙会入口搭了一座高台，工作人员需要架一架直梯供人上下。

\(1\) 梯子的底端离高台底部水平距离为 2.4 米，梯子的顶端搭在高台上、离地面 1.8 米处。求这架梯子的长度；

\(2\) 工作人员用三根木条 3 米、4 米、5 米搭成一个三角支架来支撑彩棚顶，请判断这个三角支架是否为直角三角形，并说明理由。

**【第2题】（第3章　位置与坐标）**

庙会现场有一张游园导览图，以正门为原点建立平面直角坐标系（单位：米），正方向与通常一致。

\(1\) 套圈摊位位于点 A(5, 2)，糖画摊位位于点 B(-5, 2)。点 B 与点 A 关于哪条坐标轴对称？

\(2\) 猜灯谜摊位位于点 C(-2, -3)，冰糖葫芦摊位与猜灯谜摊位关于 x 轴对称。求冰糖葫芦摊位的坐标，并说明它位于第几象限；

\(3\) 投壶游戏摊位原来在点 E(1, 3) 处，因场地调整向右平移 3 个单位，再向下平移 2 个单位。求平移后投壶摊位的坐标。

**【第3题】（第5章　二元一次方程组）**

逛累了，小华一家到小吃区买糖葫芦和汤圆。设一份糖葫芦 x 元，一份汤圆 y 元。

\(1\) 已知购买 2 份糖葫芦和 3 份汤圆共需 34 元；购买 3 份糖葫芦和 2 份汤圆共需 31 元。请根据题意列出关于 x、y 的二元一次方程组；

\(2\) 用加减消元法求出糖葫芦和汤圆的单价。

**【第4题】（第7章　证明·平行线）**

庙会场地上方拉着两排彩旗，两根绳子 a 与 b 互相平行（a∥b），第三根绳子 c 斜着穿过它们。

\(1\) 已知 c 与 a 相交所成的角 ∠1 = 70°，∠2 是 c 与 b 相交形成的同位角，且 ∠2 = ∠1。请写出由此判断 a 与 b 平行的依据，并求出 ∠2 的度数；

\(2\) 已知 a∥b，∠1 = 70°，∠3 与 ∠1 是一对同旁内角。求 ∠3 的度数；

\(3\) 庙会门口还有一个三角形的彩灯框架，它的三个内角中 ∠A = 55°，∠B = 65°。求 ∠C 的度数。

**第二部分　答案与解析**

**【第1题】勾股定理**

\(1\) 梯子的底端到高台的水平距离、梯子顶端离地高度与梯子构成一个直角三角形，其中水平距离和竖直高度是两条直角边，梯子是斜边。

由勾股定理 a² + b² = c²，得：梯子² = 2.4² + 1.8² = 5.76 + 3.24 = 9，所以 梯子 = √9 = 3（米）。

答：这架梯子的长度为 3 米。

\(2\) 三边中，最长边为 5 米，两条较短边为 3 米、4 米。

因为 3² + 4² = 9 + 16 = 25 = 5²，满足勾股定理的逆定理，所以由 3、4、5 为边的三角形是直角三角形，且边长为 5 米的边所对的角是直角。

答：这个三角支架是直角三角形（因为 3、4、5 是一组勾股数）。

**【第2题】位置与坐标**

\(1\) 点 A(5, 2) 与点 B(-5, 2) 的横坐标互为相反数（5 与 -5），纵坐标相同（都是 2），所以两点关于 y 轴对称。

答：点 B 与点 A 关于 y 轴对称。

\(2\) 关于 x 轴对称的点，横坐标不变、纵坐标变为相反数。所以冰糖葫芦摊位的坐标为 (-2, 3)。

该点横坐标为负、纵坐标为正，位于第 II 象限（符号为 (-, +)）。

答：冰糖葫芦摊位坐标为 (-2, 3)，位于第 II 象限。

\(3\) 点的平移规律是「右加左减、上加下减」。向右平移 3 个单位：横坐标 1 + 3 = 4；向下平移 2 个单位：纵坐标 3 - 2 = 1。

答：平移后投壶摊位的坐标为 (4, 1)。

**【第3题】二元一次方程组**

\(1\) 由题意得：2x + 3y = 34 ......①；3x + 2y = 31 ......②。

答：方程组为「2x + 3y = 34；3x + 2y = 31」。

\(2\) 用加减消元法。

① × 3：6x + 9y = 102 ......③；

② × 2：6x + 4y = 62 ......④；

③ − ④：5y = 40，得 y = 8。

把 y = 8 代入①：2x + 3 × 8 = 34，即 2x + 24 = 34，2x = 10，得 x = 5。

答：糖葫芦每份 5 元，汤圆每份 8 元。

**【第4题】证明·平行线**

\(1\) ∠1 与 ∠2 是直线 c 分别与 a、b 相交所成的同位角。因为 ∠2 = ∠1（同位角相等），所以 a∥b，依据是「同位角相等，两直线平行」（平行线的判定）。

又 ∠1 = 70°，所以 ∠2 = 70°。

答：依据是「同位角相等，两直线平行」；∠2 = 70°。

\(2\) 因为 a∥b，∠1 与 ∠3 是直线 c 截两平行线所成的同旁内角。由「两直线平行，同旁内角互补」得 ∠1 + ∠3 = 180°。

所以 ∠3 = 180° − 70° = 110°。

答：∠3 = 110°。

\(3\) 由三角形内角和定理，三角形三个内角之和为 180°。

∠C = 180° − ∠A − ∠B = 180° − 55° − 65° = 60°。

答：∠C = 60°。
