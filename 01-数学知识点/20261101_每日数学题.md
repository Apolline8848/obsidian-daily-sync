**每日数学题（八年级上册·北师大版）· 2026年11月01日**

周末参观城市规划展览馆

**第一部分　题目**

【生活情境】周末，小宇和爸爸妈妈来到城市规划展览馆参观。馆内有一个巨大的新城区规划沙盘和一张按比例绘制的平面图，图上有纵横交错的道路、方正的广场草坪和各类公共建筑。小宇一边参观，一边思考起了数学问题。

**第 1 题（实数）**

\(1\) 规划图中有一块正方形中心广场，图上标注其面积为 2.89 万平方米。求这块正方形广场的边长。

\(2\) 另有一块正方形草坪，面积恰好是 2 万平方米，它的边长可表示为 100√2 米。请说明 √2 是有理数还是无理数，并把边长精确到 0.1 米（√2 ≈ 1.414）。

**第 2 题（位置与坐标）**

规划平面图以展览馆主楼所在位置为原点建立平面直角坐标系（单位：千米），正方向与通常一致。

\(1\) 学校位于点 A(3, 2)，医院位于点 B(-3, 2)。点 B 与点 A 关于哪条坐标轴对称？

\(2\) 体育馆位于点 C(-2, -3)，公园与体育馆关于 x 轴对称。求公园所在位置的坐标。

\(3\) 因规划调整，图中点 D(1, 2) 处的地标向右平移 4 个单位，再向上平移 3 个单位。求平移后地标的坐标。

**第 3 题（二元一次方程组）**

参观结束后，小宇一家到售票处买票。已知购买 3 张成人票和 2 张儿童票共需 210 元；若购买 2 张成人票和 3 张儿童票共需 190 元。设成人票每张 x 元，儿童票每张 y 元。

\(1\) 根据题意列出关于 x、y 的二元一次方程组。

\(2\) 用加减消元法求出成人票和儿童票的单价。

**第 4 题（证明·平行线）**

规划图中，东西走向的朝阳路 a 与 b 互相平行（a∥b），南北走向的建设路 c 与它们分别相交。

\(1\) 已知 c 与 a 相交形成的角 ∠1 = 65°，c 与 b 相交形成的同位角 ∠2 与 ∠1 相等。请写出由此判断 a 与 b 平行的依据，并求出 ∠2 的度数。

\(2\) 已知 a∥b，∠1 = 65°，∠3 与 ∠1 是一对同旁内角，求 ∠3 的度数。

\(3\) 规划图中还有一块三角形绿地，其三个内角中 ∠A = 50°，∠B = 70°，求 ∠C 的度数。

**第二部分　答案与解析**

**第 1 题（实数）**

\(1\) 解：正方形面积 S = 边长²，所以边长 = √S。

S = 2.89 万平方米 = 28900 平方米。

边长 = √28900 = √(289 × 100) = √289 × √100 = 17 × 10 = 170（米）。

（因为 17² = 289，√100 = 10。）

答：正方形广场的边长为 170 米。

\(2\) 解：正方形草坪面积 S = 2 万平方米 = 20000 平方米。

边长 = √20000 = √(2 × 10000) = √2 × √10000 = 100√2（米）。

因为 √2 是无限不循环小数，不能写成两个整数的比，所以 √2 是无理数。

边长 = 100√2 ≈ 100 × 1.414 = 141.4（米）。

答：√2 是无理数；草坪边长约为 141.4 米。

**第 2 题（位置与坐标）**

\(1\) 解：A(3, 2) 与 B(-3, 2) 的横坐标互为相反数（3 与 -3），纵坐标相同（都是 2），所以两点关于 y 轴对称。

答：点 B 与点 A 关于 y 轴对称。

\(2\) 解：关于 x 轴对称的点，横坐标不变、纵坐标变为相反数。C(-2, -3) 关于 x 轴对称的公园坐标为 (-2, 3)。

答：公园所在位置的坐标是 (-2, 3)。

\(3\) 解：点的平移规律是「右加左减、上加下减」。向右平移 4 个单位：横坐标 1 + 4 = 5；向上平移 3 个单位：纵坐标 2 + 3 = 5。

答：平移后地标的坐标为 (5, 5)。

**第 3 题（二元一次方程组）**

\(1\) 解：由题意得：3x + 2y = 210 ......①；2x + 3y = 190 ......②。

答：方程组为「3x + 2y = 210；2x + 3y = 190」。

\(2\) 解：用加减消元法。

① × 3：9x + 6y = 630 ......③；

② × 2：4x + 6y = 380 ......④；

③ − ④：5x = 250，得 x = 50。

把 x = 50 代入①：3 × 50 + 2y = 210，即 150 + 2y = 210，2y = 60，得 y = 30。

答：成人票每张 50 元，儿童票每张 30 元。

**第 4 题（证明·平行线）**

\(1\) 解：∠1 与 ∠2 是直线 c 分别与 a、b 相交所成的同位角。因为 ∠2 = ∠1（同位角相等），所以 a∥b，依据是「同位角相等，两直线平行」（平行线的判定）。又 ∠1 = 65°，所以 ∠2 = 65°。

答：依据是「同位角相等，两直线平行」；∠2 = 65°。

\(2\) 解：因为 a∥b，∠1 与 ∠3 是直线 c 截两平行线所成的同旁内角。由「两直线平行，同旁内角互补」得 ∠1 + ∠3 = 180°。

所以 ∠3 = 180° − 65° = 115°。

答：∠3 = 115°。

\(3\) 解：由三角形内角和定理，三角形三个内角之和为 180°。

∠C = 180° − ∠A − ∠B = 180° − 50° − 70° = 60°。

答：∠C = 60°。
