**每日数学题（八年级上册·北师大版）· 2026年10月29日**

------ 周末滨江定向越野挑战赛 ------

**第一部分　题目**

【生活情境】周末，小军和同学们报名参加在滨江公园举行的「定向越野挑战赛」。组委会给每位选手发了一张平面坐标地图和一只电子计时指卡，沿途设有检查点，补给站里售卖能量棒和矿泉水。请你运用所学的数学知识，帮小军解决下面的四个问题（每个问题覆盖一个不同的章节）。

**第1题（第一章　勾股定理）**

（1）在滨江公园里，小军从起点出发，先沿正东方向走 60 米，再沿正北方向走 80 米，到达第一个检查点。求起点到第一个检查点的直线距离。

（2）赛道旁立着一面三角形指示旗，三边长分别为 0.6 米、0.8 米、1.0 米。请判断这面旗是否为直角三角形，并说明理由。

**第2题（第三章　位置与坐标）**

以起点 O 为原点建立平面直角坐标系（每 1 格表示 100 米），正东为 x 轴正方向，正北为 y 轴正方向。已知三个检查点的位置：A(2,3)、B(−3,2)、C(1,−4)。

（1）分别写出点 A、B、C 所在的象限；

（2）求点 A 关于 x 轴对称的点 A′ 的坐标；

（3）选手从检查点 B 出发，先沿 x 轴正方向平移 5 格，再沿 y 轴正方向平移 2 格，到达终点 D。求点 D 的坐标。

**第3题（第四章　一次函数）**

赛前租用电子计时指卡，设租用 x 小时需付费 y 元，y 是 x 的一次函数。小军租 1 小时付 12 元，租 3 小时付 28 元。

（1）求 y 关于 x 的函数表达式；

（2）指出一次项系数 k 和常数项 b 的值，并说明付费 y 随租用时间 x 如何变化；

（3）小军租 5 小时，应付多少元？

**第4题（第五章　二元一次方程组）**

补给站售卖能量棒和矿泉水。小军买 2 根能量棒和 3 瓶矿泉水，共花 16 元；同学小华买 3 根能量棒和 2 瓶矿泉水，共花 19 元。求能量棒和矿泉水的单价各是多少元。（请列出二元一次方程组并求解）

**第二部分　答案与解析**

**第1题（第一章　勾股定理）**

（1）起点到检查点的路线与正东、正北两段构成直角三角形，两段直角边长分别为 60 米、80 米，所求直线距离是斜边。

由勾股定理 a² + b² = c²：

直线距离² = 60² + 80² = 3600 + 6400 = 10000

直线距离 = √10000 = 100（米）

答：起点到第一个检查点的直线距离为 100 米。

（2）三边中，最长边为 1.0 米，两条较短边为 0.6 米、0.8 米。

0.6² + 0.8² = 0.36 + 0.64 = 1.00，而 1.0² = 1.00。

因为两条较短边的平方和等于最长边的平方，所以由勾股定理的逆定理可知，这面旗是直角三角形，且边长为 1.0 米的边所对的角是直角。

答：这面旗是直角三角形。

**第2题（第三章　位置与坐标）**

（1）A(2,3) 横、纵坐标都为正，在第一象限；B(−3,2) 横坐标为负、纵坐标为正，在第二象限；C(1,−4) 横坐标为正、纵坐标为负，在第四象限。

（2）关于 x 轴对称：横坐标不变、纵坐标变为相反数，所以 A(2,3) → A′(2,−3)。

（3）沿 x 轴正方向平移 5 格，横坐标加 5；沿 y 轴正方向平移 2 格，纵坐标加 2。故 B(−3,2) → D(−3+5, 2+2)，即 D(2,4)。

答：A 在第一象限，B 在第二象限，C 在第四象限；A′(2,−3)；D(2,4)。

**第3题（第四章　一次函数）**

（1）设 y = kx + b。把 x = 1、y = 12 和 x = 3、y = 28 分别代入，得：

k + b = 12　......①

3k + b = 28　......②

② − ①，得：2k = 16，解得 k = 8。

把 k = 8 代入①：8 + b = 12，解得 b = 4。

所以函数表达式为 y = 8x + 4。

答：y = 8x + 4。

（2）一次项系数 k = 8，常数项 b = 4。因为 k = 8 ＞ 0，所以付费 y 随租用时间 x 的增大而增大。

（3）当 x = 5 时，y = 8 × 5 + 4 = 40 + 4 = 44（元）。

答：租 5 小时应付 44 元。

**第4题（第五章　二元一次方程组）**

设能量棒每根 x 元，矿泉水每瓶 y 元。由题意列方程组：

2x + 3y = 16　......①

3x + 2y = 19　......②

用加减消元法：

① × 3 得：6x + 9y = 48

② × 2 得：6x + 4y = 38

两式相减：(6x + 9y) − (6x + 4y) = 48 − 38，即 5y = 10，解得 y = 2。

把 y = 2 代入①：2x + 3 × 2 = 16，即 2x + 6 = 16，2x = 10，解得 x = 5。

检验：3 × 5 + 2 × 2 = 15 + 4 = 19，符合②。

答：能量棒每根 5 元，矿泉水每瓶 2 元。
