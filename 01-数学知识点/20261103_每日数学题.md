**每日数学题（八年级上册·北师大版）· 2026年11月03日**

生活情境：周末逛宜家·为新书房选购家具布置

**第一部分　题目**

**【生活情境】**

周末，小明和爸爸妈妈一起逛宜家商场，为家里新装修的书房选购书桌、书架、地毯等家具。在选购过程中，他们测量了书房的尺寸、计算了地毯的长度、研究了商场的会员积分规则，还统计了这次购物的花费。请帮小明解决下面四个问题。

**【第1题】（第1章 勾股定理）**

书房地面是长方形，长 4 米、宽 3 米。小明想沿书房地面的一条对角线铺一块长地毯。

\(1\) 这块地毯的长度至少应为多少米？

\(2\) 测量工人想检查墙角是否为直角：他测得相邻两面墙的长分别为 5 米和 12 米，这两面墙之间的斜边长为 13 米。请说明这个墙角是否为直角，并说出理由。

**【第2题】（第2章 实数）**

小明看中一块正方形地毯，它的面积是 13 平方米。

\(1\) 用算术平方根表示这块地毯的边长；

\(2\) 估算这块地毯的边长，精确到十分位；

\(3\) 比较这块地毯的边长与 3.6 米的大小。

**【第3题】（第4章 一次函数）**

宜家的会员积分规则如下：每消费 x 元可获得积分 y 分，y 与 x 成一次函数关系 y = kx + b。已知消费 1000 元可得 220 分，消费 2000 元可得 420 分。

\(1\) 用待定系数法求 k、b，并写出函数关系式；

\(2\) 判断积分 y 随消费金额 x 的增大而如何变化，并说明理由；

\(3\) 小明家这次共消费 1500 元，可获得多少积分？

**【第4题】（第6章 数据的分析）**

小明家这次选购了 5 件商品，价格（单位：元）分别为：150、200、200、250、400。

\(1\) 求这组数据的平均数、中位数、众数和极差；

\(2\) 计算这组数据的方差，并指出哪件商品的价格偏离平均数最远。

**第二部分　答案与解析**

**【第1题】勾股定理**

\(1\) 由勾股定理：对角线² = 长² + 宽² = 4² + 3² = 16 + 9 = 25，所以对角线 = √25 = 5（米）。

**答：地毯的长度至少应为 5 米。**

\(2\) 因为 5² + 12² = 25 + 144 = 169 = 13²，满足勾股定理的逆定理，所以由 5、12、13 为边的三角形是直角三角形，斜边 13 米所对的角是直角，即这个墙角是直角。

**答：这个墙角是直角（因为 5、12、13 是一组勾股数）。**

**【第2题】实数**

\(1\) 正方形边长 = √13（米）。

\(2\) 因为 3.6² = 12.96，3.7² = 13.69，而 12.96 \< 13 \< 13.69，所以 3.6 \< √13 \< 3.7，估算边长 ≈ 3.6（米）。

\(3\) 因为 3.6² = 12.96 \< 13 = (√13)²，且 3.6 与 √13 都是正数，所以 3.6 \< √13，即地毯的边长大于 3.6 米。

**答：边长为 √13 米，约 3.6 米，且 √13 \> 3.6。**

**【第3题】一次函数**

\(1\) 由题意得方程组：1000k + b = 220，2000k + b = 420。两式相减得 1000k = 200，所以 k = 0.2；代入得 220 = 1000 × 0.2 + b，即 220 = 200 + b，所以 b = 20。故 y = 0.2x + 20。

\(2\) 因为一次项系数 k = 0.2 \> 0，所以 y 随 x 的增大而增大（函数递增），即消费金额越多，积分越多。

\(3\) 当 x = 1500 时，y = 0.2 × 1500 + 20 = 300 + 20 = 320（分）。

**答：y = 0.2x + 20；积分随消费金额增大而增大；消费 1500 元可得 320 分。**

**【第4题】数据的分析**

\(1\) 平均数 = (150 + 200 + 200 + 250 + 400) ÷ 5 = 1200 ÷ 5 = 240（元）。

将数据从小到大排列：150、200、200、250、400。中位数 = 200（元）；众数 = 200（元）；极差 = 400 − 150 = 250（元）。

\(2\) 各数据与平均数的偏差分别为：150 − 240 = −90，200 − 240 = −40，200 − 240 = −40，250 − 240 = 10，400 − 240 = 160。

偏差的平方分别为：8100、1600、1600、100、25600。

方差 = (8100 + 1600 + 1600 + 100 + 25600) ÷ 5 = 37000 ÷ 5 = 7400。

各数据中偏差绝对值最大的是 160（对应 400 元的商品），所以价格偏离平均数最远的是 400 元的商品。

**答：平均数 240 元、中位数 200 元、众数 200 元、极差 250 元；方差为 7400；偏离平均数最远的是 400 元的商品。**
