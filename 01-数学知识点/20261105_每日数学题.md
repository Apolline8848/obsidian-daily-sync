**每日数学题（八年级上册·北师大版）· 2026年11月05日**

------ 立冬·全家包饺子 ------

**第一部分　题目**

【生活情境】立冬到了，天气转凉，小华一家围坐在一起包饺子。妈妈负责和面、擀皮，爸爸负责调馅，爷爷奶奶和小华负责包。厨房里，面板、擀面杖、饺子皮、馅料盆摆得整整齐齐，处处都藏着数学问题。请你运用所学的数学知识，帮小华解决下面的四个问题（每个问题覆盖一个不同的章节）。

**【第1题】（第2章　实数）**

\(1\) 妈妈用的正方形面板，面积是 196 平方厘米，求这块面板的边长；

\(2\) 爸爸揉好一团面，准备做成一个正方体的面团，这个面团的体积是 216 立方厘米，求这个正方体面团的棱长；

\(3\) 一块正方形饺子皮的面积是 12 平方厘米，它的边长可以表示为 2√3 厘米。请说明 √3 是有理数还是无理数，并估算 √12 精确到 0.1（√3 ≈ 1.732）。

**【第2题】（第3章　位置与坐标）**

餐桌上，小华以桌面中心为原点建立平面直角坐标系（单位：厘米），正方向与通常一致。

\(1\) 一盘饺子位于点 A(4, 3)，另一盘饺子位于点 B(-4, 3)，点 B 与点 A 关于哪条坐标轴对称？

\(2\) 醋碟位于点 C(-3, -2)，蒜泥碟与醋碟关于 x 轴对称，求蒜泥碟所在位置的坐标，并说明它位于第几象限；

\(3\) 一笼蒸饺原来位于点 D(2, 1) 处，摆放时向右平移 5 个单位，再向上平移 3 个单位，求平移后蒸饺所在位置的坐标。

**【第3题】（第6章　数据的分析）**

全家 6 口人（爷爷、奶奶、爸爸、妈妈、小华、妹妹）一起包饺子，每人包的数量（个）分别为：10、14、16、16、20、26。

\(1\) 求这组数据的平均数、中位数、众数和极差；

\(2\) 求这组数据的方差，并指出哪个数据偏离平均数最远。

**【第4题】（第7章　证明·平行线）**

厨房里放着三根擀面杖，其中两根 a 与 b 互相平行（a∥b），第三根 c 斜着搭在它们上面。

\(1\) 已知 c 与 a 相交所成的角 ∠1 = 60°，c 与 b 相交所成的同位角 ∠2 与 ∠1 相等。请写出由此判断 a 与 b 平行的依据，并求出 ∠2 的度数；

\(2\) 已知 a∥b，∠1 = 60°，∠3 与 ∠1 是一对同旁内角，求 ∠3 的度数；

\(3\) 妈妈在饺子褶上摆出一个三角形装饰，它的三个内角中 ∠A = 48°，∠B = 67°，求 ∠C 的度数。

**第二部分　答案与解析**

**【第1题】实数**

\(1\) 正方形的面积 = 边长的平方，所以边长 = 面积的算术平方根。

边长 = √196 = 14（厘米）（因为 14² = 196）。

答：这块面板的边长为 14 厘米。

\(2\) 正方体的体积 = 棱长的立方，所以棱长 = 体积的立方根。

棱长 = ∛216 = 6（厘米）（因为 6³ = 216）。

答：正方体面团的棱长为 6 厘米。

\(3\) 正方形面积 = 边长的平方，所以边长 = √12 = √(4 × 3) = 2√3（厘米）。

因为 √3 是无限不循环小数，不能写成两个整数之比，所以 √3 是无理数。

√12 = 2√3 ≈ 2 × 1.732 = 3.464，精确到 0.1 约为 3.5。

答：√3 是无理数；√12 ≈ 3.5。

**【第2题】位置与坐标**

\(1\) A(4, 3) 与 B(-4, 3) 的横坐标互为相反数（4 与 -4），纵坐标相同（都是 3），所以两点关于 y 轴对称。

答：点 B 与点 A 关于 y 轴对称。

\(2\) 关于 x 轴对称的点，横坐标不变、纵坐标变为相反数，所以蒜泥碟的坐标为 (-3, 2)。

该点横坐标为负、纵坐标为正，位于第 II 象限（符号为 (-, +)）。

答：蒜泥碟坐标为 (-3, 2)，位于第 II 象限。

\(3\) 点的平移规律是「右加左减、上加下减」。向右平移 5 个单位：横坐标 2 + 5 = 7；向上平移 3 个单位：纵坐标 1 + 3 = 4。

答：平移后蒸饺所在位置的坐标为 (7, 4)。

**【第3题】数据的分析**

\(1\) 平均数 = (10 + 14 + 16 + 16 + 20 + 26) ÷ 6 = 102 ÷ 6 = 17（个）。

将数据从小到大排列：10、14、16、16、20、26。中位数 = (第3个数 + 第4个数) ÷ 2 = (16 + 16) ÷ 2 = 16（个）。

众数 = 16（出现 2 次，次数最多）；极差 = 26 − 10 = 16（个）。

答：平均数 17 个、中位数 16 个、众数 16 个、极差 16 个。

\(2\) 平均数 = 17，各数据与平均数的偏差分别为：10 − 17 = −7，14 − 17 = −3，16 − 17 = −1，16 − 17 = −1，20 − 17 = 3，26 − 17 = 9。

偏差的平方分别为：49、9、1、1、9、81。

方差 = (49 + 9 + 1 + 1 + 9 + 81) ÷ 6 = 150 ÷ 6 = 25。

各数据中偏差绝对值最大的是 9（对应数据 26），所以偏离平均数最远的数据是 26。

答：方差为 25；偏离平均数最远的数据是 26。

**【第4题】证明·平行线**

\(1\) ∠1 与 ∠2 是直线 c 分别与 a、b 相交所成的同位角。因为 ∠2 = ∠1（同位角相等），所以 a∥b，依据是「同位角相等，两直线平行」（平行线的判定）。又 ∠1 = 60°，所以 ∠2 = 60°。

答：依据是「同位角相等，两直线平行」；∠2 = 60°。

\(2\) 因为 a∥b，∠1 与 ∠3 是直线 c 截两平行线所成的同旁内角。由「两直线平行，同旁内角互补」得 ∠1 + ∠3 = 180°。

所以 ∠3 = 180° − 60° = 120°。

答：∠3 = 120°。

\(3\) 由三角形内角和定理，三角形三个内角之和为 180°。

∠C = 180° − ∠A − ∠B = 180° − 48° − 67° = 65°。

答：∠C = 65°。
